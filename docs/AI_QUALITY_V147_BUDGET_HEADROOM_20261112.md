# 기존 예산의 전용 잔액과 후속 보정 준비

T25.1·T34.3에서 비용 CSV와 과거 보정 전용 배정·정산을 다시 대조했다. **일반 가용액은 US$0.611241이지만, 과거 72회 보정 전용 배정에 미사용액 US$5.078796이 별도로 남아 있다.** 이 전용 잔액은 일반 원장에 자동 반환되지 않으며, 아직 후속 평가에 사용할 수 있는 상태가 아니다.

| 기존 추가 US$35 안의 구분 | US$ | 상태 |
| --- | ---: | --- |
| 현재 일반 가용액 | 0.611241 | 현재 원장 가용액, 예약 0 |

| 전용 배정의 미사용 차액 | **5.078796** | 후속 범위로 재배정하는 연결과 승인 필요 |

현재 V3 원장의 보수 사용액 US$34.388759에는 과거 전용 배정이 포함돼 있다. 미사용 차액을 정산해 대체한다면 통합 보수 사용액은 US$29.309963이 되고 조건부 여유 US$5.690037과 합해 US$35가 된다. 이는 **제안 계산이며 현재 원장을 변경한 값이 아니다.** 기존 US$5의 닫힌 원장·잔여액을 재사용하지 않는다.

정산 파일은 `automaticReleaseToGeneralLedger: false`를 명시한다. 따라서 실행 전에 원래 전용 배정의 미사용 차액을 한 번만 소비하도록 연결하고, 일반 예약과 합친 상한을 강제해야 한다. 같은 미사용액을 다른 범위에서 다시 쓰거나 과거 배정 기록을 덮어써서는 안 된다. [과거 배정 범위](AI_QUALITY_V147_CALIBRATION_EARMARK_20261109.md)

## 남은 48회에 대한 조건부 제안

현재 요청 72개 중 실제 근거가 있는 24개를 제외한 48개만 후속 범위에 넣었다. 모델·제시 순서·요청 본문·계산 본문·후보 지문을 유지한다. 입력 계산 48회를 먼저 하고, 실제 입력 토큰에 25% 여유·30분 캐시 쓰기 단가·출력 최대 1,024토큰·지역 10% 여유·계산료 여유 US$1.68을 포함해 상한을 검사하는 제안이다.
