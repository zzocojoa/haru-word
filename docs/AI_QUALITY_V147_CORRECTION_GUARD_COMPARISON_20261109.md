# T6.2 교정 검사 오거절과 의미 보존 대조

동결된 후보에서 같은 동사의 현재형과 진행형을 연결하지 못하는 사례와, 교재에 없는 부사형을 교정문에서 막는 사례를 재현했다. 동결된 소스와 빌드에 손대지 않고 후보 파서를 세 형태로 묶어 비교했다. 신규 실제 모델 호출은 0건이다.

| 검사 방식 | 정상 교정 6건 수용 | 잘못된 교정 12건 중 수용 | 기존 합성 재생 180건 수용 |
| --- | ---: | ---: | ---: |
| 동결 후보의 검사 | 0 | 0 | 174 |
| 단어 비교를 제외한 검사 | 6 | 8 | 180 |
| 범위를 좁힌 시험안 | 6 | 0 | 180 |

단어 비교를 제외하면 수량·부정 등 명시된 보호 조건은 계속 검사한다. 그 밖의 명사 교체, 인용문 변경, 잘못 만든 부사와 철자가 통과했다. 시험안은 같은 조동사 뒤의 동사 형태와 문장의 나머지 부분이 일치하는 경우를 확인했다. 검토된 부사 형태도 인용문과 연결동사 보어를 보호하는 범위에서 확인했다. [British Council 진행형](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/verb-be) · [Merriam-Webster의 reckless](https://www.merriam-webster.com/dictionary/reckless) · [harmless](https://www.merriam-webster.com/dictionary/harmless)

180건 대조는 저장 당시의 입력과 동일한 합성 제공자 응답을 실제 판정 파서에 다시 넣은 결과다. 시험안은 제품 빌드에 적용하지 않았다. 동결 후보와 원래 60문항은 유지하고, 이 비교에 사용한 문항은 다음 수정판의 개발 근거로 구분한다. 새 평가의 참조 검토 첫 묶음은 실행 승인 대기 상태다.
