MC08에서만 새 피드백 변형을 만들었다. 과거 F04의 설명 “음악을 틀라는 뜻으로 완성했어요.”와 과거 fail 기대값·원문·점수는 그대로다. 새 설명은 “새 교정문은 음악을 틀라는 명령문입니다. 원래 의도를 확인한 것은 아닙니다.”다. 이 문장은 제시된 교정문의 성격만 말하므로 설명 차원의 pass를 가설로 둔다. 원래 학습자가 명령을 의도한 것은 아니므로 교정fail·필요한 보류fail·inventedIntent true는 유지한다. 설명 하나가 맞아도 유해한 전체 피드백을 승인하지 않는지 검사한다. 이는 새 예시이며 과거 점수의 소급 수정이나 개선율 근거가 아니다.

새 모듈은 기존 compileAiPanel을 직접 호출한다. 실제 목표/문맥 필드·별도 제품정책·기준4·출력1024를 그대로 사용해12×3모델×2배치=72개 개별 보정 요청을 만든다. 기대값·옛 ID·분류·검토 메모는 제공자 본문에 넣지 않는다. 각 입력 계산 본문은 전송할 실제 요청에서 같은 필드를 추출한다. 세 모델과 두 순서의 분모를 줄이거나 배치 응답으로 대체하지 않았다.

11개 가시 피드백의 기대 판정은 같은 작성자인 AI의 출처 기반 **가설**이다. 나머지1개는 미제공 통제다. 출처를 읽은 것, 합성 payload72개가 기대값과 일치한 것은 실제 채점기 보정/독립 영어 인증이 아니다. 기존 본평가 실행기는 여전히 qualifiedWitnesses0/required12로 키·잠금·호출 전에 차단한다. 호출자 boolean으로 승격할 수 없다. 새 미공개 가족도 아직 만들지 않았다.
