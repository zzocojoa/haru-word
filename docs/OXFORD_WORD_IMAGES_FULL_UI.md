# Oxford 전체 이미지 화면 연결

**현재 상태 · 2026-10-16:** 전체 3,809개 연결과 긴 단어 편집창 수정은 GitHub [PR #35](https://github.com/zzocojoa/haru-word/pull/35)로 `main@c79be6b`에 병합됐다. 기존 사이트는 **v132**, 런타임 소스는 `909df06`이다. 10월 15일 최종 검증에서 전체 원격 이미지와 운영 화면 파일의 일치를 확인했고, 이번 문서 정리에서는 GitHub/Sites 메타데이터를 재조회했다. [최종 상태·검증 요약](releases/2026-10-16-oxford-images-release-status.json)은 원래 검증 시점과 남은 한계를 구분한다. 아래 v131은 최초 전체 UI 게시, v132는 후속 편집창 수정 기록이다.

## 범위와 성공 기준

승인된 WebP 3,809개를 기존 사이트의 이미지 연습·단어 익히기·단어 편집창에 연결한다. 기존 시범 20개의 순서는 유지하고 나머지는 교재 순서로 이어 붙인다. 이미지 생성·재업로드와 AI 호출은 필요하지 않다.

- 이미지 연습은 선택한 기본 뜻과 품사가 일치하는 전체 항목을 제공한다. 앞면에는 정답을 숨기고, 확인 후 단어·뜻·품사를 표시한다. 성적은 기록하지 않는다.
- 일반 수업은 단어와 뜻을 공개하는 **단어 익히기**에서만 그림을 표시한다. 진단·회상·첫 답 단계에는 그림을 추가하지 않는다.
- 편집창은 현재 선택한 뜻 또는 작성 중인 뜻에 맞춰 미리보기를 갱신한다. 다른 뜻·개인 단어에는 추정한 그림을 붙이지 않는다.
- 학습 자료 스냅샷·첫 답·성적·일정·초안·사용자 편집·revision·저장/백업 형식을 변경하지 않는다. 이미지와 연습 위치는 학습 기록에 저장하지 않는다.

## 구현과 검사

1. 검증된 전체 가공 목록과 원격 연결 목록에서 작은 클라이언트 인덱스를 만든다. 빌드 시 교재 파일 지문·ID·철자·품사·뜻·출처 지문·이미지 해시·원격 주소를 대조한다. 교재가 바뀌면 오래된 이미지를 새 뜻으로 재해석하지 않고 빌드를 중단한다.
2. ID별 Map을 사용한다. 그림은 현재 항목과 다음 한 장만 요청하며 3,809개를 한꺼번에 다운로드하지 않는다. 주소는 기존 사이트의 해시 경로를 사용한다.
3. 전체 3,809개 매핑, 같은 철자/다른 뜻·품사, 개인 단어, 잘못된 인덱스와 교재 변경 차단을 단위 검사한다.
4. 로컬 Chromium/WebKit에서 전체 개수·비시범 항목·앞뒤·닫기·실패·편집 초안·단어 익히기·저장 재시도·기록 격리를 검사한다. 320/390/1440px·글자 200%·키보드·axe와 최종 테스트/타입/린트/빌드를 확인한다. 실제 iPhone은 별도 검사로 구분한다.

## 배포·복구·운영 영향

기존 Sites 프로젝트와 R2/DB 바인딩·공개 범위·환경 값을 유지한다. `word_image_pilot_enabled`는 기존 이름을 호환 유지하며 이제 전체 이미지 화면을 제어한다. 기본 false이며 운영은 기존 true를 사용한다. 임시 업로드 키는 재등록하지 않는다.

위험도는 중간이다. 학습 UI와 정적 목록만 바꾸며 DB 마이그레이션은 없다. 실패 시 플래그를 false로 적용하거나 **R2 읽기 지원이 있는 v130**을 다시 게시한다. R2 파일·GET/HEAD와 사용자 기록은 유지한다. R2 도입 이전 버전으로 단순 복귀하지 않는다.

관측에는 이미지 해시·HTTP 상태·안전한 오류 코드만 사용한다. 개인 문장·답변·키를 기록하지 않는다. 전체 이미지의 뜻 검수는 기존 승인 원장을 근거로 하며 이번 작업이 새로운 전체 의미 검수나 실제 iPhone 검사를 의미하지 않는다.

로컬 최종 검사 615개·타입·린트·빌드는 종료 코드 0이며, 기존 린트 경고 15개가 있다. 양쪽 브라우저의 활성/비활성 화면·로컬 D1 격리·저장 재시도·개별 검사 파일과 해시는 [검증 보고서](releases/2026-10-15-oxford-image-full-ui-verification.json)에 기록한다. **기존 사이트 v131**에 게시했으며 환경 revision71·공개 정책 revision4와 업로드 차단을 유지했다. [출시 보고서](releases/2026-10-15-oxford-image-full-ui-rollout.json)에 게시 후 전체 이미지 확인과 최종 상태를 남긴다.

## 로컬 재검증 명령

기존 빌드와 루프백 Worker를 사용한다. 승인 WebP 폴더는 `outputs/oxford-web/14552b36a1653f2aed9e14b09c833c0031b1204de5e0bdfc6902543a05d4ba6e/webp-640-q82-v1/assets`다. 예를 들어 PowerShell에서 다음과 같이 설정한다.

```powershell
$env:QA_BASE_URL='http://127.0.0.1:<로컬 포트>'
$env:QA_IMAGE_PILOT_MODE='enabled'
$env:QA_WORD_IMAGE_ASSET_ROOT=(Resolve-Path 'outputs/oxford-web/14552b36a1653f2aed9e14b09c833c0031b1204de5e0bdfc6902543a05d4ba6e/webp-640-q82-v1/assets').Path
# 설치된 모듈 위치로 QA_PLAYWRIGHT_PATH와 AXE_CORE_PATH를 설정한다.
node tests/image-practice-qa.cjs
node tests/image-practice-qa.cjs isolation
node tests/word-image-study-qa.cjs
$env:QA_BROWSER='webkit' # 같은 세 명령을 반복한다.
```

`full`은 기본 3,809개 대상과 두 장 요청을 확인한다. 기존 시범 20개 전환 검사와 별도로 `extended`는 A1~B2·동일 철자·높이가 다른 truth를 포함한 비시범 표본을 검사한다. 표본 전환 검사에서만 나머지 항목의 선택 뜻을 가상 사용자 뜻으로 설정한다. 전체 매핑은 단위 검사의 3,809개 대조로 확인한다.

플래그가 없는 Worker에서는 `node tests/image-practice-qa.cjs production`과 `node tests/word-image-study-qa.cjs disabled`로 진입·편집창·단어 익히기의 이미지 요청 0을 확인한다. 운영 학습 API를 QA로 호출하지 않는다.

접근성은 기존 20개의 검토한 장면 설명을 유지하고, 나머지는 정답을 누설하지 않는 공통 그림 안내를 사용한다. 전체 3,809개의 개별 장면 대체 텍스트를 새로 작성·검수한 것은 아니다. 단어 확인 후 뜻·품사는 텍스트로 접근할 수 있다.

## 긴 단어 편집창 확대 수정 · v132

2026-10-15 후속 검토에서 `recommendation` 편집창의 이미지가 320/390px·글자 200%에서 화면 밖으로 밀리는 문제를 확인했다. 제목 행의 줄바꿈과 단어 내부 줄바꿈을 허용하여 그림이 편집창 안에 남도록 수정했다. 저장·선택 뜻·이미지 매칭 로직은 바꾸지 않았다.

`node tests/image-practice-qa.cjs editor`는 `recommendation`과 기존 `bicycle`을 열어 320/390/1440px·글자 100/200%에서 이미지 전체의 위치·가로 넘침·axe·편집 취소 보호를 검사한다. 원래 코드에서 양쪽 브라우저 모두 실패(종료 1)한 뒤, 수정한 빌드에서 통과(종료 0)했다. 전체 이미지 연습과 `node tests/word-image-study-qa.cjs`의 저장 재시도도 Chromium/WebKit에서 통과했다.

[후속 검증 기록](releases/2026-10-15-word-image-editor-wrap-verification.json)은 로컬 검증 당시의 지문과 결과다. 이후 커밋 `909df06`을 GitHub와 Sites 소스에 푸시하고 기존 사이트 **v132**에 게시했다. 운영 CSS의 바이트도 검증한 빌드와 일치했다. [출시 기록](releases/2026-10-15-word-image-editor-wrap-rollout.json)에 배포·소스·환경과 CI 상태를 남긴다. GitHub의 Node 22/24 작업은 계정 결제·사용 한도 오류로 시작되지 않았으며, 로컬 통과와 구분한다. 위험도는 낮고 CSS 배치만 변경했다. DB/API/백업 마이그레이션과 관측 변경은 없으며, 복구는 이 CSS 수정만 되돌리거나 R2 읽기를 유지하는 v131을 재게시한다. 실제 iPhone 확인은 별도다.

## 남은 확인과 완료 기준

- GitHub CI: 계정의 결제·사용 한도 차단 원인을 해결한 뒤 Node 22/24 작업이 실제 실행돼 성공했는지 확인한다. 로컬 통과를 CI 통과로 바꾸어 적지 않는다.
- 실제 iPhone: Safari·홈 화면 실행에서 이미지 연습, 긴 단어 편집창, 글자 확대, 저장·재접속을 확인하고 결과를 기록한다. 로컬 Chromium/WebKit 결과와 구분한다.
- 이미지 백업·복구: 원본 PNG·WebP·승인 원장·연결 목록의 외부 복사본 여부를 확인하고 표본을 복원해 해시를 대조한다. 현재 외부 백업·복구는 미검증이다.
- 선택 개선: 기존 20개 외의 3,789개에 정답을 누설하지 않는 개별 장면 대체 텍스트를 작성·검수한다.

문서만 수정할 때는 Site를 다시 게시하지 않는다. 병합 전 증거와 시범 회차의 실패·대기 기록은 당시 상태로 유지하고, 현재 상태는 위 최종 요약에 연결한다.
