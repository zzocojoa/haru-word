# T34.4 채점 기준 v6·v7 비교 사전등록

앱의 메시지 보류 규칙을 영어 어휘 점수에 섞는 문제가 v7에서 줄어드는지 확인한다. 공개 개발 통제 6조건 × 3모델 × 2채점 버전의 36개 요청을 고정했다. 18쌍에서 각 버전은 같은 영어 입력, 앱 피드백, 참고 근거, 필드 순서, 모델과 출력 상한을 받는다. 비교하는 세 경계 안에서도 모델별 필드 순서를 고정했다. 버전 이름과 기준 지문은 각 버전의 실제 요청 형식에 맞춘다. 기대값과 사례 ID는 호출자만 보관한다.

| 대조 | 사전 기대값 |
| --- | --- |
| `Behind the music`을 완전한 문장 과제와 제목 과제로 제시 | 두 조건 모두 `music` 어휘 판단은 `pass`. 별도 앱 규칙 검사는 문장 과제 `fail`, 제목 `pass`. |
| `My cousin go to the library.`를 단어 `go`와 3인칭 단수 일치 과제로 제시 | 같은 `appropriate` 표시를 단어 뜻 사용으로는 `pass`, 요구 문법의 사용으로는 `fail`로 판단. |
| 명사 `music`을 사용한 문장과 형용사 `musical`만 사용한 문장을 제시 | 같은 `appropriate` 표시에서 명사 사용 `pass`, 파생 형용사만 사용 `fail`. |

판정은 고정 18쌍을 모두 모아 사례별·모델별로 대조한다. v7 어휘 판단이 사전 기대값에 18/18 일치하고, 문장 과제에서 v6의 불일치가 v7의 일치로 바뀐 쌍이 하나 이상이면 이 경계 수정에 대한 진단 근거로 삼는다. 다른 판단축과 중대 표시의 변화도 원문과 함께 검토한다. 누락, 본문 또는 버전 불일치, 판정 충돌은 보류로 남긴다. 6조건에는 같은 문장의 과제 변경과 이전에 개발에 쓴 단어·형태가 포함된다. 독립 평가자 자격, 미공개 오류 가족 검증, 본평가, 출시 판단은 각각 별도 관문을 적용한다.
