# T24.1·T24.2 후보 동결과 새 예비평가 첫 묶음

기준판과 `reference-v7` 후보판의 서버 파일 각각 291개와 289개를 앞선 실행 지문과 대조해 보관했다. 요청 함수 소스, 의존성 잠금 파일, 검토 정책, 기존 채점 기준도 같은 기록에 연결했다.

이전 60문항은 모두 개발 노출 표시가 있고, 첫 묶음 중 한 문항은 앱의 교정 검사를 수정할 때 직접 사용했다. 이전 문항과 검토 결과는 회귀 근거로 보관한다. 새 평가에서는 후보를 동결한 뒤 작성한 문항을 별도로 관리한다.

새 문항 초안은 단어와 문법 각각 정상, 수정 필요, 문맥 부족에 한 문항씩 배정했다. 기존 60문항과 정규화한 문장 중복은 0건이다. 6개 출처에서 목표 용법과 문장 완성 여부를 대조했으며, 독립 AI 교차 검토와 구조 가족 검토는 남아 있다. 두 앱과 세 모델 설정에서 합성 요청 36건을 확인했다. 두 앱에 전달된 입력은 쌍별로 일치했고, 요청에 작성자의 기대 판정과 출처 식별자가 들어가지 않았다. 실제 생성·채점은 0건이다. 60문항 분모를 유지하며 새 초안은 6/60, 정식 참조 자격은 0/60이다.
