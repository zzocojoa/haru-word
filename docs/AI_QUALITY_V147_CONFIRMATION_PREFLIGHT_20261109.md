# T34.2·T24.2 확인 평가 표본 사전 검사

개발·예비평가에서 이미 사용한 문장을 확인 평가 표본으로 다시 세지 않도록 로컬 검사기를 추가했다. 알려진 문장 지문, 가족 ID, 공통 시작·마무리 구절을 대조한다. 문장과 ID를 바꿔도 이미 확인한 두 문장 틀에 해당하면 제외한다. 검사에서 겹치지 않은 문항은 독립 가족 검토 대기 상태로 남긴다.

이전 문장 목록의 지문 953개를 보존하고, 구현 중 바뀐 테스트 파일 10개의 정적 문장 후보를 다시 읽어 지문 129개를 추가했다. 예비평가 초안 60문항 중 공통 틀을 쓰는 12문항과 회귀 테스트에 원문 그대로 들어간 2문항을 찾았다. 두 틀의 단어와 ID를 바꾼 대조군 12개도 모두 걸러졌다. 이번 정적 조사에서 펼치지 않은 동적 문장 틀 10개와 나머지 자료의 의미상 중복은 추가 확인 대상이다.

| 회귀 테스트에서 확인한 문항 | 원본 근거 | 보류한 요청 |
| --- | --- | --- |
| `fresh-grammar-needsCorrection-04` | `tests/ai-quality-morphology.test.mjs:28` | 생성 6개, 참조 검토 2개 |
| `fresh-word-needsCorrection-06` | `tests/ai-quality-morphology.test.mjs:30` | 생성 6개, 참조 검토 2개 |

두 문항은 개발 회귀 근거로 분류했다. 기존 60문항 기록과 16개 요청 지문을 보존했고, 대체 문항은 아직 채택하지 않았다. 12개 공통 틀 문항은 예비 길이 검사에 유지한다. 예비 60문항 전체는 확인 평가에 다시 쓰지 않는다. 첫 묶음에서 출처가 부족했던 별도 한 문항 재검토 범위는 이번 두 문항과 겹치지 않는다.
