# 브라우저에서 단어·문법 교정 요청과 새로고침 검증

별도 로컬 수정 후보의 빌드에서 가상 계정을 사용했다. Chromium과 WebKit에서 단어 연습과 문법 수업을 열고 문장을 입력한 뒤 ‘AI 참고 의견 요청’을 눌렀다. 브라우저의 앱 API 응답은 가로채지 않았으며, Worker에서만 AI 제공자 응답을 합성했다.

| 확인 항목 | 결과 |
| --- | --- |
| 문장 편집 중 제공자 요청 | 0건 |
| 버튼 클릭과 합성 제공자 요청 | 제출 4건에 각각 한 번 |
| 완성 교정문 표시와 저장 영수증 | 4건 일치 |
| 새로고침 뒤 원문·교정문 복원 | 4건 일치, 추가 요청 0건 |
| 기존 학습 기록 | 단어 독립 회상 상태와 문법 첫 답·관찰 기록 보존 |

최초 실행에서 문법 화면에 결과가 보인 직후 저장 상태를 읽어, 비동기 학습 기록 저장보다 검사가 먼저 끝났다. 실제 저장 값이 나타날 때까지 확인하는 방식으로 테스트를 수정했고 네 경로를 재실행해 종료 코드 0을 확인했다. 제품 파일 변경, 실제 모델 호출, 운영 쓰기는 0건이다. WebKit 로컬 브라우저 검사는 실제 iPhone 검사와 구분한다.
