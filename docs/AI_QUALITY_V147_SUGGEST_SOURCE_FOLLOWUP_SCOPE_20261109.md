# T24.3·T25.1 출처 보류 1문항 재검토 실행 범위

첫 검토에서 두 AI가 `Noor suggested postponing the launch.`라는 교정에 동의했다. 한 AI가 제공된 요약만으로 원문 형태를 배제할 수 없다고 판단해 보류했다. 이번 요청에는 `suggest` 바로 뒤의 동사 형태를 명시한 문법 근거를 추가한다. [첫 검토 기록](AI_QUALITY_V147_FIRST_REFERENCE_WAVE_RESULT_20261109.md) · [Cambridge 문법 자료](https://dictionary.cambridge.org/grammar/british-grammar/word-patterns-suggest)

| 범위 | 고정 값 |
| --- | --- |
| 실제 요청 | Sol과 Terra 검토 각 1회. 입력 토큰 계산 각 1회 |
| 요청별 중단선 | 계산한 입력 2,000토큰. 출력 최대 1,024토큰 |
| 추가 원장 가용액 | US$1.152100. 예약액 US$0 |
| 보수적 예약 상한 | **US$0.097209**. 모델 비용 여유 US$0.027209와 입력 토큰 계산료 여유 US$0.070000을 합산 |

모델 비용 여유는 입력량 25% 여유, 30분 캐시 쓰기 단가와 지역 처리 10% 여유를 포함한다. 실행 시 먼저 두 입력을 계산한 뒤 예약 한도 이내인지 확인한다. 예약액과 실제 청구액을 구분한다. [OpenAI 공식 요금](https://developers.openai.com/api/docs/pricing?latest-pricing-expanded=true)

별도 실행 승인과 일치하는 범위 지문이 확인된 경우에만 기존 키를 읽는다. 각 요청을 보내기 전에 기록하고, 같은 실행의 재전송과 자동 재시도를 막는다. 양쪽 응답이 일치하고 두 모델이 추가 출처를 인용하면 채택 심사 대기로 기록한다. 이 결과는 개발에 이미 사용한 문항의 출처 재검토에 한정한다.

실제 AI 검토와 토큰 계산은 각각 0회다. 정식 참조 자격 0/60과 앱 예비평가 0/360을 유지한다.

합성 검사 11개가 통과했다. 승인 누락, 승인 지문 불일치, 입력 상한 초과, HTTP 오류, 비밀 값 반사, 사용량 불일치, 응답 형식·교정·출처 이견을 포함한다. 검사 중 실제 예산 원장 두 사본과 실행 승인 상태는 그대로 유지됐다.
