# T24.2·T34.3 예비평가 참조 12문항의 출처 보완 재검토

[출처를 보완한 12문항](AI_QUALITY_V147_PILOT_REFERENCE_TRIAGE_20261109.md)에 대해 기존 작성 모델을 제외한 두 모델에게 한 번씩 요청한다. 24개는 개별 Standard 요청이다. 원래 과제와 작성된 참조를 유지하고 기존·추가 출처의 사실을 함께 제공한다. 기존 점수, 모델별 투표, 작성 모델, 새로운 기대 결과는 제공하지 않는다.

모델은 목표 용법, 원문 문법, 교정 또는 교정 보류, 출처의 충분성을 각각 판정하고 실제 사용한 출처 ID를 적는다. 두 모델 모두 추가 출처를 인용하고 세 판단을 지지하며 출처가 충분하다고 평가한 문항을 집계한다. 이견·불확실성·미수집은 보류로 남긴다. 이전 120개 검토를 다시 채점하거나 새 검토로 교체하지 않는다. 60문항의 최종 참조 자격과 예비평가 실행은 별도 조건이다.

고정 요청 지문은 `18a9e57951f4e3b0e281a329445e15a6752df272c4edc36c742d0164e46408d2`다. 출력 상한 768토큰, 실제 입력 계산 한도 6,000토큰이다. 입력 계산을 모두 받은 뒤에만 모델 요청을 보내며 예약 상한은 US$2.308192로 계산료 여유 US$0.84를 포함한다. 추가 US$35 원장의 일반 가용액 US$3.039780에서 예약한다. 최대 6개를 함께 보내고 실패 이후에는 다음 묶음을 중단한다. 자동 재전송은 없다.
