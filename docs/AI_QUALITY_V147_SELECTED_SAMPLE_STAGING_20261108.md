# T34.2·34.3 · 선택한1% 목표의 표본·실행 설계

2026-11-08 · 상위24/40·세부78/133 · T34.1완료/나머지T34 진행 중. 새 유료AI·입력계산·키 접근0회. **1% 상한의 최소770가족은 개선 검정력이나 최종 표본의 완료를 뜻하지 않는다.**

## 선택된 조건과 미선택 조건

사용자가 선택한 전체95%·114단측 경계·관측 중대오류0·6유형별 최소770독립가족(총4620)을 유지한다. 표본 단위는 가족이며 모델·기준선/후보·반복·입력순서 표를 독립가족으로 세지 않는다. 후보의 중대오류는 별도 차단한다. 기준선의 알려진 오류나 보정용 양성 통제를 후보의 새 중대오류로 혼동하지 않는다. 기준선의 오류도 비교 근거로 보존한다.

개선/악화/동일/미측정 네 범주를 쓰는 기존 `pairedEffect`와 `paired-power-v1`은 그대로다. 한 모델·한 유형에서 전부 측정되고 `개선비율 하한-악화비율 상한>0`이어야 개선이 검출된다. 표는 **실제 순개선5%p라는 가정**의 민감도다. 표시한80% 목표와5%p 계획 효과는 작업용 제안이며 사용자가 확정한 추가 기준이 아니다. 전체 연구 공동 합격 확률·실제AI 성능·실제문항 독립성을 의미하지 않는다.

완전 측정인 앞4행은 순개선이 모두5%p지만 악화 구성에 따라 결과가 다르다. 마지막 행은 측정된 가족에서 세 번째 행과 같은 분포이며 가족 미측정확률0.1%를 가정했다. 실제 누락률 추정값이 아니다. 전부 측정돼야 한다는 기존 조건 때문에 표본 증가가 언제나 전체 검출확률을 높이지 않는다. 100%로 보이는 값은 표시 반올림이며 보장이 아니다.

N770에서 개선10%/악화5% 가정의 검출확률은 약15.46%다. N3072에서는 네 완전측정 예시가 모두80%를 넘지만, 이 네 예시만으로N3072를 최종 채택하지 않는다. 예비 근거·가족 독립성·필수 유형별 조건·효과/검정력·누락/오류·실제 비용을 함께 검토하고 T35에서 새로운 확인 표본 전에 동결한다. 위험1% 달성이나T34.2완료로 처리하지 않았다.

## 예비60문항을 보존하는 단계 계획

기존 배분을 그대로 유지했다. 단어/문법×정상/교정필요/문맥부족6유형 각10가족,문법15수업 각2가족이다. 기준선/후보·3생성모델·예비반복1·생성자 외2검토모델·두입력순서를 유지한다. 제품생성360+교차검토1440+참조180+보정72=2052회라는 원래 범위를 줄이지 않았다. 이는 실제 전송 승인이나 정확한 미래 비용 견적이 아니다.

60개 배정 슬롯을 기록하고6유형이 하나씩 포함되는10개 블록을 만들었다. 블록 안 순서는 사용자 위험 선택 기록의SHA로 고정했다. 문항별 실제 본문/참조/출처/가족의 독립성은 아직 미동결이다. 식별자60개를 만들었다고 독립된 영어 가족60개가 검증된 것은 아니다.

제안하는 실행 단위는 한 가족의3모델×2버전 생성6회와 별도 교차검토24회다. 사전에 고정한 전체60가족/모든셀 분모를 유지한다. 단계별 실제 입력을 확인하고 출력 상한을 포함해 그 단계만 예약한 뒤, 실제 사용량을 정산해 다음 단계의 가용액을 계산한다. 예산 부족 시 나머지는 미실행/미측정으로 남고 전체 평가를 보류한다. 어려운 유형을 삭제하거나 결과가 좋은 단계만 모아 합격시키지 않는다. 전송 실패/불확실성은 기존 무재전송·최대비용 보존을 유지한다.

## 예산에서 확인된 제약

현재 추가35달러 중 가용21.583226달러·예약0이다. 원래5달러 닫힌잔여를 재사용하지 않았다. 현재 제품의 실제 설정은 응답 상한4096토큰이다. 입력0토큰을 넣고 출력 상한과 기존10%여유만 계산해도 **생성360회 전량 예약 노출은35.143680달러**, 한 가족 생성6회는0.585728달러다. 모델의 최대 입력 용량을 쓴 계산이 아니며,가격은 확인한2026-11-08 고정 가격을 사용했다. 참조·교차검토·입력계산료 여유·실제입력은 이 노출 계산에서 제외했다.
