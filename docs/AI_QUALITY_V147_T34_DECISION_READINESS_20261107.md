# T34.4 완료 조건·실제 평가 준비 상태 점검

**34번 「위험 허용치·표본·반복·판정 기준 사전 설계」는 review다.** 현재 작업은 34.4 「기준 도전 검토와 변경 통제」다. 34.3의 개발 예문 유입 차단은 검증했지만, 위험 기준·표본 타당성·AI 평가자 자격·본평가 비용을 확정한 것은 아니다. 전체40개·세부133개, 취소1개/세부3개와 상위24개·세부77개 완료 이력을 유지한다.

과거 phase29의 질문은 **“5% 예시부터 상세 검토할지, 1% 예시부터 검토할지”라는 선호 질문**이었다. 그 답변이 없다는 이유로 무과금 분석을 중단할 필요는 없다. 권장했던5% 예시를 작업상 검토 예시로 삼되, 어떤 최종 위험 수준도 승인됐다고 기록하지 않는다. 사람 검토자 섭외도 요구하지 않는다. 최종 위험/주장 승인과 구체적인 새 유료 범위 승인은 별개로 유지한다.

확인 평가의 최소 효과·검정력은 T34에서 검토 원칙을 세우고, T35에서 예비 결과를 설계 자료로 사용해 새 확인 평가를 보기 전에 동결해야 한다. 예비 결과를 확인 평가의 합격 근거로 쓰거나, 확인 결과를 보고 표본/기준을 완화하지 않는다. 이 점검으로 T34·T35의 완료 조건이나 전체 목표를 줄이지 않는다.

## 실제 진단이 보여 준 한계

- 완료한 공개6문항×3모델×2순서의36판정은 사전 기대값과10/36 일치했다. 문항 자체11/36, 공유 기준4/6과 구분한다. 개발에 노출된6개 대조 문항이며36개의 독립 가족 표본이 아니다. 영어 정답률·서비스 위험률·보정 합격으로 바꾸지 않는다.
- 네 가지 양성 위험 플래그를 각각6/6 감지했어도, 다른 차원의 오판이나 과잉 거절이 없음을 입증하지 않는다. 동일 공급자 모델의 공통 편향과 같은 개발 과정에서 작성한 기대값의 한계가 남는다.
- 순서에 따른10/18 차이는 한 번씩의 관찰이고 항목 별칭도 달랐다. 순서 효과나 기준 보완의 인과 효과로 확정하지 않는다. 구 응답을 새 기준으로 소급 채점하지 않는다.
- 전역426개·유한 템플릿69개·정적 후보433개를 합친 정확한 표면형893개는 부분 개발 노출 목록이다. 새로운 오류 가족의 독립성, 동적/변환/다른 경로와 보관 자료 전체, AI 사전학습에서의 미노출을 보증하지 않는다.
- 코드/모의 서버/Worker 검증은 실행·저장·복구의 근거다. 실제 AI가 기준을 이해하고 지켰다는 근거와 구분한다. 현재12개 보정 참조는 미자격/분쟁 상태이며 현재 필수 본평가 프로필의 차단을 유지한다.

## US$5와 전체 예비안의 관계

현재 승인 한도는 기존 사용분을 포함한 **세전 US$5**이며, 보수적 사용·예약은 **US$3.788335**, 잔여는 **US$1.211665**다. 옛 원장이나 미정 비용 여유를 초기화하지 않는다. 준비한 Sol·Terra4응답/4계산은 별도 범위 답변을 기다리는 부분 진단이며, 전체 본평가나 Astra 평가를 대체하지 않는다.

기존 예비안은 참조 준비180회와 별도 본평가1872회다. 본평가에는 생성360회(모델당120회)가 포함된다. 현재 제품 생성의 출력 상한4096을 유지하고 Standard 출력 단가를 적용하면 다음과 같다.

| 비용 검토 항목 | 세전 USD |
| --- | ---: |
| 생성360회가 모두 출력 상한을 사용할 때의 출력 비용 성분 | **31.948800** |
| 위 성분에 보수적 지역10% 여유 적용 | **35.143680** |
| 모든2052역할에4096출력을 가정한 이전 예시의 출력 성분 | 182.108160 |

위 표는 **완주를 보장하는 최대비용 명세의 하한을 점검한 값**이다. 입력 비용을 일부러0으로 놓아 제외한 계산이며, 모델 최대 입력량을 실제 입력량으로 가정하지 않았다. 실제 요청도 보내지 않았다. 마지막 행의 모든 보조 역할4096은 예시 조건으로 최종 승인 명세가 아니다. 생성4096은 현재 제품/예산 커널의 고정 조건이다.

**실제 청구액의 예측이나 최소 청구액은 아니다.** 각 응답의 실제 출력은 상한보다 작을 수 있고, 그룹별 예약/정산으로 부분 수집할 수도 있다. 다만 현재 전량·출력 상한을 그대로 두고 모든 최대 사용에 대비하는 완주 보장을 US$5로 약속할 수는 없다. 입력 실측을 정확히 하더라도 출력 비용 성분이 사라지는 것은 아니다. 표본·모델·역할·출력 상한을 임의 축소해 전체 평가를 완료 처리하지 않는다.

2026-11-07 [OpenAI 공식 API 가격](https://developers.openai.com/api/docs/pricing)을 다시 확인했다. Standard 출력 단가는 백만 토큰당 Sol US$10·Terra US$5·Astra US$50다. 기존 고정 가격과 일치했다. 입력 토큰 계산의 별도 단가와 실제 청구서는 계속 미확인이다. 새4회 진단의 조건부 예약액 US$4.718671도 실제 청구액 보증으로 바꾸지 않는다. 한도 인상이나 새 결제 승인을 요청하거나 실행하지 않는다.

## 다음 진행 조건

무과금으로 위험/표본/짝 비교 설계 예시와 자료 범위를 더 검토할 수 있다. 현재 준비된 새4회 공개 진단은 기존 질문에 대한 실제 사용자 답변과 동일 지문을 확인한 뒤 실행한다. 그 결과로 기준 자격과 불일치를 먼저 검토한다. 이 답변이 전체 예비·확인·운영·게시 승인이 되지는 않는다.

최종 N/r·가족/추출 분포·확인 효과/정밀도와 실제 본문·입력 토큰·가격·전체 비용 명세가 정해지기 전에는 T24/25/26의 실제 본평가 진입을 완료 처리하지 않는다. T35/36의 확인·일반화, T37의 AI 설명 적용성/실제 학습 효과 한계, 운영·출시·1일/7일 및 전체40작업은 남는다.

이 점검의 Node 계산은 현재 v3 합성 descriptor를 실제 컴파일해 역할·모델별 횟수와 고정 생성 상한을 확인했고, 별도 Python Decimal 계산으로 대조했다. 실제 영어 평가나 확정 실측 견적은 아니다. 원본 근거는 ROOT `outputs/ai-quality-v147-implementation-20261106/phase57/`의 `t34-readiness-audit.json`, `independent-readiness-costs.json` 및 최종 검증·보존 기록을 따른다. 원점수·키·개인 학습 내용은 기록하지 않았다.

제품/평가 실행 코드는 변경하지 않았으며 기존 제품·프로토콜 검증을 재사용한다. 이번 변경은 이 완료 조건 점검·관리 자료·기존 대시보드 반영이다. 실제 API/토큰 계산/키 접근·운영 QA·Git·배포·산출물 삭제0이다. T34와 자식4개의 review 및 전체 품질/출시 held를 유지한다.
