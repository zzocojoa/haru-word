# T24·T26 예비 60문항의 로컬 앱 경로 검증

60문항을 기준판·수정판과 Sol·Terra·Astra의 조합으로 격리된 두 빌드에 제출했다. 합성 로그인 헤더를 사용해 실제 상태 저장 경로와 단어·문법 피드백 API를 검증했다. 앱이 외부로 보내려는 요청 본문 **360/360**이 준비한 본문과 바이트 단위로 같았다. 단어 요청 180건에는 기존 단어 162건과 개인 단어 18건이 포함됐고, 문법 요청 180건은 15개 수업을 다뤘다. 일반 문장·짧은 답변·제목·명령 문맥도 포함됐다. 외부 전송을 격리 런타임에서 가로채 매 요청에 가상 미완료 응답을 돌려줬다. 360건 모두 교정문 없이 실패 영수증을 기록했다. 해당 영수증을 다시 읽었고, 같은 요청 ID를 다시 보내도 제공자 전송 시도가 늘지 않았으며 다른 계정에는 결과가 노출되지 않았다. 미인증과 모델 불일치 대조 4건은 전송 전에 차단됐다. 검사 뒤 두 로컬 Worker와 리스너를 닫았고 외부 AI 호출·입력 토큰 계산·키 접근·운영 쓰기는 각각 0건이다.

Node 24 사전 검사 8/8, 전체 경로 360/360, 독립 Python 본문·역할·빌드 지문·원장 대조와 검사 스크립트의 ESLint가 종료 코드 0이다. 최초 스크립트는 현재 로컬 검증만 수행하고 API 키를 읽는 경로가 없다.

예비평가의 실제 생성은 0/360, 교차 채점은 0/1,440이다. 예비 전량의 기존 입력 계산료 여유는 US$63이고, 수정 화면 보정 54개의 입력 계산료 여유는 US$1.89다. 추가 예산 원장 가용액은 US$1.770287이다. 이 금액은 청구액과 구분한다. 4개 참조 이견과 새 화면 보정이 남아 있고, 기존 전체 평가 실행기는 합성 모드만 수락한다. 실제 생성·교차 채점을 한 실행에 연결하고 승인된 범위와 예산을 검증하는 단계가 필요하다. T24·T26 및 품질 관문의 상태는 보존했다.
