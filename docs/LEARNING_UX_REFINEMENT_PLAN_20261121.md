## 과제 3의 확정 문구

| 상태 | 기본 표시 | 펼치거나 눌렀을 때 |

| 결과 후 | `AI 참고 의견`, `정답 판정은 아니에요`, 뜻·용법 및 문법 평가, `다시 요청` | `결과 상세`에 판단 근거, 보낸 한국어·영어, 사용 모델. `AI 전송·보관 안내`는 다시 요청 아래 |

평가와 교정을 재요청 버튼보다 먼저 배치한다. 제목 옆 ‘선택’ 표시와 반복되는 일반 교정 안내를 제거한다. 이전 조건의 결과와 미확인 요청을 알아보고 대응할 수 있는 흐름을 유지한다.

## 과제 7의 확정 화면

기본 화면 순서는 제목과 닫기, `변경하면 자동으로 저장돼요.`, 학습 수준, 하루 단어 목표, 현재 조건의 배정 안내, 복습만 하기 스위치, 주간 점검 요일, AI 참고 의견 모델, 친숙도 다시 확인 버튼이다. 하루 단어 목표는 1~10개이며 화면에는 현재 값과 배정 규칙을 표시한다. AI 모델의 중복 라벨과 친숙도 버튼 앞 반복 제목을 제거한다.

| 기본 접힘 항목 | 펼쳤을 때 |
| --- | --- |
| 목표 배정 안내 | 목표 범위와 기본값, 변경 적용 시점, 기존 배정·기록 유지, 후보 부족 시 배정 규칙 |
| AI 모델·요금 안내 | 다음 요청부터 모델 적용, 기존 의견·성적 유지, 명시 요청에만 선택 모델로 전송, 사용 한도, 요금표와 공식 링크 |
| 임시 입력·로그아웃 | 이 브라우저에 최대 7일 평문 보관, 보관 항목 수·한도, 임시 입력 삭제 및 삭제하고 로그아웃. 확인 단계에서 삭제 범위와 AI 재요청 비용 가능성 표시 |
| 학습일·기록 안내 | 계정별 저장과 한국 시간 자정의 학습일 변경 |
| 문제 진단 | 진단 정보 범위, 새로고침 시 초기화, 문제 진단 기록 받기 |

저장 실패·모델 사용 불가·임시 입력 보관 오류처럼 조치가 필요한 알림은 기본 영역에 표시한다. 확정 시안은 기본 작업 폴더의 `outputs/stitch-settings-preview-20261121/settings.html`이다. 해당 폴더에 모바일 기본·펼침, 데스크톱 캡처를 보관한다.

## 조사 근거

- 뜻 저장 뒤 24회 중 13회에서 화면이 아래쪽에 머물렀다. 문장 저장 뒤 최상단 도달은 다음 단어 8/12, 회차 결과 4/12였다.
- 상단 테두리 조사는 38개 화면 상태를 2개 브라우저와 3개 크기로 총 228회 검사했다. 같은 증상은 주간 점검과 월말 쓰기에서만 발견했다.
- 저장하고 나가기 화면에서 제목→안내, 집계→버튼, 버튼→첫 단어 기록은 각각 0px이었다. 390×844에서 카드 하단 약 10px이 메뉴에 가렸고, 844×390 WebKit에서 저장 직후 제목이 화면 위로 벗어났다. 기본 작업 폴더의 `work/p66/work/exit-summary-spacing-cBNH3z/`에 기준 캡처가 있다.
