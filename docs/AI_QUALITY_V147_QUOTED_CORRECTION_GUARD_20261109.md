# T7.2·T7.3 교정 결과의 인용문 보존

로컬 수정 후보에서 `Mina wrote “They helped.”`의 인용문을 `“They help.”`로 바꾼 합성 교정이 기존 검사를 통과했다. 일반 활용형 검사에서 `helped`와 `help`를 같은 동사로 취급한 결과다. 인용부호로 묶인 문구를 활용형 검사보다 먼저 대조하도록 수정했다. 인용문 안의 내용을 유지하면서 바깥 문법을 고치거나 인용부호 모양을 바꾸는 교정은 허용한다.

| 검증 | 결과 |
| --- | --- |
| 실제 판정 파서 회귀 | 인용문 변경 6건 거절. 바깥 문법·따옴표 모양·아포스트로피 대조군 6건 수용 |
| 빌드한 단어·문법 API | 정상 교정 2건 저장 및 재조회. 인용문 변경 2건에서 교정 없는 실패 응답 저장 및 재조회 |
| 중복 요청 | 같은 요청을 다시 제출한 4건에서 제공자 요청 추가 0건 |
| 기존 앱 회귀 | 요청 본문 180/180 동일, 합성 응답 180/180 수용, 이전 복원 6건 저장·재조회. Chromium과 WebKit에서 두 복원 사례를 다시 표시 |
| 최종 검사 | 단위 테스트 895/895, 타입 검사·린트·빌드 종료 코드 0. 기존 린트 경고 15개 |

첫 타입 검사에서 현재 컴파일 대상으로 지원하지 않는 정규식 플래그를 발견해 바꿨다. API 검사의 가상 단어에 빠진 뜻을 채웠고, 수집기가 제외하는 로그 대신 실제 API 응답과 저장된 영수증을 대조했다. 인용부호가 닫힌 네 형태를 검사하며, 복잡하게 중첩된 인용의 해석은 이 검사 범위를 벗어난다.

변경은 별도 로컬 수정 후보에 적용했다. 동결 평가 후보 서버 파일을 기존 지문과 대조했으며 변경 0건이다. 실제 모델 호출과 운영 쓰기는 0건이다.
