# T34.3·34.4 채점 기준 v7·v8 실제 대조 실행 범위

2026-11-09. [phase96에서 고정한 공개 6개 사례·3모델·2버전](AI_QUALITY_V147_ASSESSMENT_BOUNDARIES_20261109.md)을 각 1회 비교한다. 기존 요청 본문, 판정 기준과 분모를 사용한다. 입력 토큰 계산 36회 이후 최대 모델 응답 36회를 수집한다. 어느 입력 계산이든 8,000토큰을 넘거나 예약액을 넘으면 모델 요청을 중단한다. 3개씩 제한된 묶음으로 실행하고, 전송·사용량 오류가 발생한 묶음의 응답을 회수한 뒤 다음 묶음을 중단한다. 자동 재전송과 재개는 금지한다.

추가 US$35 원장 가용 US$5.935753 중 최대 US$4.283592를 예약한다. 계산료 미확인 여유 US$1.260000, 계산된 토큰보다 입력이 많아질 경우의 여유 25%, 출력 상한 1,024토큰, 지역 단가 10% 여유를 포함한다. 고정 본문은 캐시 수명을 별도 설정하지 않는다. 공식 기본 30분 쓰기 단가인 일반 입력의 1.25배까지 모델 입력 비용에 반영한다. 실제 사용량에서 더 긴 캐시 수명이나 입력·출력 한도 이탈이 보고되면 해당 묶음 뒤 중단하고 예약액 전부를 보수적으로 남긴다. 예상 채점 형식과 모순된 응답은 원문과 오류 번호를 남긴다. 해당 슬롯을 합격 처리할 수 없다. 공개 대조의 개선 기준을 충족해도 보정 문항 채택, 예비·확인 평가, 운영 게시에는 별도 조건이 적용된다.
