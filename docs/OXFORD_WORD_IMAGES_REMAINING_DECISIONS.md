## 1. 글자 형태가 뜻인3항목

[기존 계획](OXFORD_WORD_IMAGES_PLAN.md)은 “이미지에 영어·한글·숫자·라벨·예문·워터마크를 넣지 않는다.”고 정했고 사용자가 capital/letter에는 “글자 금지 유지·두 항목 보류”, print에는 “글자 금지 유지·print 보류”를 선택했다. 다음 후보는 이 결정의 변경이 필요하므로 생성하지 않았다.

|---|---|---|
| capital 형용사 · d056f2650b116cba | 대문자의 | 같은 글꼴/같은 높이의 소문자 a와 대문자 A 형태를 비교하고 대문자 쪽을 고르는 손. 단순히 큰 글자=대문자라는 잘못된 규칙을 쓰지 않는다. |

예외의 범위는 이3항목의 뜻을 이루는 영문 글자 형태에만 한정하며 설명 문구·제목·한국어·숫자·워터마크·브랜드·다른3806항목의 글자 금지는 유지한다. 원본/320px에서 의미·표식·스타일·PNG를 재검수하고 기존 정책 기록을 삭제하지 않고 후속 결정으로 연결한다. 글자 금지를 유지하면 기존 보류도 유지하며 전체3809개 완료로 표시하지 않는다.

## 2. breast 명사 · 53b4f95ddd122fc2

기본 뜻은 유방이다. 내장 도구가 기존 의료 해부학 장면2회를 output/sexual 분류 HTTP400으로 거절했고 실제 이미지가 반환되지 않았다. 반환되지 않은 내부 결과/오분류 원인은 확인할 수 없다. 기존 반복 품질14개 범위에서는 제외했고 다른 서비스로 전환하거나 같은 거절 요청을 자동 재시도하지 않았다.

새 후보를 선택한다면 원래 노출/절개도를 반복하지 않고, 완전히 옷을 입은 성인 여성과 의료인이 중립적인 상담 공간에서 유방 위치에 관한 상담을 하는 별개의 교육 연상 장면을 검토한다. 손은 옷 위의 해당 위치를 가리키며 노출·질환/진단 주장·문자/리본 표식은 포함하지 않는다. 일반 가슴/옷 상담으로만 읽히면 뜻 검수 미달로 보류한다. 새 장면도 내장 도구가 거절하면 실제 오류/시작 슬롯을 기록하고 중단한다. 생성 여부와 학습 의미 통과를 미리 보장하지 않는다. 기존2실패/요청ID/해시와 파일 없음 상태를 지우지 않는다.

## 결정 후 실행 체크리스트

1. 실제 사용자 답변을 기존 보류/실패와 연결한 별도 승인 기록에 고정한다.
2. 새 정적 장면/프롬프트·교재/기존 원장 지문을 검증한다. 최초53회와 품질14개 승인 객체는 교체하지 않는다.
3. 항목별 원본·320px·필요 확대·PNG 해시/디코딩·의미를 확인한다. 실패·시작 슬롯도 기록하고 서비스 실패에는 중단한다.
4. 새 통과 수와 남은 미승인 수를 문서/manifest에 일치시키고 검증된 결과만 커밋한다. 화면/호스팅/배포는 별도다.
