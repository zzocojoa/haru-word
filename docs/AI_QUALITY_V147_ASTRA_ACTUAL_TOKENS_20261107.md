## 실제 입력을 사용한 비용

## 계산 요청과 미정 비용도 예약에 포함

계산 요청을 무료로 정산하지 않았다. 공식 요금표는 Responses API가 별도 과금되지 않고 선택한 모델의 토큰 단가를 적용한다고 설명하지만, 별도의 count 전용 단가를 확인한 것은 아니다. 계산 요청마다 동일 Astra 요청의 입력과 최대출력4,096에 해당하는 금액을 추가로 잡아 **US$0.481162를 계산 요청용 여유로 계속 예약**했다. 이는 게시된 모델 토큰 단가에 따른 보수적 여유이며 count 전용 요금이나 최종 청구액의 인증이 아니다.

첫 Astra는 화면에 있는 원문 `She is speaking quiet.`와 교정문 `She is speaking quietly.`를 그대로 인용했다. 기존 프롬프트는 화면의 피드백 문구 인용을 허용하지만, 기존 검사기는 인용을 설명문에서만 찾아 `CR1_FEEDBACK_QUOTE`로 거절했다. 실제 원문·응답을 보존한 채 이전 검사 실패를 재현했다.
