# 검토 묶음과 실제 사용량 대조 — 2026-11-12

T24.3에서 검토 요청을 묶는 오프라인 도구를 구현하고, T34.3에서 실제 사용량을 대조했다. 제품 실행 코드는 바꾸지 않았다.
새 유료 AI 응답·입력 토큰 계산·API 키 읽기는 모두0회이며 현재 추가35달러 원장과 기존 승인을 유지한다.

## 바뀐 요청 구성

각 생성 결과를 생성자 이외 두 모델·두 표시 순서로 검토하는 조건과 총1,440슬롯을 유지했다.
같은 모델·표시 순서의 검토만 최대8개씩 한 JSON 요청에 넣는다. 같은 영어 원문의 여러 결과는 서로 다른 묶음에 넣어 직접 비교 노출을 줄인다.
표시된 한국어 의도·영어 답안·판정·교정문·설명과 참조는 각 항목에 그대로 묶인다. 다른 항목의 내용·사건·정답을 빌려 쓰지 않도록 요청한다.
생성자·제품 버전·과거 점수·작성자 기대값은 검토 본문에 넣지 않는다. 검토 표를 재사용하거나 다수결로 불일치를 없애지 않는다.

| 개발 자료 | 개별 검토 슬롯 | 묶음 요청 | 자료 없는 슬롯 |
| --- | ---: | ---: | ---: |
| 합성 앱 결과360건 |1,440|168요청에 유효 자료1,260판정 연결|180|
| 앞서 실제 앱에서 얻은6응답 |24|12요청에24판정 연결|0|

자료가 없는180슬롯은 분모에 남기고 AI에 보내지 않는다. 이를 통과나 성공적인 보류로 집계하지 않는다.
자료가 있는1,260판정의 요청 수를1,260→168로 줄이는 구성이다. 실제 AI 판정은 아직0건이다.
전량 결과가 있는 정식1,440판정을8개씩 담아도 적어도180요청이 필요하며, 동일 원문 분리 등으로 더 필요할 수 있다.

기존 개별 검토의 출력 상한1,024토큰을 항목마다 유지해 묶음 상한을 최대8,192로 잡았다.
잘못된/빠진/중복 항목, 다른 정책 응답, 본문이나 토큰 계산 본문 변조는 차단한다. 응답 배열 순서가 달라도 항목 ID로 원래 검토 슬롯에 연결한다.
중대 오류와 불확실한 판정은 다른 항목의 통과와 별도로 보존한다. 자동 재시도·실제 전송·예산 예약 기능은 이 도구에 없다.

이것은 한 번의 Responses 요청에 여러 JSON 검토 항목을 넣는 설계다. 별도 Batch API나 할인 단가를 사용하지 않는다.
[OpenAI Docs의 요청 묶음 안내](https://developers.openai.com/api/docs/guides/rate-limits#batching-requests)는 여러 작업을 한 요청에 담는 방법을 설명하지만,
우리 채점기의 개별/묶음 품질 동등성을 보장하지 않는다. 문서 내 레거시 prompt 배열 예제를 Responses 입력으로 그대로 사용하지 않았다.
묶음 간 내용 간섭·순서·누락·출력 예산의 효과를 실제 보정에서 확인하기 전 정식 평가에 활성화하지 않는다.

## 비용과 남은 조건

현재 계산료 공학 충당기준0.035달러/계산을 적용하면, 자료가 있는 현재 묶음168개의 충당액은5.88달러다.
전체1,440판정이 모두 준비된 경우 최소180계산의 충당액은6.30달러다. 기존 개별1,440계산의50.40달러보다 작지만,
남은 조건부 예산0.723750달러를 여전히 초과한다. **이 금액들은 확인된 계산 API 요금이 아니다.**

새 본문에 대한 실제 입력 토큰 계산은 실행하지 않았다. 기존 생성 요청의 토큰 수를 새 채점 본문에 재사용하지 않는다.
아래는 각 요청 입력을5,000토큰으로 가정하고 입력25%·가격10% 여유, 항목별 전체 출력 상한, 계산료 충당액을 더한 조건부 합산 예약 시나리오다.
실측 견적이나 실제 지출 예측이 아니며, 모델 최대 입력량으로 계산한 것도 아니다.

| 범위 | 요청 수 | 조건부 합산 상한 US$ |
| --- | ---: | ---: |

계산은2026-11-12 재확인한 [Standard 짧은 문맥 공식 가격](https://developers.openai.com/api/docs/pricing)을 사용했다.
모든 관측/가정 입력에30분 캐시 쓰기 단가, 출력에 해당 모델 단가를 적용하는 기존 보수 기준을 유지했다. Batch 할인·캐시 적중을 가정하지 않았다.
요청별 실측 비용, 단계별 예약·정산과 실제 지출은 이 합산 상한과 구분해야 한다.

현재 일반 가용0.156241달러·전용 미사용0.567509달러·재배정 시 조건부 합계0.723750달러다.
전용 자금은 자동으로 일반 자금이 되지 않으며 새 유료 범위도 승인되지 않았다.
정식 평가를 진행하려면 기존 계산료 충당액의 정산 가능 범위와 요청별 실측 비용/총 범위를 먼저 확정해야 한다.
표본·두 비생성자·두 표시 순서·중대 오류·참조 자격·1% 위험 목표를 예산에 맞춰 임의로 낮추지 않는다.
