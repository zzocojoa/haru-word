# 교정 보류와 응답 부재 구분 · 평가 기준 v10

T34.4의 실제 이견 네 건은 ‘교정문을 보류한 결과’를 correction 차원에서 통과로 평가할지, 교정문이 없으므로 미측정으로 볼지의 차이였다. 평가 기준 v10에서 교정문 제공과 보류를 모두 관찰 가능한 결정으로 명시했다.

| 상황 | 새 기준의 correction 판단 | 예 |
| --- | --- | --- |
| 핵심 문맥이 부족해 필요한 내용을 묻고 교정을 보류함 | 정당하면 pass, 판단이 어려우면 uncertain | 과거인지 미래인지 묻고 임의 시제를 선택하지 않음 |
| 의도가 충분한데도 교정을 거절함 | fail 가능 | ‘나는 음악을 좋아해요’가 있는데도 Music의 뜻을 더 알려 달라고 함 |
| 응답 자체가 없음 | 다섯 차원 unavailable | 전송 실패나 응답 미보존 |

빈 교정문을 자동 통과시키지 않는다. 보류가 적절했는지 판단해야 하며, correction과 abstention 등 각 차원의 점수는 서로 자동 복사하지 않는다. 응답이 있을 때 교정문이 비었다는 이유만으로 correction=unavailable을 반환하면 새 해석기가 이를 거부한다. 응답 객체가 없으면 기존처럼 모든 차원을 unavailable로 유지한다.

변경은 평가 도구에 한정했다. 한국어 의도 사용 조건, 원문 문법과 의미 교정의 분리, 중대 오류 네 종류, 모델·두 제시 순서·다섯 평가 차원과 문항당 출력 상한 1,024는 유지했다. 사용자에게 추가 AI 호출을 요구하거나 제품의 교정 로직을 바꾸지 않았다.

새 기준을 개별·묶음 요청 생성기와 응답 해석기, 로컬 수집기에 연결했다. 수집기는 미제공 슬롯을 분모에서 보존하고, 정상 응답을 미제공 슬롯에 숨기거나 지문이 다른 슬롯을 넣으면 키를 읽기 전에 거부한다. 이전 단계의 자격증명 오탐 수정도 포함한다.

회귀 검사 **8/8, ESLint exit 0**이다. 필요한 보류·불필요한 거절·응답 부재·위험한 의미 선택·한국어 의도 교정·과거 응답 혼용 차단을 확인했다. 합성 종단 검사에서 24판정과 응답 부재 4슬롯, 전체 28슬롯을 구분해 유지했다. 이는 실제 AI 품질 검증이 아니다.

같은 공개 기준 12개를 새 기준으로 편성해 **18요청·72판정**을 준비했고, 그중 응답 부재 통제는 6판정이다. 합성 기대값을 넣어 72개 구조를 해석한 것은 전송·형식 검사다. 기대값은 여전히 AI 가설이며 참조 자격·채점기 자격·실제 영어 정확도를 인증하지 않는다. 실제 v10 AI 판정은 **0/72**다.

과거 v9의 새 판정 5/9, 미측정 39개와 중단 원문·실행 표식·보수 상한 US$2.806936은 변경하지 않았다. v9 응답의 해시를 바꿔 새 결과처럼 재사용하지 않는다. 이번 추가 AI 응답·토큰 계산·실제 키 읽기는 0이고, 비용을 다시 산정하거나 원장을 변경하지 않았다. 제품 소스 765개도 그대로여서 제품 테스트·타입·빌드는 반복하지 않았다.

다음 실제 실행에는 기존 실패의 정산 대조와 새 기준에 맞는 고정 실행 명세가 필요하다. 이 작업은 그 유료 실행을 준비 완료하거나 실행한 것으로 표시하지 않는다. 정식 보정·참조 자격·예비/본평가·1% 위험 상한·출시/운영 검증은 보류다. Task Master와 대시보드에는 기준 변경과 로컬 검증만 반영한다.
