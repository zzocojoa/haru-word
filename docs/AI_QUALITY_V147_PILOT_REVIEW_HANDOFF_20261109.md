# T26.2 앱 피드백과 교차 채점 요청 연결

예비 60문항의 고정 생성 슬롯 360개를 유지했다. 기준판과 수정판의 로컬 앱이 합성 제공자 응답을 받아 저장한 318개 피드백을 영수증과 함께 재조회했다. Chromium과 WebKit에서 얻은 제목·교정문·설명이 318건 모두 일치했다. 긴 기록은 ‘더 보기’를 열어 본문을 읽고 버튼 제목은 채점 입력에서 제외한다. [앞선 앱 요청 360건 대조](AI_QUALITY_V147_PILOT_WORKER_PREFLIGHT_20261109.md)

피드백 한 건마다 생성 모델을 제외한 두 모델에 입력 우선·피드백 우선 요청을 각각 한 개씩 연결했다. 생성자가 보는 입력, 기준판·수정판 구분과 영수증 지문은 내부 대조에 사용했다. 채점 모델에는 원래 과제·화면 내용·공통 판정 기준을 제공하며 생성자, 버전, 사례 식별자와 기대 라벨은 감췄다. 전송 본문과 토큰 계산 본문을 각각 지문화했다. 화면 설명 한 건을 바꾼 대조에서 해당 결과에 연결된 요청 ID 네 개만 달라졌다.

합성 응답으로 354개 앱 경로를 실행했다. 318개는 피드백을 표시했고, 36개는 실패로 저장했다. 실패 36개는 의도적으로 만든 미완료 6개와 현행 앱 검증이 거절한 합성 교정 30개다. 6개는 누락을 확인하기 위해 제출하지 않았다. 따라서 1,440개 전체 채점 슬롯 중 1,272개가 저장된 화면과 연결됐고 168개는 화면 미확보로 보류됐다. 거절 기록의 사유는 내용 변경 24개와 부정 변경 6개이며, 모두 합성 교정이므로 실제 모델의 오류나 영어 정답 여부는 판단하지 않았다.

중복 부모·누락된 계획 슬롯·요청 지문 변조·재조회 불일치가 차단됐다. 첫 화면 추출은 긴 기록의 펼치기 제목을 포함해 실패했다. 요청 준비 중에는 6개 문항의 수업 기준이 제목 필드 한도를 넘었다. 제목에는 짧은 수업명을 사용하고, 전체 기준은 원래 요청 입력에 보존했다. 저장된 앱 응답으로 재실행했으며 Python 검산은 1,440개 요청의 화면·부모·모델·순서·지문을 대조했다.

요청마다 규칙을 다시 구성하는 로컬 비교 실행은 대체 방식의 전수 검증 뒤 중단했다. 확정 지문이 있는 기존 V8 요청의 공통 지침과 구조를 재사용했고, Python에서 1,440건의 공통 지침과 옵션을 그 원본에 대조했다. 새 방식으로 전체 슬롯을 편성하고 변조·누락 대조 5개를 수행하는 데 약 5초가 걸렸다.

이번 연결기는 가상 재생 범위다. 실제 AI 생성 0/360, 교차 채점 0/1,440, 새 입력 토큰 계산 0건이며 원장 가용액 US$1.770287을 유지했다. 실제 실행에는 승인된 전송·비용 경로 연결과 참조 및 채점기 보정이 남아 있다.
