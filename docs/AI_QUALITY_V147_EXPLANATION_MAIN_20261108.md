# 설명 기준4의 본평가 경로 연결

2026-11-08 · T34.3/T34.4 · phase73. 상위24/40·세부77/133 완료(취소1/3)와 T34/자식4 review를 유지한다. 전체 목표·실제 본평가·출시는 미완료다.

## 변경한 동작

기존 본평가 도구에 `contract.explanationScope=explanationMainPolicyV1()`을 선택하는 경로를 추가했다. 기존의 실제 학습 목표 필드·원래 요청 지문·선택 문맥을 전달하면서, 공개 설명 대조에서 사용한 기준4·지시·스키마·출력1024상한을 그대로 사용한다. 판정5차원·중대위험4종·근거3축과 별도 제품 정책 검사를 유지한다.

예를 들어 “Close the hatch.”를 불필요하게 고친 피드백에서, 설명이 실제 편집 내용을 정확하게 말했으면 설명 차원은 pass일 수 있다. 교정 차원의 fail은 그대로 남으므로 전체 피드백은 승인되지 않는다. 정상 문장을 유지했더라도 설명 자체가 거짓이면 설명 차원에서 실패한다. 의미 반전은 계속 중대 보류다. 이 예시는 공개 개발 문항이며 새로운 미공개 성능 근거가 아니다.

컴파일러 → 실제 요청 본문·입력 토큰 계산 → 물리 캡처 → 보고서가 같은 기준4 지문과1024상한을 사용한다. 본문을 구형 기준으로 바꿔 검증한 사본을 전송하지 않는다. 실제 부모 요청의 원래 목표가 다르면 문장만 같아도 거절한다. 이전 버전 응답, 누락·변조된 문맥/기준 지문, 중복 JSON 키와 출력 상한 변경도 거절한다. 잘못된 응답의 원문과 알려진 사용량은 보존하고 미확정 비용을 남긴다.

이 연결은 현재 **합성 모드의 본평가 도구**까지다. V3 도구의 실제 제공자 전송 금지와 신규 OpenAI Responses 전용 제품 정책은 유지했다. 실제 본평가를 실행했다거나 운영 제품에 게시했다고 표현하지 않는다.

## 자격을 인정하지 않는 조건

새 기준에 맞춰 출처가 검증된 본평가 보정12문항 레지스트리가 아직 없다. 공개 단어 진단의 Sol/Terra36판정은 이를 대신하지 않는다. 새 경로의 실행기는 이 상태에서 저널 잠금·토큰 계산·모델 전송 전에 거절한다. 호출자가 `sourceQualified=true`를 넘기거나 필수 자격 플래그를 끄는 방식으로 통과시킬 수 없다. 향후 출처와 실제 보정 근거가 준비되면 별도 버전으로 연결해야 한다.

실패한 옛 기대값·66/72 이견·원문·원장은 바꾸지 않았다. 합성 fixture는 이전 점수를 기계적으로 재사용하여 전송/저장/파싱을 검사한다. 새 영어 정답표나 실제 채점기 자격으로 등록하지 않는다. fixture를 기록한 테스트는 저널·계산·캡처 기본 도구를 직접 사용한 통제 검사이며, 실제 실행기의 자격 차단을 우회하는 런타임 옵션은 만들지 않았다.
