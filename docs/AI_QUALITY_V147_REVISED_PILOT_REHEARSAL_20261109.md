# T24.4·T26.1·T26.2 대체 문항을 포함한 예비평가 로컬 재현

대체 초안 두 개를 포함한 60문항을 두 동결 앱에서 세 모델 설정으로 제출했다. 기존에 기록한 생성 요청 360개의 본문을 그대로 재현했다. 로컬 Worker는 가상 계정과 합성 응답을 사용했다.

| 확인 범위 | 결과 |
| --- | ---: |
| 생성 요청과 결과 영수증 재조회 | 360/360 |
| 기준판 합성 피드백 저장 | 177/180 |
| 후보판 합성 피드백 저장 | 180/180 |
| Chromium·WebKit 표시 일치 | 저장 피드백 357/357 |
| 화면과 연결된 교차 채점 요청 | 1,428/1,440 |
| 대체 문항 화면에 연결된 교차 채점 요청 | 48/48 |

기준판은 한 문법 문항의 합성 교정문을 내용이 바뀌었다고 판단해 세 모델 설정에서 거절했다. 후보판은 같은 교정문을 저장했다. 거절 세 건의 결과와 연결된 채점 슬롯 12개는 전체 분모에 보류로 유지했다. 별도 대조에서는 미완료 응답 한 건과 누락 영수증 한 건을 넣어, 예정 채점 수를 유지하면서 보류가 20개로 늘어나는 것을 확인했다.

원문과 목표를 포함한 실제 앱 입력, 저장된 화면, 채점 요청과 입력 계산 본문을 연결했다. 생성 모델 이외의 두 모델과 두 순서가 모든 부모 요청에 배정됐다. 원본 영수증 식별자와 작성자 기준은 채점 요청에서 제외했다. 독립 Python 검산으로 채점 본문 1,440개와 입력 계산 본문 1,440개의 지문과 연결을 확인했다.
