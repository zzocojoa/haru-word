# T27.2·T27.3 개정 예비평가 집계 검증

동결한 개정 문항 60개와 화면 검토 요청 1,440개를 연결했다. 모델 두 개와 입력 순서 두 가지로 구성한 네 채점 자리마다 원래 요청 지문과 채점 상태를 기록한다. 서로 다른 원본이나 화면을 같은 결과로 집계하려는 경우 보고서 생성을 중단한다.

| 구분 | 실제 상태 |
| --- | ---: |
| 계획된 앱 결과 | 360 |
| 화면은 있지만 채점 응답이 없는 자리 | 1,428 |
| 화면 자체가 없는 채점 자리 | 12 |
| 기준판과 후보판의 화면이 모두 있는 비교 쌍 | 177 |
| 후보판 화면만 있는 비교 쌍 | 3 |
| 정식 통과로 확인된 앱 결과 | 0/360 |
| 개선·회귀를 판정할 수 있는 비교 쌍 | 0/180 |

합성 응답으로 누락 4개, 실행 실패 1개, 형식 오류 1개를 각각 집계했다. 앱 결과 세 건에서 판정 이견을 보존하고, 다른 응답 세 개가 빠진 경우에도 한 응답의 중대 오류 표시를 남겼다. 과제 형식의 불확실성도 별도로 보류했다. 합성 응답에서 네 판정이 모두 일치한 경우도 정식 통과로 집계하지 않았다. 원본 합성 채점과 요약의 지문을 함께 보관했다.

Node 22와 24에서 새 집계 검사 각각 3개, 기존 점수 집계 검사 20개, 변경 스크립트 ESLint가 통과했다. 과거 화면 채점 검사 한 파일은 현재 제품의 판정 응답 규격과 설명 검증 코드 지문이 과거 고정 기준과 달라 로딩 단계에서 중단됐다. 당시 기준과 점수는 보존하며, 현재 화면의 실제 채점 자격을 부여하지 않는다.

정식 기준 답안 채택 0/60, 실제 앱 평가 생성 0/360, 실제 교차 채점 0/1,440이다. 이번 단계의 실제 모델 호출은 0회다.
