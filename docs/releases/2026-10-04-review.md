- 운영/main 차이 114개 경로가 분류 JSON과 정확히 일치하며 중복·누락은 없다. 원래 운영 브랜치와 평가 자료는 보존했다. 분류 결과의 실험 95개와 별도 안전 검증 2개 등을 이번 카드 변경에 넣지 않았다.
- EN_Card 정식 exporter로 만든 UI129개·서버 릴레이2개와 두 명세를 운영 `c65b66d`의 바이트/해시와 대조했다. 프록시는 기존 운영의 trial POST와 같다.
- main의 강화된 `card-automation.test.mjs`, `braces-guard.test.mjs`, 카드 QA fixture·manifest 4개 파일은 변경하지 않았다. 카드 브라우저 검사는 새 `#/automation` 화면에 맞췄다.
- Site ID·의존성·잠금 파일은 main과 동일하다. DB·마이그레이션·Cron·Secret·예약 변경, 운영 재게시, 실제 AI·카카오 호출은 없다.

## /review

스코프 검사: 카드 변경의 GitHub 반영 준비와 공통 관리 문서에 한정했다. 구조적 검토와 테스트·유지보수·보안/API·성능·디자인 전문 영역, 별도 문맥의 adversarial 검토에서 잔여 지적은 0이다. 모든 완료된 검토는 Codex 에이전트이며 다른 모델 간 교차 검토로 표시하지 않는다. 독립 adversarial 검토에서는 테스트·fixture를 SUMMARY 모드로만 읽었고, 테스트 전문 검토와 주 검토는 실제 테스트를 읽었다.

별도 Codex CLI 0.132.0은 현재 선택 모델에 더 최신 클라이언트가 필요하다는 HTTP400으로 실행하지 못했다. CLI/모델을 변경하거나 이 실패를 통과로 집계하지 않았다. 검토가 지적을 찾지 못했다는 사실은 미래 오류가 없다는 보장이 아니다.
