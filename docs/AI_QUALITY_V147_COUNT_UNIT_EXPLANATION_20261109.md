# T8.2·T37.2 수량 단위 교정의 이유 표시

저장된 실제 모델 응답의 `Two luggage block aisle.`은 `Two pieces of luggage block the aisle.`로 교정됐지만, 화면에는 바뀐 표현을 비교하라는 안내만 나왔다. 앱은 수량 단위가 정확히 추가된 교정을 이미 확인하고 있으므로 그 확인 결과를 설명에도 사용한다. 예를 들어 `luggage`의 개수는 `piece of`나 `item of`로 나타내고, 두 개를 셀 때는 단위를 복수형으로 쓴다고 안내한다. [British Council의 불가산 명사](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/uncount-nouns)

한 개의 짐, 여러 개의 장비, 목적지가 붙은 문장에도 같은 설명을 확인했다. 개수·시제·목적지·대상을 바꾸거나 인용문을 고치는 대조군에는 이 설명이 붙지 않는다. 수량 표현의 이유만 검증하며, 나머지 문장 편집에 관한 규칙은 기존 안내 범위를 따른다.

보존된 실제 모델 응답 세 개를 Chromium과 WebKit에서 재생했다. 화면 여섯 건에서 원문·판정·교정문·저장과 재조회를 대조했다. 두 화면의 수량 표현 설명만 달라졌으며 `avoid` 사례는 기존 비교 안내가 표시됐다. 새 AI 호출은 0회다.

기존 예비 후보의 합성 응답 180건도 현재 해석기로 재생해 판정·교정문·설명이 일치함을 확인했다. 전체 단위 검사 899개와 타입 검사·빌드·린트가 통과했다. 린트의 기존 경고는 15개다. 첫 전체 검사에서 동결 회귀 테스트가 현재 설명 모듈을 읽어 실패했다. 당시 커밋의 설명 모듈과 지문을 동결 자료에 추가한 뒤 전체를 다시 통과했다.
