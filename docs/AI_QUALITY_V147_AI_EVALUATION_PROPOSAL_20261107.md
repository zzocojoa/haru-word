# AI 전용 실제 품질 평가 설계 제안 · 2026-11-07

상태: **검토안·미승인**. T34와 세부4개는 review다. 사람 검토자를 구하지 않는다. 실제 AI 호출/키 접근/새 과금 승인·사용0, 출시·운영 보류다. 이 문서는 사람이 있다는 가정과 단일 채점 호출 수를 쓴 phase12 초안을 현재 AI 전용 방식으로 구체화한다. 원본 JSON은 `.taskmaster/docs/ai-quality-v147-ai-only-evaluation-proposal.json`이다. 옛 초안·닫힌 원장·점수·실패 이력은 보존한다.

## 판단할 수 있는 것과 없는 것

고정한 합성 오류 가족에서 정해진 AI 기준을 만족했는지 판단한다. 사람이 검증한 영어 정답률·실제 학습 효과·서비스 전체 오류율을 입증했다고 표현하지 않는다. 같은 공급자의 다른 AI도 공통 오판을 할 수 있다. AI 합의는 근거 수준을 표시하며, 통계 신뢰구간도 그 AI 판정 결과에 관한 값이다. 위험 한도·주장 범위의 사용자 선택은 아직 없다.

## 제안 실행 순서

1. 후보/정책을 동결한 뒤 새60가족의 입력·허용 답안·근거·노출을 작성한다. 참조 작성1+다른두모델 검토2, 최대180회인 별도 준비 단계다. 실패를 남기고 반복 작성으로 좋은 참조만 고르지 않는다. 최종 작성 계약·본문은 아직 미동결이다.
2. 별도 예비 평가에서 공개 보정12증인×3모델×2순서=72회로 채점기부터 확인한다. 현재 실행기 기준은 judge/순서별11/12 이상 일치·중대 오류 누락0이다. 실제 AI가 이 기준을 충족했는지는 미측정이다. 순서/장황함/자기선호/입력 속 지시문 통제의 실제 효과도 검증해야 한다.
3. 예비60가족×기준/후보×3모델×1반복=생성360회, 각출력에 다른두모델×2순서=검토1440회다. 보정 포함1872회이며 준비180과 원장·승인을 합치지 않는다. 예비 결과만으로 출시하거나 모집단 위험·개선을 확정하지 않는다. 채점 입력순서2개는 생성2반복이 아니다. r1 예비에서 생성 반복 안정성은 미측정이며 확인 r2에서 별도로 확인한다.
4. T35에서 예비 자료를 설계용으로만 사용해 최소 효과·확인 표본·정밀도/검정력과 새 미공개 가족을 사전 등록한다. 확인 평가 결과를 본 뒤 표본을 늘리거나 기준을 낮추지 않는다. T36/37/40 및 운영·1일/7일 단계는 계속 남는다.

## 표본과 범위

예비는 단어/문법×정상/교정필요/문맥부족의6층에10가족씩 둔다. 문법은15수업을 각각 두 조건으로 배정해30가족을 만든다. 따라서 모든 수업이 포함되지만 **각수업의 세 조건을 전부 검사하는 것은 아니다**. 각층에서 길이4짧음/4보통/2지원경계, 복잡도5단순/5복합을 배분한다. 기존 문장2000자·상황500자 범위를 줄이지 않는다. CEFR 인증이나 수업별 위험 보장은 하지 않는다.

가족은 문법 틀과 행위자·시간·수량·문맥 관계의 구조로 구분한다. 단어/이름 치환, 표면적 재표현과 반복 출력은 독립 가족 수에 더하지 않는다. 프로젝트 개발·예비·확인 노출을 따로 기록하고 확인 가족을 새로 만든다. AI 사전학습에서 절대 본 적 없는 문장이라는 주장은 불가능하다. 독립·대표 추출 분포의 타당성은 아직 확인되지 않았고, 사용자 동의가 이를 증명하지 않는다.

## 결과와 보류 규칙 제안

- 모델·유형별로 목표, 문법, 의미 보존 교정, 설명, 보류의5차원을 본다. 출력마다4개 판정을 보존하고 하나라도 불일치·불확실·누락이면 보류한다. 다수결·유리한 재시도는 없다.
- 관측 중대 오류0·필수 정상 오거절0·근거 없는 단정적 교육 규칙0·예정 셀 미측정0을 별도 관문으로 제안한다. 통신/앱 보호 거절/미실행을 영어 오답으로 꾸미거나 분모에서 빼지 않는다.
- 공급자 원문과 앱 표시 결과를 따로 남긴다. 앱이 강제 보류한 것을 모델의 영어 오답이라고 집계하지 않는다. 원문에 별도 의미 채점이 필요하면 새 슬롯·비용 설계를 먼저 한다.
- 단순 비악화는 개선이 아니다. 확인 전에 개선 대상 가족·최소 효과를 고정하고 paired gain/loss의 하한을 요구한다. 현재 최소 효과와 충분한 검정력은 미확정이다.

## 표본 수·호출 수의 민감도

아래5%/1%/0.5%는 **AI 판정 중대 사건**의 조건부 상한 예시다. 전체95%·고정114개 단측 bound, 각층 iid 가족·모든 셀 측정을 가정한다. 중대 사건0일 때 필요한 표본이며 다른 오류·paired 효과의 검정력을 보장하지 않는다. 현재 어떤 안도 선택·승인되지 않았다. 114개는 보수적 기존 방법이며 동등한 요구를 충족하는 더 효율적인 사전 설계는 별도 검토할 수 있다.

## 공식 가격과 아직 확정하지 않은 비용

2026-11-07 확인한 Standard·짧은문맥(입력272K이하)·100만토큰당 세전 USD다. 계정별 실제 이용 가능성·청구서는 확인하지 않았다.

| 모델 | 일반입력 | 출력 | 30분캐시저장 | 12시간캐시저장 |
| --- | ---: | ---: | ---: | ---: |
| gpt-6.1-sol | $2.00 | $10.00 | $2.50 | $5.00 |
| gpt-6.1-terra | $1.00 | $5.00 | $1.25 | $2.50 |
| gpt-6-astra | $10.00 | $50.00 | $12.50 | $25.00 |

캐시 저장 가격은 일반 입력에 또 더하는 추가 요금이 아니라 해당 토큰의 대체 요율이다. 기본30분은1.25배,12시간은2.5배다. 비용 민감도에서는 캐시 적중 할인을 기대하지 않고 입력2.5배·출력4096토큰을 가정했다. 숨겨진 reasoning은 출력 합계에 포함하므로 중복 가산하지 않는다. 현재 제품 생성4096토큰 상한을 임의로 줄이지 않는다.

예를 들어 **모든 슬롯이 입력8192·출력4096 상한을 쓴다는 가정**에서 예비2052회의 계산값은 세전US$364.216320이다. 이는 실제 본문의 입력 상한을 검증한 견적도, 예상 청구액도, 결제 승인 요청도 아니다. 상한에 못 미치는 실제 사용은 이 값과 다를 수 있고, 실제 본문이 가정을 넘으면 이 계산을 사용할 수 없다. 보조 역할의 출력 한도도 최종 계약·본문·검증 없이 낮추지 않는다.

T24에서 준비/실제 생성/부모 결과를 포함한 파생 검토 본문의 토큰 상한과 옵션을 확정한 뒤 현재 단가·캐시·불명 비용을 결합해 별도 단계별 금액을 제안해야 한다. 지금 승인된 금액은US$0다. 이번 숫자를 실제 호출 상한으로 삼거나 옛US$5/US$165/닫힌 잔액을 재사용하지 않는다.
