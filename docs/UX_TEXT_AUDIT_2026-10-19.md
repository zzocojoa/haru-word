# 하루단어 UI 텍스트 전수 검사·개선안

검사일: **2026-10-19 KST** · 기준: **게시 v139** · 작성 당시 상태: **문서 제안, UI 미반영**

후속 로컬 반영과 검증 상태는 [UI 구현 기록](UX_TEXT_IMPLEMENTATION_2026-10-19.md)과 [계획 대조 검토](UX_TEXT_PLAN_REVIEW_2026-10-19.md)를 따른다. UI-0043 버튼 이름 연동과 UI-0514 결과 불확실성 보완 이유는 후자에 기록한다. 아래 원문 목록·판단은 감사 당시 근거로 보존하며 운영 게시 완료를 뜻하지 않는다.

후속 전체 화면·실제 호출 분기의 로컬 재검증은 [광역 로직 검토](UX_TEXT_WIDE_REVIEW_2026-10-19.md)에 완료 결과를 기록했다. 이전 선택 검사와 최종 전체 기능·프로필·성능 결과를 구분하며, 원래 감사 문서의 근거와 별도 실기기·사용자 평가 한계를 보존한다.

권고의 핵심은 **학습 행동을 안내하는 한 문장, 의미가 분명한 버튼, 필요한 상태 안내를 남기는 것**이다. 정답 공개 전의 단서·예문 노출은 제한하고, 학습자가 기록을 잃거나 AI 의견을 정답으로 오해하지 않도록 하는 문구는 보호한다. 문구 수를 일률적으로 줄이지 않는다.

## 1. 검사 기준과 확인 범위

Sites 읽기 전용 조회에서 사이트가 active이고 최신 버전이 139임을 확인했다. 해당 버전의 소스 SHA는 `effc203cb09f9a6ed47b81f9bec19e00d21fba4c`이며, [v139 소스·게시 정보를 보존한 통합 기록](releases/2026-10-18-en-card-retirement-integration.json)의 값과 일치한다. 원래 종료 결과 JSON은 기본 폴더의 로컬 자료이므로 이 체크아웃에도 있는 통합 기록으로 링크를 연결했다. 검사 원본은 기본 폴더 아래 `work/en-card-removal-20261018/`이다. 기본 체크아웃은 이전 학습 코드가 섞여 있어 원문 기준으로 사용하지 않았다. 기존 변경 파일은 보존했다.

운영 환경 revision 72에서 `word_image_pilot_enabled`, `grammar_enabled`, 문법 v2·v3·v4 생성 플래그가 모두 true임을 확인했다. v4 신규 수업에는 별도 `grammarV4Ready()` 조건도 있으므로, 플래그만으로 모든 계정에 v4가 열린다고 단정하지 않는다. 기존 v1~v4 기록의 표시 분기를 함께 검사했다.

**검사 방법은 게시 소스의 정적 전수 조사다.** JSX 본문, 버튼·레이블·플레이스홀더, 접근성 이름, 조건별 안내, 클라이언트·서버 오류, 상수, 지연 로딩, JSON 교재와 합성된 문법 교재를 추적했다. 개인 계정의 학습 문장·답안·백업을 수집하지 않았다. 이번에 브라우저 화면 전수 재현, 실기기·VoiceOver 검사, 언어 정확도 교열을 수행한 것은 아니다. 화면 배치·동시 노출로 인한 부담에 대한 판단은 코드 구조에 근거한 UX 가설이며 사용자 실험 결과가 아니다.

별도 회원가입·환영 튜토리얼·알림 설정·연속 학습 보상·회원 프로필은 현재 앱에서 확인되지 않았다. 없는 화면을 만들어 검사한 것으로 적지 않았다. ChatGPT가 제공하는 외부 로그인 화면, 사전·출처 외부 페이지는 앱 소유 문구가 아니므로 링크 이름만 포함했다. 종료한 EN_Card와 `/cards` 리다이렉트는 현행 학습 화면에서 제외했다.

## 2. 제거·유지·간소화 기준

| 기준 | 판단·적용 규칙 | 남겨야 하는 예외와 예시 |
| --- | --- | --- |
| C1 중복 줄이기 | 같은 화면에서 동일 행동·상태를 제목, 본문, 플레이스홀더가 반복하면 하나로 합친다. 구현 원리·세부 배정 수치는 도움말로 옮긴다. | ‘저장 중’과 ‘저장 실패’는 다른 상태다. 모달로 분리돼 단독 진입하는 안내는 중복으로 삭제하지 않는다. |
| C2 인출 보호 | 답하기 전에는 질문과 응답 방식만 보여 준다. 뜻·철자·정답 예문·힌트는 명시적 요청 또는 제출 뒤에만 공개한다. | 접근성 대체 텍스트를 없애지 않는다. 문제의 그림을 설명하되 목표 영어 단어를 정답처럼 먼저 읽지 않는다. 도움 사용·첫 답 기록을 보존한다. |
| C3 행동·용어 명확화 | 버튼은 ‘대상+행동’, 상태는 사실로 쓴다. 동일 기능의 이름을 화면·모바일·접근성 이름에서 맞춘다. | 짧아져도 모호하면 바꾸지 않는다. ‘변경 버리고 닫기’를 ‘확인’으로 줄이지 않는다. |
| C4 기록·복구 보호 | 저장 성공, 저장 시도, 화면 임시 보관, 결과 미확인을 구분한다. 오류는 일어난 일과 다음 행동을 함께 알린다. | 초안 손실, 전체 교체, 복원 가능 여부, 한도, 응답 유실 시 재조회, 취소 경고는 접지 않는다. ‘현재 입력 백업 → 최신 기록’ 순서를 유지한다. |
| C5 평가 오해 방지 | 친숙도·회상 성공·문장 자기평가·수업 완료·오늘 목표를 각각 표현한다. 미확인을 실패로 바꾸지 않는다. | ‘수업을 마쳤어요’는 ‘완벽히 익혔어요’가 아니다. AI의 ‘수정 제안 없음’은 ‘정답’이 아니다. 성적 enum·분모·과거 기록은 변경하지 않는다. |

| C8 접근성 유지 | 레이블·진행률 이름·상태 알림·이미지 대체 텍스트·닫기 이름을 보존한다. | 시각적으로 숨긴 문구도 UI 텍스트다. 플레이스홀더만 남기거나 정답을 aria-label에 먼저 넣지 않는다. |
| C9 출처 유지 | 공식 목록, 앱 작성 예문, 사전 참고 풀이, AI 의견을 구분한다. 기여자·라이선스·원문 링크는 보존한다. | 출처 설명은 줄여도 법정 표시나 기여자 표기를 삭제하지 않는다. Oxford 공식 서비스처럼 표현하지 않는다. |

판정의 **제거**는 해당 노출 위치의 삭제이며 저장 데이터·기능 삭제가 아니다. **간소화**에는 문장 축약, 쉬운 말로 교체, 중복 통합, 필요한 도움말로 이동이 포함된다. **유지**는 기능과 학습 목적에 필요한 정보라는 뜻이며 모든 문장의 언어 정확성을 인증한다는 뜻은 아니다. 글자 수 목표나 삭제율 목표를 적용하지 않는다.

근거: 제한된 인지 처리 자원을 학습에 쓰도록 돕는다는 방향은 [Sweller의 인지 부하 연구](https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog1202_4)를 참고했다. 외국어 어휘의 반복 인출과 학습자의 성과 예측을 구분할 필요는 [Karpicke·Roediger의 인출 학습 연구](https://doi.org/10.1126/science.1152408)를 참고했다. 개별 한국어 수정안은 이 앱의 흐름을 검토해 내린 편집 판단이며 해당 논문이 특정 문구의 효과를 검증한 것은 아니다. 레이블·입력 지시·오류 해결 정보를 남기는 기준은 [W3C 폼 지시](https://www.w3.org/WAI/tutorials/forms/instructions/)와 [접근성 초기 점검](https://www.w3.org/WAI/test-evaluate/preliminary/)을 참고했다.

## 3. 적용 우선순위와 공통 합의

| 우선순위 | 먼저 다룰 문제 | 완료 조건 |
| --- | --- | --- |
| P0 | 입력 손실·복원 교체·미확정 결과의 안내 보호 | 손실 대상·안전 백업·교체 동의가 행동 직전에 보이고, 응답 유실을 성공/실패로 단정하지 않는다. |
| P1 | 회상 정답 공개, 평가 용어, 저장 상태, AI 권한·설정 지시, 접근성 | 도움 사용과 첫 답이 보존되고, 학습자가 저장·채점·AI 상태를 구별할 수 있다. |
| P2 | 중복·제목·도움말·버튼 정리 | 같은 행동을 같은 이름으로 부르며 학습 중 읽어야 할 안내가 줄어든다. |

표시 용어는 `미측정 → 아직 확인 안 함`, `독립 성공 → 도움 없이 성공`, `기록 완료 → 학습 기록함`, `회차 종료 → 회차 마침`, `오늘 종료 · 저장 → 저장하고 나가기`로 통일한다. **데이터 키·API enum·과거 CSV 열 이름·백업 형식은 바꾸지 않는다.** 숫자만 단독으로 표시하지 말고 목표·기록·비율의 단위를 남긴다. ‘월말 쓰기’는 영어 단어 쓰기와 선택 문장 쓰기를 분명하게 안내하며 주간·월말 기능을 합치지 않는다.

| 기록 경계 | 회상·친숙도·문장·문법·오늘 목표의 결과가 서로 바뀌지 않음 | 표시 라벨만 변경하고 enum·분모·기존 백업·CSV와 과거 결과를 비교. |
| AI 고지 | 요청 전에 전송·주의사항, 결과에 참고 의견·제공사, 실패에 가능한 행동이 보임 | 두 AI 진입·기록 재열기·Attribution 단독 사용을 확인. 실서비스 AI 호출 없이 fixture 사용. |
| 복원 보호 | 사전 백업·전체 교체·문법 진도 예외·한도·명시 동의가 남음 | 작은/큰 백업, 구형 백업, 재개, 취소, 결과 미확인 사례. |
| 접근성 | 한국어 닫기 이름·입력 label·진행 상태가 유지되고 불필요한 반복 낭독이 없음 | 키보드·스크린리더·320/390px·텍스트 200% 확인. 실제 iPhone 결과는 에뮬레이션과 구분. |

사용자 평가에서는 문구 삭제율보다 **다음 행동을 이해하는지, 도움과 독립 응답을 구별하는지, 저장 실패에서 입력을 지킬 수 있는지**를 확인한다. 학습 시작·회상·문장 작성·복원에서 성인 초급 학습자의 행동을 관찰하고, 문장 길이 감소만으로 학습 효과 향상을 선언하지 않는다.

이번 작업은 로컬 문서 작성으로 위험도 낮음. 런타임·저장·API·DB·마이그레이션·AI 정책·관측 이벤트 변경과 게시가 없다. 문서 철회는 신규 감사 문서만 제거하면 되며 기존 작업 파일은 되돌리지 않는다. 실제 반영 시에는 기존 사이트의 소스 동기화·검증·게시 절차와 기록 보호를 따른다.
