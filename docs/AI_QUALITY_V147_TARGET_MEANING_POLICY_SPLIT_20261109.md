# T34.4 영어 판단과 앱 규칙 분리

v6 공개 통제에서 영어 어휘 사용을 평가하는 지시에 앱의 메시지 충분성 검사가 들어갔다. 기존 평가 계약은 영어 판단과 관측 가능한 앱 규칙을 별도로 기록한다. v7 후보는 이 계약에 맞춰 영어 판단 지시에서 앱의 생성 지시를 걷어내고, 출처 해시는 보존한다. 앱 규칙은 기존 호출자 측 `policyCompliance` 검사에서 계속 계산한다.

| 공개 사례 | 영어 판단에서 보는 항목 | 앱 규칙 검사에서 보는 항목 |
| --- | --- | --- |
| MC08 `Music` | 명사의 뜻과 품사, 제안한 명령문, 모르는 의도를 단정했는지 각각 평가 | 기본 문장 쓰기 모드에서 두 판단을 보류했는지, 교정문을 비웠는지, 확인 질문을 표시했는지 |
| MC05 `She go home.` | 단어 `go`의 뜻 사용과 주어·동사의 일치를 별도로 평가 | 원문 유지 등 응답 상태의 관측 가능한 조건을 검사 |

두 사례의 고정 입력과 합성 응답으로 분리를 확인했다. MC08에서는 어휘 판단 `pass`와 앱 규칙 `fail`, 교정·보류 `fail`이 함께 남는다. MC05에서는 앱 규칙 `pass`와 문법 `fail`, 잘못된 문법을 승인한 중대 표시가 함께 남는다. MC02의 시간 문맥이 불확실할 때 적용하는 교정 기준과 나머지 판단축은 v6의 것을 사용한다.

기존 84개 요청을 읽어 새 판단 지시, 응답 형식 이름, 기준 해시 세 곳만 바뀌는지 대조했다. 버전이 다르거나 지시를 변조한 응답 처리와 서로 모순되는 중대 플래그를 차단했다. Node 22·24 각 3/3, ESLint 2파일 모두 종료 코드 0이다. 이번 추가 응답·입력 계산·키 읽기는 각각 0회다.

v6 실제 통제 결과 **66/72, 기준 미달**과 이전 v5 **71/72**는 당시 기록으로 보존한다. v7의 실제 모델 판정과 독립 평가자 자격은 미측정이다. Task Master 34.2·34.3은 검토 중이며 34.4는 진행 중이다. 유형별 최소 770개 독립 가족, 관측 중대 오류 0건, AI 판정상 1% 위험 상한 기준을 유지한다. 최종 표본·효과·반복과 사전 판정·비용 명세 확정 뒤 T35로 이동한다. T36과 출시는 보류다.
