원래 100문항 평가는 이전 후보에서 91쌍 통과·8이견·앱 거절1이었다. 새 후보의3사례/교차6판정과 T38 운영2사례×3모델의 표시·저장/새로고침6/6을 확인했지만, 이를 새 후보100문항 통과율이나 실제 영어 정답률로 합치지 않는다. 1% 위험 상한·학습효과는 미입증이며 사용자가 이번 기능 게시에서 필수 조건을 변경했다. 현재 Task Master는30/40·103/133 완료이고 T39의11월14일·20일 점검은 미실시다.

이번 정리 과정에서 전체 테스트의 README 복구 링크 누락1건을 발견해 링크를 복원했다. 최종 Node22·24 단위 각각924/924, Node24 문법자료·타입·린트(기존15경고)·빌드는 exit0이다. 대시보드 재생성과 데이터 검사2/2도 통과했다. 원본 v148의918개 검사와 이번 최신 호환성6개 추가 검사를 구분한다. 게시된 v148 제품 동작 코드는 바꾸지 않았으며 현재 문서와 회귀 테스트만 추가 보완했다.

독립 검토는 제품 보안/호환·테스트 경계·계획/예산 기록을 확인했다. 차단할 P1은 발견하지 못했다. 후속 확인 후보로 `app/use-feedback-context.ts`가 기존 `ai-context-v4`의 보조 문맥 초안을 새 `intended_korean`으로 해석할 가능성이 제기됐다. 실제 오교정은 재현하지 않았으며 이번 소스와 유료 검증을 변경하지 않고 다음 초안 마이그레이션 점검에 남긴다. 이 항목을 해결 완료나 새로운 운영 사고로 기록하지 않는다.

추가 US$35 내 조건부 잔액US$3.955111·이번 운영 점검의 보수 차감US$0.904946을 유지한다. 모델 실제 토큰·최종 청구액과 계산 API 공식 단가는 미확인이다. 기존 US$5는 닫힌 상태다. 이번 PR 정리에 새 유료 API·원장 초기화·운영 학습 쓰기는 없다.

저장소에는 제품 코드·회귀 테스트·재사용 평가 도구·계획과 승인/정산 기록을 포함한다. `outputs` 원시 응답/로그/스크린샷과 동결 `work` 사본, `.env`, `.sites-runtime`, `.wrangler`는 Git에 넣지 않고 원래 위치에 보존한다. 로컬 원시 근거에 의존하는 역사적 평가 도구는 일반 clone만으로 재실행할 수 없다. 평가 기록의 당시 절대 경로·지문·점수는 이식성을 이유로 다시 쓰지 않는다.
