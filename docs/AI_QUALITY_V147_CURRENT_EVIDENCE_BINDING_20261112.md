연결된 24개는 해당 사전 기준에 모두 일치한다. **현재 전체 보정 합격을 뜻하지 않는다.** 과거 전체 결과 71/72와 당시 MC12 이견은 그대로 보존한다. 현재 화면 또는 요청이 바뀌면 그 요청의 근거는 다시 분리해야 한다.

평가 도구에 `bindCurrentMc12EvidenceV1`을 추가했다. 응답 원문·계산 영수증·모델·제시 순서·요청 지문·정산된 실행 범위를 대조한다. 저장된 판정이 실제 응답과 다르거나 다른 문항/순서의 응답을 넣으면 거절한다. 현재 설명이 바뀐 경우에는 과거 판정과 입력량을 넘기지 않고 새 검토로 분류한다. 전송·보정 합격·예산 사용 권한을 부여하지 않는다.

[Cambridge 직접 동사 보어 규칙](https://dictionary.cambridge.org/grammar/british-grammar/word-patterns-suggest)은 이번 직접 가져오기에서 403이었으며 공식 페이지의 검색 결과로 해당 규칙만 재확인했다. 실제 두 검토 요청에 제공했던 출처 요약·응답은 바꾸지 않았다. 참조 검토 역할의 통제 검사와 노출·가족 검토가 완료되지 않아 **정식 참조 자격은 0/60**으로 유지한다.
