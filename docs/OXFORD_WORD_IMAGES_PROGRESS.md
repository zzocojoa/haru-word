## 저장과 검증 근거

이미지 원본은 아래 **주 작업 폴더**의 Git 제외 경로에 저장한다. 현재 worktree에는 연결 목록·문서·관리 스크립트를 둔다. 기본 생성 위치의 원본도 유지하며 기존 파일을 덮어쓰지 않는다.

```text
C:/Users/user/Documents/ChatGPT/하루단어/outputs/oxford-images/
  14552b36a1653f2aed9e14b09c833c0031b1204de5e0bdfc6902543a05d4ba6e/
    <항목-ID>-<용법-slug>-v1.png
    <항목-ID>-<용법-slug>-v2.png   # 수정한 경우만
    qa/<항목-ID>-v<시도>-320.png
```

- 3,809개 ID·기본 뜻·품사·교재 지문을 원본 자료와 대조했다. 교재 SHA256은 계획의 기준 값과 같다.
- 선택 파일의 SHA256·바이트 수·PNG 크기·세로 비율·실제 프롬프트 해시를 확인했다. 모든 현재 이미지는 1,086 × 1,448 PNG다.
- 로컬 Chromium에서 PNG를 디코딩하고 320px 화면의 288px 이미지로 표시했다. 원본과 실제 축소 스크린샷을 각각 열어 검토했다. 검토용 단어·메모는 이미지 밖에 표시한다.
- 7개 재개 보호 검사를 격리된 `work/` 사본에서 통과했다: 완료 항목 중복 시작 거부, 순서 위반 거부, 두 번째 수정 거부, 체크포인트 누락 시 전체 호출 수 복구, 미해결 호출 보존·신규 호출 차단, 메타데이터 저널 재생, 원장 불일치 거부. 검사 자체의 이미지·API 호출은 0회다.
- 제작 근거는 Git 제외 `work/oxford-images-progress.json`, `work/oxford-images-verification-*.json`, 항목별 `qa/` 스크린샷에 보존한다. `work/oxford-images-pilot-progress.json`은 과거 시범 20개 기록이며 현재 원장으로 사용하지 않는다.

실제 iPhone, 독립 학습자의 뜻 추론·학습 효과, 이미지 호스팅·전송 성능은 미검증이다. 앱 코드를 변경하지 않아 앱 전체 테스트·타입·린트·빌드는 실행하지 않았다. 관리 스크립트의 Node 구문 검사·재개 보호 검사와 이미지 검증을 수행했다. 운영 사이트·학습 기록·DB·백업·API·예약은 변경하지 않았다.

## 다음 묶음과 재개 절차

다음 미제작 항목은 `airport`, `all` 한정사·대명사, `also`, `always`, `amazing`, `and`, `angry`, `animal`, `another`다. 철자가 같아도 ID·품사·기본 뜻별로 장면을 구분한다.

```powershell
node scripts/oxford-images.cjs status
node scripts/check-oxford-image-resume.cjs
node scripts/verify-oxford-images.cjs <검사할-항목-ID들>
```

1. 현재 원장과 연결 목록·교재 해시를 대조한다. `current`가 있으면 기존 도구 결과·파일부터 확인하고 새 호출을 시작하지 않는다. 원장 파일이 없으면 연결 목록의 모든 시도와 미해결 상태에서 복구하며 시범 20회로 초기화하지 않는다.
2. 다음 교재 항목의 뜻·표현·예문을 읽고 별도 장면 JSON을 `work/`에 저장한다. `prepare <장면-JSON>`은 정적 장면만 기록한다.
3. 호출 준비가 된 뒤 `start <항목-ID>`로 시작 슬롯을 기록한다. 출력된 실제 프롬프트와 참고 경로를 **채팅의 내장 image_gen**에 전달한다. 이 스크립트 자체는 이미지를 생성하거나 외부 API를 호출하지 않는다.
4. 결과 파일을 찾으면 `capture <항목-ID> <기본-생성-파일>`로 원본을 복사하고 해시·시도를 저장한다. 결과가 불명확하거나 서비스 오류가 있으면 자동 재시도하지 않는다.
5. 원본을 열어 검사하고 위 verifier로 320px 스크린샷을 만든 뒤 실제로 열어 확인한다. `review <검수-JSON>`에 통과/보류와 결함을 기록한다. 수정은 문제를 특정하여 항목당 한 번만 허용한다.
6. 10개마다 수량·현재 위치·검수·호출 수를 보존한다. 이미지·원장·검수 근거는 Git 제외 파일이므로 다른 컴퓨터에서 재개하려면 원본 폴더도 안전하게 복사하고 모든 해시를 확인해야 한다.

현재 전체 목표는 진행 중이며 이미지 호스팅·앱 화면 반영·병합·운영 배포 완료로 표시하지 않는다.
