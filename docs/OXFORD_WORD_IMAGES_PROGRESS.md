- 추가 048의 최신 10개 검증 보고서는 `work/oxford-images-verification-1791262639925.json`이다. 수정 없이 10회 생성했고 PNG 해시·디코딩·320px 표시를 통과한 뒤 원본과 실제 축소 화면을 모두 열어 검사했다. `know`는 성인 두 명 중 한 명이 실제 열쇠를 들고 다른 한 명이 사과/열쇠/배 카드 세 개의 가운데 맞는 열쇠 카드를 가리키는 관계를 두 크기에서 확인했다. 카드 위치는 기획의 나열과 달라도 대응이 유지된다. `land`는 넓은 풀 지면/노출 흙·굽은 흙길·낮은 언덕/수목을 두 크기에서 구분했다. 실제 능력/Tom의 성격·실제 지리 위치/토지 소유나 매매 판단을 인증하지 않는다.

- `language`는 성인 두 명의 말하는 열린 입/설명 손·주의하며 듣는 상대와 원탁의 빈 펼친 책 한 권/이름 없는 지구본 한 개를 원본과 320px에서 구분했다. 지구본의 대륙형 실루엣은 소통 맥락의 보조물이며 실제 지도 정확성·특정 언어/국적·민족/능력을 인증하지 않는다. `large`는 온전히 선 성인 한 명보다 높고 넓은 바위 한 개·같은 지면을 두 크기에서 확인했다. 실제 비율을 정확히 두 배라고 단정하지 않는다. `last1 (final)`은 버스 세 대를 두 크기에서 직접 세고 왼쪽을 향한 줄의 오른쪽 마지막 버스만 황토색·앞 두 대 중립색/뒤 빈 도로를 확인했다. 작성한 마지막 위치의 연상이며 실제 당일 막차 운행/탑승·귀가의 증거가 아니다.

- `late` 형용사는 교사 한 명/이미 공부하는 착석 학습자 두 명/문가 새 사람 한 명으로 성인 네 명과 교사의 열린 손/빈 칠판·책·두 책상/공책·연필/보조 가방을 두 크기에서 구분했다. 부사는 성인 네 명 중 차를 마시는 두 명·서서 반기는 주인/문턱을 넘어오는 방문자와 앞발 안쪽·뒷발 바깥쪽/찻잔 두 개·가방 한 개를 확인했다. 두 항목 모두 문짝/경첩/잠금 하드웨어가 없으며 상태와 도착 행동을 구분한다. 일부 얼굴/그립/발·뒤 가구는 가려진다. 실제 시각/일정·개인의 책임/성격·성별/신원·처벌을 인증하지 않는다.

- `later`는 위 읽기/탁자 위 미사용 전화·아래 덮은 책/귀에 댄 전화와 각 장면의 성인/책상/전화/책 한 개씩·보조 화분/의자를 원본과 320px에서 확인했다. 위 전화의 앞/뒤 면을 확정하지 않으며 두 행동의 차이는 유지된다. 작성한 지금→이후 연상으로 실제 약속·동일 날짜/경과 시간·미래 사건 완료를 인증하지 않는다. `laugh` 동사는 성인 한 명의 크게 열린 웃는 입/접힌 눈가·배의 손/느슨한 반대 손을, 명사는 성인 두 명 중 오른쪽 주인의 열린 웃는 입/눈가·환영 손과 왼쪽 방문자의 미소/가방·문틀을 두 크기에서 구분했다. 동사 원본에는 작은 눈물 한 방울이 있으나 축소 화면에서 그 미세 형태나 모든 손가락을 독립 검증했다고 기록하지 않는다. 실제 Tom/개인 감정·소리/의학 상태나 방문자의 실제 지각을 인증하지 않는다.

- 모든 원본의 글자·숫자·로고 부재와 기준 종이/절제된 색채를 검토했다. 물리 사물 그림 카드·열쇠 구멍/톱니·흙/풀·제본/빈 책·지구본 축/대륙형 실루엣·돌 결/단추/버클/봉제/신발끈·차선/차량 창/거울/등/빈 번호판·공책의 희미한 선·전화 모서리·눈물/옷/가방/목재/매트는 문자나 효과음 표식이 아니다. 주요 얼굴/뜻 관계는 보이며 일부 하체/그립/가구 가장자리는 가려지거나 생략된다. 하단 QA 캡션은 원본 밖 검사용 표시다.

## 다음 묶음과 재개 절차

다음 미제작 항목은 `learn`, `leave`, `left` 형용사·부사·명사, `leg`, `lesson`, `let`, `letter`, `library`다. 철자가 같아도 ID·품사·기본 뜻별로 장면을 구분한다.

```powershell
node scripts/oxford-images.cjs status
node scripts/check-oxford-image-resume.cjs
node scripts/verify-oxford-images.cjs <검사할-항목-ID들>
```

1. 현재 원장과 연결 목록·교재 해시를 대조한다. `current`가 있으면 기존 도구 결과·파일부터 확인하고 새 호출을 시작하지 않는다. 원장 파일이 없으면 연결 목록의 모든 시도와 미해결 상태에서 복구하며 시범 20회로 초기화하지 않는다.
2. 다음 교재 항목의 뜻·표현·예문을 읽고 별도 장면 JSON을 `work/`에 저장한다. `prepare <장면-JSON>`은 정적 장면만 기록한다.
3. 호출 준비가 된 뒤 `start <항목-ID>`로 시작 슬롯을 기록한다. 출력된 실제 프롬프트와 참고 경로를 **채팅의 내장 image_gen**에 전달한다. 이 스크립트 자체는 이미지를 생성하거나 외부 API를 호출하지 않는다.
4. 결과 파일을 찾으면 `capture <항목-ID> <기본-생성-파일>`로 원본을 복사하고 해시·시도를 저장한다. 결과가 불명확하거나 서비스 오류가 있으면 자동 재시도하지 않는다.
5. 원본을 열어 검사하고 위 verifier로 320px 스크린샷을 만든 뒤 실제로 열어 확인한다. `review <검수-JSON>`에 통과/보류와 결함을 기록한다. 수정은 문제를 특정하여 항목당 한 번만 허용한다.
6. 10개마다 수량·현재 위치·검수·호출 수를 보존한다. 이미지·원장·검수 근거는 Git 제외 파일이므로 다른 컴퓨터에서 재개하려면 원본 폴더도 안전하게 복사하고 모든 해시를 확인해야 한다.

현재 전체 목표는 진행 중이며 이미지 호스팅·앱 화면 반영·병합·운영 배포 완료로 표시하지 않는다.
