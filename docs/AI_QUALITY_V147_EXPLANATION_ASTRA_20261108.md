# 설명 기준4 · Astra 후속 공개 진단 사전 명세

T34.3(사전등록 판정·중단·예산), T34.4(기준 도전 검토·변경 통제)의 후속이다. 기존 추가 US$35 승인과 기존 키 재사용 승인을 사용한다. 원래 US$5 범위는 사용 상한 4.471863/닫힌 잔여 0.528137로 유지한다. 이 문서는 실행 전 명세이며 실제 결과나 출시 승인을 뜻하지 않는다.

## 고정 비교

phase71의 동결된 54요청 풀에서 Astra 18개만 선택한다. 공개 단어 평가 조건9개 × 배치2개이며, 입력·영어 지시·기준4·출력1024·기대값은 변경하지 않는다. phase72의 Sol/Terra 36판정에 빠진 모델을 보완한다. 전부 개발 공개 조건이며, 반복 판정은 독립 표본18개가 아니다.

기대값과 증거3축의 전부 일치, 요구 중대 플래그 누락0을 제한된 진단 기준으로 사용한다. 불일치가 발생해도 다수결로 기대값을 고치지 않는다. 참인 설명이라도 잘못된 교정이면 보류하며, 거짓 설명만 있는 경우도 보류한다. 의미 반전 외 다른 중대 오류의 충분한 양성 사례, 문법15수업, 미공개 가족, 학습 효과는 이 진단에 포함되지 않는다.

본평가용 출처 검증12문항 레지스트리는 별도 필요하다. 이번 공개54 비교가 모두 일치해도 본평가 자격·전체 영어 정답·출시 자격으로 자동 승격하지 않는다.
