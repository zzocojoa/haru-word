# UI 문구 개선 계획 대조 검토

기준은 PR #47 병합 main `85d95ae51e14b2466d1acbf8a39c2416d2f2e326`이며 작업은 `codex/ux-text-improvements`의 로컬 변경이다. [원래 감사 계획](UX_TEXT_AUDIT_2026-10-19.md), 전체 UI 목록, 학습 콘텐츠 목록과 범위 문서를 실제 코드·회귀 검사·원시 로그에 대조했다. 운영 v139 게시, GitHub CI 실행이나 startup·과거 401 원인 조사는 아니다.

이 문서는 계획 대조 단계의 이력이다. 이후 전체 기능·분기 재검증, WebKit 초점 수정과 당시 실패한 검사의 보완을 완료한 결과는 [광역 로직 검토](UX_TEXT_WIDE_REVIEW_2026-10-19.md)를 따른다. 아래 sentence-feedback-layout의 실패·잔여 작업 표시는 당시 상태이며, 최종 현재 계약 검사 통과와 구분해 보존한다.

## 검토에서 보완한 내용

| 발견 | 보완·검증 |
| --- | --- |
| 문장 AI 전송 고지가 요청 버튼 위에 있고 문법 분기는 `수업 목표을`로 표시됨 | 두 진입 모두 버튼 바로 아래 한 번 표시하고 `수업 목표를`로 수정. 요청 전 전송 항목·Google/Groq·개인정보·무료 API 고지를 실제 화면에서 확인. 조사 오류는 수정 전 단위 검사 실패, 수정 후 통과. |
| 이미지 위치의 최초 조회 실패와 저장 응답 유실이 모두 ‘저장하지 못했다’로 표시됨 | 최초 조회는 불러오기 실패, 이미 표시한 위치는 저장 결과 미확인으로 구분. 저장 재시도 전에 서버부터 확인한다는 안내를 추가. 실제 응답 유실·25초 대기 종료·최초 조회 실패에서 확인하고 GET 선행·쓰기 수·위치/학습 기록 보존도 검사. |
| 복원 차단 안내가 없어진 `여기까지 저장` 버튼을 지시함 | 친숙도 진행 중은 `나중에 이어 하기`, 완료 후는 `저장하고 나가기`, 단어 준비 중은 `학습 홈으로`를 안내. 세 상태의 실제 버튼·복원창 차단·학습 state/revision 불변 확인. |
| 긴 기록의 브라우저 검사가 문장·메모에 한정됨 | 저장한 긴 뜻과 과거 AI 입력·교정 제안·설명도 모바일/데스크톱에서 키보드로 펼쳐 원문 전체·줄바꿈·출처·참고 고지 1회·state/revision 불변 확인. 완료 단어 다시 보기의 긴 뜻도 포함. |

`UI-0514`의 개별 수정안은 계획의 상위 C4 원칙(결과 미확정을 성공/실패로 단정하지 않음)에 맞게 보완했다. `UI-0043`은 원래 유지 행이지만 다른 버튼 이름 변경에 맞춰 연동 수정했다. 원래 감사 표를 덮어쓰지 않는다. 원래 변경 결정 **237개**에 이 유지 행 1개를 추가로 보완했고, 나머지 유지 UI **1,035개**와 유지 AI 코드 **9개**는 그대로다. API enum·데이터·교재·CSV·백업·마이그레이션·바인딩·의존성은 유지한다.

## 검증 결과와 남은 한계

최종 실행 결과·정확한 로그/소스 지문은 [계획 검토 검증 기록](ux-copy-audit-2026-10-19/plan-review.json)에 남긴다. 최초 구현의 [38개 브라우저 결과](ux-copy-audit-2026-10-19/verification.json)는 당시 기록으로 보존하며 이번 재실행으로 바꿔 쓰지 않는다. 그 입력 509파일과 원시 로그 44개 지문을 먼저 확인했다.

이번 추가·수정 범위는 `ux-text`, `feedback-issue`, `backup`, `large-backup`, `image-practice-resume`를 Chromium/WebKit에서 실행해 **10개 모두 종료 0**을 확인했다. 대용량 검사는 18MB 이상·1,825회차/18,250결과의 전송 중단 후 재개, commit 응답 유실 후 1회 반영, 안전 백업·취소·원래 기록 복원, 실제 기록 19.9MB 경계를 포함한다. 합성 계정과 로컬 D1만 사용했다. 최종 단위는 Node22/24 각각 **643/643·실패/취소/skip/todo 0**, 타입·린트·빌드 종료 0이다. 린트 오류 0·기존 경고 15개, 마지막 QA 대기 수정 두 파일의 추가 ESLint도 종료 0이다. 변경되지 않은 교재의 문법 검사는 이번 검토 중 실행한 종료 0 결과를 사용한다. 문서/로그 지문·상대 링크·`git diff --check`도 통과했다.

추가 탐색으로 실행한 `sentence-feedback-layout-qa.cjs`는 **실패**했다. 이 모음은 현재 main에 없는 `.sentence-structure` UI와 ‘분석 없음이면 다시 점검’을 기대한다. `HEAD`의 원래 테스트/`FeedbackDetail` 및 변경되지 않은 `sentenceFeedbackPresentation`을 대조하고 원래/현재 컴포넌트를 렌더링해 기존 불일치를 확인했다. 통과 수에 포함하지 않는다. 이번 검토에서 해당 기능을 다시 구현하거나 기존 테스트 조건을 삭제하지 않았다. 실제 현재 AI 고지·오류·긴 의견·제안 적용은 위 유효한 모음으로 검사했다. 전체 브라우저 manifest가 통과했다는 의미가 아니며, 이 예전 문장 구조 모음의 정리는 별도 잔여 작업이다.

새 QA의 최초 두 실패는 친숙도 시작 저장이 끝나기 전 revision을 비교한 것과 지연 화면 등장 전 count를 읽은 것이었다. 해당 화면/저장 완료를 기다린 뒤 원래 불변·유일성 단언을 유지했다. 앱의 대기 시간을 늘리거나 검사를 삭제하지 않았다. 수정 전 조사·위치 문구의 단위 실패와 모든 QA 실패 시도는 원시 로그에 보존한다.

실제 iPhone/VoiceOver·실서비스 AI/외부 폰트·운영 계정 기록·성인 초급 학습자 사용성 연구는 미검증이다. 접근성 근거는 브라우저 에뮬레이션, DOM/role/label, 키보드·axe·캡처이며 실제 스크린리더 사용자 경험 완료를 뜻하지 않는다. 전체 이미지 장면 설명 작성, 학습 효과·언어학적 정확성 인증도 별도 범위다. startup·기존 401 원인은 미확정이다.

## 범위와 복구

추가 앱 변경은 AI 안내 위치/조사, 이미지 위치 오류, 복원 차단 안내 네 파일에 한정된다. 네트워크 요청·성적 계산·저장/충돌/복원 알고리즘·로그/관측 필드는 바꾸지 않는다. 문구 수정과 가상 계정 검증에 따른 운영 위험은 없으며, 향후 배포의 승인이나 준비 완료를 의미하지 않는다. 새 마이그레이션 0개, 커밋·푸시·PR·배포·설정 변경 없음. 되돌릴 때도 v139의 EN_Card 종료와 학습/위치 데이터를 보존한다.
