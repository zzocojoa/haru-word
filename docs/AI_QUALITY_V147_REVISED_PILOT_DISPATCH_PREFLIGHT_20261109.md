# T24.4·T34.3 개정 예비평가의 전송 전 검사

개정 예비 60문항, 생성 본문 360개와 로컬 채점 본문 1,440개를 전송 전 검사에 연결했다. 본문 지문 외에도 문항과 실제 앱 입력의 연결, 기준판·후보판 입력의 일치, 생성자를 제외한 두 채점 모델과 두 순서를 확인한다. 대체 전 문항, 다른 부모에 붙인 채점, 중복·누락, 계산 본문 변조를 넣으면 검사를 거절한다.

로컬 채점 본문 1,440개는 모두 합성 재현용이다. 실제 예비평가의 채점 본문은 승인된 앱 실행에서 저장·재조회한 결과로 구성해야 한다. 검사는 로컬 근거를 읽어 상태를 보고하며 키나 전송 함수를 받지 않는다.

| 실행 전 확인 사항 | 현재 상태 |
| --- | --- |
| 개정 예비평가의 정확한 범위 승인 | 대기 |
| 정식 참조 채택 | 0/60 |
| 현재 앱 화면으로 채점기 보정 | 대기. 이전 71/72는 이전 화면의 결과 |
| 현재 평가 원장 가용액 | US$1.152100 |
| 한 문항의 개별 교차 채점 예약 하한 | US$1.425728. 현재 가용액보다 US$0.273628 높음 |
| 한 문항의 생성과 채점 동시 예약 하한 | US$2.221456 |

비용은 기존 예약 규칙의 하한이며 실제 청구액과 구분한다. 두 원장 사본과 승인 상태를 대조했으며 새 예약은 없다.

별도로 준비된 출처 재검토 실행기에 개정 예비평가의 지문을 전달한 경우와 자체 지문을 승인 파일 없이 전달한 경우를 확인했다. 두 경우 모두 승인 오류로 중단됐고 키 읽기, 토큰 계산, 모델 호출은 모두 0회였다. 별도 출처 재검토 범위는 승인 대기 상태다. [별도 재검토 범위](AI_QUALITY_V147_SUGGEST_SOURCE_FOLLOWUP_SCOPE_20261109.md)
