# 기본 교정 흐름 우선 실행 — 2026-11-12

사용자 지시에 따라 기존 `ai-quality-v147` 플랜의 실행 우선순위를 수정한다. 40개 상위·133개 세부 작업과 과거 완료·실패·평가·승인·예산 기록은 유지한다. 이 문서는 기본 기능 구현의 순서를 바로잡으며, 미충족 출시 조건을 통과로 바꾸지 않는다.

## 먼저 구현하고 확인할 동작

1. 사용자의 답안·학습 목표·사용자가 제공한 문맥을 OpenAI Responses에 한 번 보낸다.
2. AI가 목표 사용과 원문 문법을 판단하고, 뜻을 보존할 수 있으면 완성된 교정문을 한 번에 돌려준다.
3. 앱은 결과를 표시·저장한다. 새로고침·재조회로 AI를 다시 호출하지 않는다.
4. 완성할 핵심 내용이 빠졌다면 아는 부분의 판단은 유지하고, 필요한 문맥을 안내한다. 없는 사람·행동·사실을 정답 교정처럼 만들어 넣지 않는다. 가정한 완성 예문을 자동 생성하는 정책은 이번 변경에 추가하지 않는다.

`Two luggage block aisle.` → `Two items of luggage block the aisle.`처럼 문법을 고치기 위한 표현 추가를 사실 변경과 혼동하지 않는다. `Every spare gasket in the drawer`는 독립 문장 쓰기에서는 미완성임을 알 수 있지만, 무엇을 말하려는지는 추가 정보가 필요하다. 목표 판단까지 무조건 ‘불확실’로 바꾸지 않는다. 답변·제목·명령으로 명시한 형식은 따로 존중한다.
