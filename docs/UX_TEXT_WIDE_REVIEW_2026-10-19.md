## 실제 로직에서 확인한 수정

### WebKit 단어 편집창 초점 복귀

수정 전 실제 포인터로 bar/favorite/some을 열고 닫으면 Chromium 3/3은 원래 단어 버튼에 초점이 남았다. WebKit 3/3은 **창 → 단어 버튼 → 탭패널**로 초점이 다시 옮겨졌다. 150ms 후 결과와 focusin 순서를 기록했으며 상태/revision은 불변이었다. 단순 대기 추가로도 A1/디자인 검사의 초점 단언이 실패했다.

`WordList.restoreFocus`의 즉시 `.focus()` 뒤에 `NavigationHistory.commit`에서 예약한 두 프레임 후 이력 초점 복원이 실행되는 경합이었다. [단어장](../app/word-library.tsx)은 기존 도움말 창과 같은 `ViewRestoration`의 `destination` 우선순위로 반환 초점을 예약한다. 이력 저장·학습 상태·서버 API를 바꾸지 않는다.

수정 후 같은 실제 클릭 재현은 두 엔진 6/6에서 원래 버튼 초점을 유지했고 페이지 오류 0, 상태/revision 불변이었다. A1~B2 및 design 회귀는 창이 사라진 뒤 **추가 두 프레임에도** 원래 버튼이 초점을 유지하는지 검사한다. 실패/수정 후 원시 근거는 `focus-probe-1792372607760.json`, `focus-probe-1792372838701.json`에 보존했다.

### 검사 코드와 앱 결함의 구분

- 기존 문구를 전제로 한 선택자를 실제 현행 버튼과 맞췄다. 존재하지 않는 버튼을 앱에 되살리지 않았다. CSV는 UI의 새 표현을 기대하지 않고 기존 열/성적 문자열을 검사한다.
- Accordion 애니메이션, 초기 학습 초점, 저장 응답/화면 반영을 기다리지 않은 단언을 실제 준비 상태 뒤로 옮겼다. 타이머 검사는 네이티브 MessageChannel로 React 반영을 마친 뒤 가상 시각을 읽고 이동한다. 타이머 앱 구현은 바꾸지 않았다.
- WebKit clock-continuity의 axe는 닫히는 모달/overlay를 통한 일시적 색상을 읽었다. 닫힌 창과 overlay가 사라진 뒤 복구 화면을 검사하도록 보완했다. 색상 기준과 위반 0개 단언을 유지한 Chromium/WebKit 재실행이 통과했다.
- 기록의 AI 의견 펼침은 실제 Radix Accordion Content의 확장이 끝난 뒤 native summary를 클릭하고 `details.open`과 원문 노출을 함께 검사한다. 안쪽 콘텐츠 div에는 애니메이션이 없어 그 요소만 기다리는 방식은 준비 상태의 증거가 아니었다. sentence-feedback와 purpose 검사의 수정 후 두 엔진 전체 흐름이 통과했다. 과거 실패와 후속 진단은 보존한다.
- sentence-feedback-layout의 이전 검사는 이미 배포된 AI 구조 비노출 정책과 다른 동작을 기대했다. 실제 정책의 비노출/원문 보존, 명시 요청·수정·재시도·저장/재연결, 긴 설명/키보드/반응형을 검사하도록 교체했다. 과거 실패는 삭제하지 않는다.
- 대용량 UTF-8 요청은 서버의 EOF 전 413 응답, 상태 불변과 편집창의 실제 다시 저장을 구분한다. 로컬 proxy의 503/ECONNRESET을 413 성공으로 계산하지 않았다. 거부 업로드 뒤 읽기 readiness를 확인하며 쓰기 자동 재시도와 서버 제한 완화는 없다.
- 백업 자원 검사의 합성 자료가 `grammar: {}`를 생략해 원본 파일 20,000,000바이트가 서버의 최종 상태에서는 20,000,013바이트가 됐다. 실제 413은 한도 보호의 정상 동작이었다. 빈 문법 항목을 자료에 포함하고 파일을 다시 정확히 20,000,000바이트로 맞춰 검사했다. 128MiB·30초 제한, 5ms 표본 간격과 상태 동일성 단언은 유지한 채 통과했다. 서버·복원 한도 코드는 변경하지 않았다.
- main 비교 검사가 과거 `단어 확인` 버튼을 기다려 기준 버전에서 시간 초과했다. 실제 main의 `뜻 보기`와 변경본의 `단어·뜻 보기`를 구분하고, 그림 로드와 카드 활성 상태를 확인하도록 보완했다. 수정 후 36개 비교 표본이 모두 완료됐다. 이 선택자 실패는 과거 startup 시간 초과 원인으로 분류하지 않는다.
