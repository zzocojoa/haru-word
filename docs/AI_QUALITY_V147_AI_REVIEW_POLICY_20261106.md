# AI만으로 진행하는 품질 평가 · 사용자 제약 반영

2026-11-06 사용자 지시: “아직 없고 앞으로도 없으니, AI 가 판단해야함.” 사람 영어 검토자 섭외를 후속 작업의 필수 조건으로 두지 않는다. 이 문서는 향후 검토 방식에 관해 이전 계획의 사람 검토자 요건을 대체한다. 과거 평가·승인·계획·실패 근거는 당시 기록으로 보존한다.

AI 평가는 진행할 수 있다. 사람이 확인한 영어 정확성·실제 학습 효과를 검증했다고 표현할 수는 없다. 다수 AI가 같은 오류에 동의할 수 있으며, 같은 공급자의 다른 모델도 통계적으로 독립인 전문가가 아니다. 이 제한은 평가 결과와 출시 판단에 계속 표시한다.

## 실행 규칙

1. 코드가 확인할 수 있는 형식·데이터 보존·원자성·중복 발송은 코드 검사와 실제 Worker 회귀로 판단한다. 영어 의미·문법·교정·설명·보류는 별도 AI 평가로 판단한다. 두 근거를 한 점수로 섞지 않는다.
2. 답변 생성 모델과 다른 두 모델이 각각 평가한다. 모델·버전·다른 채점자의 점수는 가린다. 별도 요청과 문맥으로 실행하지만, 이를 편향이 독립이라는 증명으로 취급하지 않는다. 신규 호출은 OpenAI Responses만 사용한다.
3. 평가 문장과 허용 답안은 후보/정책 동결 후 만든다. 사전 등록한 문항 역할·출처·허용 대안·불확실성을 기록한다. 같은 AI의 문항 생성과 정답 확신만으로 검증된 정답표를 만들지 않는다. 확인 가능한 문법/사전 근거를 연결하고 출처를 실제 확인한다. 근거가 없는 AI 합의는 `ai-consensus`로 표시한다.
4. 판정 전에 의미 보존·문법·교정·설명·보류의 5차원 기준, 중대 오류, 정상 문장 오거절, 반복·순서 변경 조건을 고정한다. 출력의 길이·표현 순서·모델의 자기 선호·평가 대상 안의 지시문에 대한 통제 검사를 포함한다. 원점수/소수 의견은 보존한다.
5. 채점기가 기존 공개 증인과 잘못된 교정/부정·수량·행위자/목표 누락 통제를 구분하는지 먼저 확인한다. 이는 제한된 증인에 대한 보정이며 인간 판정과의 일치나 모든 영어의 정답성을 입증하지 않는다.
6. 하나라도 중대 오류를 지적하거나 채점자/반복 사이에 불일치·불확실·누락·형식 오류가 있으면 해당 문항은 보류한다. 단순 다수결, 유리한 판정만 선택하기, 합격할 때까지 재시도하지 않는다. 추가 조정이 필요하면 미리 정한 별도 상한/슬롯 안에서만 수행하고 원점수는 바꾸지 않는다. 현재 추가 실제 호출 승인은0이다.
7. 모든 유효 가시 출력을 검토하고, 어려운 유형을 평균에 숨기지 않는다. 고정 분모에 보류/미측정을 남긴다. 표본 신뢰구간은 해당 표본의 **AI 판정 결과**에 대한 값으로 한정한다. 인간 정답 검증이 없는 상태에서 이를 실제 영어 오류율의 보장으로 바꾸지 않는다. 반복 출력을 독립 문항으로 세지 않는다.
8. 설명이 일관되고 새 예문에 같은 규칙을 적용하는지 AI가 확인할 수 있다. 이것은 교육 설명의 대리 지표다. 실제 사람의 이해·기억·전이 효과는 미측정이며, 가상 학습자의 답변을 실제 학습 효과로 집계하지 않는다. 사람 참여를 이번 AI 평가의 필수 섭외 요건으로 두지 않는다.

## 예산·출시 상태

기존 최대756요청의 가상 실행은 도구 검증 근거다. 사람 검토를 추가 AI 교차 평가로 바꾸면 채점·보정·정답표 검토 요청 수가 늘어나므로, 실제 평가에756상한을 그대로 사용하지 않는다. T24/25/35에서 새 역할·반복·최대 요청·토큰·최대 비용과 새 프로토콜/원장/승인을 결합해야 한다. 현재 실제 평가용 키 읽기·호출·신규 승인/사용은 모두0이다. 옛 닫힌 원장/잔액을 재사용하지 않는다.

검토 방법을 AI로 정한 것과 허용 위험·출시를 승인한 것은 별개다. T34 위험/표본/반복/주장 범위와 새로운 비용 제안은 미승인이다. 실제 품질·출시 게이트는 보류다. 향후 통과 표현은 “정해진 표본과 AI 평가 기준에서 통과”로 제한하며, 전문가 검수 완료·학습 효과 입증·무오류를 주장하지 않는다.
