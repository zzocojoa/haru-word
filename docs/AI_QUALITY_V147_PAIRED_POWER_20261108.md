# T34.2 — 표본 수와 개선 발견 가능성

2026-11-08 · `ai-quality-v147` · 상위34/세부34.2 · phase58. 무과금 설계 도구이며 T34는 `review`, 전체 품질/출시는 `held`다. 실제 예비·확인 평가, 일반화, 학습 효과, 운영·출시 후 점검을 포함한 40개 작업의 범위를 유지한다.

## 이번에 해결한 계산 공백

기존 `risk-design.mjs`의 N151/770/1543은 전체 신뢰수준95%를 유지하도록 오류확률5%를114개 단측 경계에 배분했을 때, 오류0건의 상한이 각각5%/1%/0.5% 아래가 되는 **정밀도 예시**다. 후보 개선을 발견할 가능성을 보장하지 않는다. 위험5%도 최종 승인값이 아니다.

새 `paired-power-v1.mjs`는 같은 문항 가족에서 기존·후보를 비교해 `개선(gain)`, `악화(loss)`, `동일(tie)`, `미측정(unavailable)` 중 하나가 나온다는 사전 가정 아래, 기존 짝 비교 판정이 개선을 발견할 확률을 계산한다. 동일에는 둘 다 성공·둘 다 실패가 함께 들어갈 수 있다. 이 계산은 중대 오류0건 등의 다른 합격 조건을 대신하지 않는다.

## 바꾸지 않은 판정과 계산 방법

- 독립 가족 N을 고정한다. 반복 생성·단어 치환·같은 가족의 여러 문장·모델·표시 순서를 새로운 독립 가족으로 세지 않는다. 반복/변형을 네 범주 중 하나로 합치는 규칙은 실제 평가 전에 별도로 사전 등록해야 한다.
- 기존 `pairedEffect`와 똑같이 `개선 비율의 단측 하한 - 악화 비율의 단측 상한 > minimumImprovement`일 때만 개선을 발견한 것으로 센다. 등호는 불합격이다. 신뢰도와114개 경계 배분, 기존 계산 모듈을 변경하지 않았다.
- N개가 전부 측정돼야 한다. 미측정을 동일이나 성공으로 바꾸거나 분모에서 제거하지 않는다. 따라서 전체 발견 확률은 `모두 측정될 확률 × 모두 측정됐을 때의 발견 확률`이다.
- 네 범주의 iid 다항분포를 미측정0건 조건에서 이항분포 혼합으로 분해한 유한합을 계산한다. 난수 시뮬레이션이 아니다. 이 분해는 이번 구현의 수학적 유도이며 공식 문서가 하루단어의 모집단 가정을 보증한다는 뜻이 아니다.
- 국소 계산기의 N 상한4096은 CPU 작업량 보호용이다. 초과값은 거절하며 표본을 줄여서 실행하지 않는다. 검증 참조의 N 범위는1~1543의10개 설계다. 이 범위를 실제 모집단 적합성 인증으로 해석하지 않는다.

분포 입력은 네 범주를 모두 명시하고 각 확률0~1, 합1을 요구한다. 합의 부동소수점 오차1e-12 이내만 명시된 divisor로 정규화한다. 이항 질량은 최빈값에서 양쪽으로 계산하고 상측 꼬리를 직접 합산한다. binary64 계산이며 극소 확률은0으로 언더플로할 수 있다. 0 출력이 불가능성 증명은 아니며, 모두 측정될 확률의 언더플로는 별도로 표시한다. 실제 판정 경계는 허용 오차를 더해 완화하지 않는다.

## 민감도 결과: 실제 AI 성능 측정값이 아닌 예시

아래는 **한 모델·한 사전 지정 계층**에서 신뢰도95%/114경계/개선 주장 기준0을 사용한 계산이다. 전체 연구·모든 모델·모든 계층의 공동 합격 확률이 아니다. N60 역시 독립 가족60개라는 별도 산술 예시이며 실제 혼합 예비60문항 전체의 검정력으로 해석할 수 없다.

| 가족 N | 개선12%·악화2%·동일86%·미측정0% | 개선30%·악화20%·동일50%·미측정0% | 측정됐을 때 첫 열과 동일한 분포·미측정1% |
| --- | --- | --- | --- |
| 151 | 7.1928% | 0.6760% | 1.5769% |
| 770 | 99.9661% | 42.4110% | 0.04355% |
| 1543 | 99.9999999996% | 92.9370% | 0.00001841% |

첫 두 열은 순 개선 차이가 모두10%p지만 개선·악화의 구성에 따라 발견 가능성이 다르다. 마지막 열은 개선11.88%/악화1.98%/동일85.14%/미측정1%로, 모두 측정됐을 때 첫 열과 같다. N770에서 모두 측정될 확률은 약0.04356%이므로, 누락0건 조건 아래 전체 발견 확률도 이를 넘을 수 없다. 표본을 늘리면 개선 검출이 쉬워질 수 있지만 미측정0건 충족은 더 어려워질 수 있다. 실제 누락률을1%로 추정한 결과가 아니다.

개선 주장 기준2%p의 별도 민감도도 계산했다. 이는 가설 경계의 예시이며 최소 검출 효과(MDE), 원하는 검정력, 위험 기준이나 최종 표본 수를 승인·선정한 것이 아니다. 실제 사전 가정은 자격을 확인한 평가자와 독립 가족을 사용하는 예비 근거로 정하고, 확인평가 결과를 본 뒤 맞추지 않는다.

## 검증과 사용 예

`paired-power-reference-v1.json`은 독립 Python SciPy1.16.3의 beta 분위수와 binom PMF/SF로10개 설계·110개 확률을 계산했다. N≤20의33개는 Decimal70자리 다항분포 전수합으로도 대조했다. Node 검사는 기존 `pairedEffect`의 작은 N 전 상태·등호 경계, 누락 분모, 동일 개선 차이의 다른 분포, 극소 꼬리·언더플로, 잘못된 입력과 승인/출시 주장 제한을 검사한다. 최종 실행 결과는 phase58의 Node22/24 로그와 비교 JSON을 따른다.

```js
import {pairedPowerSensitivity} from './.taskmaster/scripts/ai-quality-v147-paired-power-v1.mjs';
const result = pairedPowerSensitivity({
  n: 151, familywiseConfidence: .95, boundCount: 114, minimumImprovement: 0,
  scenarios: [{id: 'illustration-only',
    probabilities: {gain: .12, loss: .02, tie: .86, unavailable: 0}}]
});
console.log(result.rows[0].power); // 약0.07193, 실제 성능/전체 합격 확률 아님
```

## 실제 평가에 앞서 남은 조건

1. 모집단/계층/독립 가족 출처와 반복의 가족별 범주 집계 규칙을 사전 정의한다.
2. 허용 위험·개선 주장 범위·최소 효과·목표 검정력과 손해 방지 기준을 확정한다. AI만 사용하는 검토의 역할·기대값 자격 검증은 여전히 필요하며 사람 섭외를 요구하지 않는다.
3. 예비 근거로 개선/악화/미측정 가정의 민감도를 검토하고, 모든 필수 계층·조건을 만족하는 N/r과 실제 입력 토큰 비용을 함께 확정한다. 한 비교의 검정력으로 연구 전체 합격을 대신하지 않는다.
4. 확인 표본·본문·버전·중단/누락/재실행 정책·금액을 평가 전에 동결한다. 확인 결과를 보고 기준을 낮추거나 표본을 늘리지 않는다.
