# 새 60문항의 가린 AI 참조 검토 준비

새 문항 60개에 서로 다른 두 모델을 배정해 검토 요청 120개를 만들었다. Sol, Terra, Astra가 각각 40개를 맡는다. 두 모델에는 같은 과제·원문·문맥과 출처 요약을 제공한다. 작성자 판정, 문항 유형, 다른 검토자의 응답, 기준판·후보판의 저장 결과는 요청에서 제외했다.

두 모델은 목표 용법과 원문 문법을 각각 판단한다. 교정이 필요하면 원문에 있는 짧은 구간과 교정 표현을 제시한다. 평가기는 없는 원문 구간, 중복·겹침, 제공되지 않은 출처, 불필요한 교정, 문맥 요구의 모순을 확인한다. 두 모델의 교정문이나 판단이 다르거나 출처가 부족하면 보류한다. 서로 다른 적절한 표현은 원판정을 보존한 상태로 별도 검토할 수 있다. 합성 검증 11건을 통과했다.

첫 여섯 문항의 검토 요청 12개와 입력 계산 12개의 보수 예약 상한은 **US$1.249116**이다. 일반 가용액은 US$1.647534다. 전체 120개 검토의 같은 방식 예약 상한은 US$12.491160이며, 입력 계산료 여유만 US$4.20이다. 실제 입력은 전송 단계에서 요청별로 확인하고, 계산료 여유와 실제 청구액은 구분한다. [공식 API 단가](https://developers.openai.com/api/docs/pricing)

요청 본문과 계산 본문 지문, 모델 배정, 비용을 별도 계산으로 대조했다. 계획 파일 SHA-256은 `f18c4b3e4f65d74d758a0e353fa7e67e0633256e53461b0fac9d4ac9bf470780`이다. 이 단계는 가린 참조 검토 준비이며, 유료 전송 경로와 실행 범위의 결합이 남아 있다. 실제 검토 0/120, 정식 참조 자격 0/60, 예비평가 생성 0/360이다.
