# T25.2·T34.3–4 현재 채점 요청에 과거 보정 근거 연결

현 후보의 화면 구성으로 공개 보정 사례를 Chromium과 WebKit에서 다시 표시했다. 두 엔진의 가시 화면 22건과 빈 화면 대조가 일치했다. 72개 요청의 본문을 과거 실제 보정과 대조하고, 요청이 같은 18건과 달라진 54건을 분리했다.

| 분류 | 처리 |
| --- | --- |
| MC01·MC03·MC04의 18건 | 모델, 요청 순서, 채점 본문, 토큰 계산 본문이 동일하다. 저장된 실제 입력 토큰과 응답을 요청·영수증 지문으로 연결했다. 당시 기준과 18/18 일치했다. |
| 화면이 달라진 9사례의 54건 | 새 토큰 계산과 채점이 필요하다. 새 본문에 과거 점수와 토큰 수를 붙이지 않았다. |

과거 전체 71/72 결과와 MC12 이견은 원본에 유지했다. 요청·응답·영수증을 바꾸거나 다른 검토자 자료를 넣는 일곱 대조에서 연결이 차단됐다. 설명만 변경한 별도 대조에서도 새 검토로 분류했다. 관련 보정·전송 전 검사 11개와 변경 스크립트 린트가 통과했다.

18건을 다시 요청하는 경우의 입력 계산료 여유 US$0.630000을 덜 수 있다. 54건의 계산료 여유는 기존 회당 US$0.035 기준 US$1.890000으로, 모델 요금 전부터 현재 가용액 US$1.152100보다 US$0.737900 많다. 이 금액은 원장의 보수적 여유금 계산이다. [순차 예산 근거](AI_QUALITY_V147_SEQUENTIAL_BUDGET_20261109.md)

채점기가 현재 화면 전체에서 보정을 통과했는지는 보류다. 새 모델 요청·입력 계산·예약은 0회이며 정식 참조 채택 0/60과 예비평가 실제 생성 0/360을 유지한다. [요청별 증거](../outputs/ai-quality-v147-implementation-20261106/phase150/calibration-reuse.json)
