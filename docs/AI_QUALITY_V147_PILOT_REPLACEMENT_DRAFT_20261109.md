# T24.2·T24.3 예비평가 대체 문항 초안

회귀 테스트에 사용된 예비 문항 두 개의 대체 초안을 작성했다. 기존 58문항과 대체 슬롯의 수업·목표 단어·평가 유형·길이 구간을 유지했다. 문법 문항은 방식 부사 위치를, 단어 문항은 `check`를 쓰는 조동사 수동태의 동사 형태를 점검한다. 작성 근거는 각각 부사 배치, 조동사 수동태, 동사 뜻에 한정했다. [British Council 부사 위치](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/where-adverbials-go-sentence) · [British Council 수동태](https://learnenglish.britishcouncil.org/free-resources/grammar/c1/advanced-passives-review?page=3) · [Merriam-Webster check](https://www.merriam-webster.com/dictionary/check)

새 원문과 작성자 교정문 네 개를 기존 지문 1,082개, 이전 예비 문항과 교정문, 세 작업본의 관련 소스에서 대조했다. 일치 문장과 알려진 공통 틀의 일치는 0건이다. 전체 노출 범위, 구조 독립성, 난이도는 별도 검토 대상이다.

| 검증 범위 | 결과 |
| --- | --- |
| 두 동결 앱 × 두 문항 × 세 모델 설정 | 입력 6쌍 동일, 합성 교정 결과 저장·재조회 12/12 |
| 같은 요청 재제출과 다른 계정의 조회 | 중복 요청 차단 12/12, 다른 계정 조회 차단 12/12 |
| 생성 요청 초안 | 이전 348개 본문을 보존하고 새 12개를 연결해 360개 |
| 가린 참조 검토 초안 | 기존 106개를 보존하고 새 문항에 4개 연결, 입력·출처·교정 규칙의 합성 검사 16개 통과 |

새 검토 본문에는 실제 앱에서 읽어 온 입력과 출처 요약을 넣었다. 작성자 판정과 완성 교정문을 가렸고, 이전 두 문항의 요청과 실패 기록은 보존했다. 첫 여섯 문항과 출처 보류 한 문항의 재검토 범위는 이전 본문과 지문을 유지했다.

이번에 합성 응답을 받아 저장하는 앱 동작을 확인했다. 정식 독립 참조 채택은 0/60, 실제 예비평가 생성은 0/360, 교차 채점은 0/1,440이다. 두 대체 문항의 가린 검토와 채택이 남아 있다. 새 모델 호출·토큰 계산·운영 쓰기는 각각 0건이다. 대체 원문, 가린 본문과 검증 기록은 Git 제외 `outputs/ai-quality-v147-implementation-20261106/phase137/`에 보존했다.
