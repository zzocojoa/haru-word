# 실제 교정의 설명 보완과 채점 요청 재연결

[실제 교정 진단](AI_QUALITY_V147_PRODUCT_CORRECTION_ACTUAL_20261109.md)의 저장된 응답에서 AI는 `carries`를 `carry`로 고친 이유를 제공했다. 기존 앱은 편집을 대조하라는 일반 안내를 보여줬다. 수정판은 단순한 법조동사 구문에서 검토한 동사 형태만 바뀐 경우 동사원형 규칙을 표시한다. 복합 명사, 인용문, 추가 편집, 시점이 달라질 수 있는 교정은 일반 안내 범위에 남는다. 모델이 생성한 자유 서술을 그대로 보여주지 않으며, 검토한 규칙은 앱이 제공한다.
