# T24.2 동결 후보의 새 예비평가 60문항 초안

후보를 동결한 뒤 작성한 첫 여섯 문항에 54문항을 더했다. 단어와 문법 각각 정상, 수정 필요, 문맥 부족에 10문항씩 배정했다. 문법 15개 수업은 두 번씩 등장한다. 길이는 짧은 문장 24개, 일반 길이 24개, 입력 한도에 가까운 문장 12개다. 긴 문항은 실제 입력 길이에서 경계를 시험하도록 문맥을 합성했고, 난이도와 대표성에 대한 별도 검토가 필요하다.

기존 60문항, 노출 원본, 제품 문장 목록의 지문 총 953개를 대조했다. 알려진 동일 문장 0건을 확인했다. 구조가 비슷한 문항의 독립성 및 전체 노출 범위는 추가 확인 대상이다.

| 로컬 재생 | 기준판 | 후보판 |
| --- | ---: | ---: |
| 실제 제품 경로에서 요청 생성 | 180 | 180 |
| 합성 교정 응답 저장 | 171 | 174 |
| 앱의 내용 변경 검사에서 거절 | 9 | 6 |

두 판에 쌍별로 같은 입력을 보냈고 작성자 판정은 요청에 포함하지 않았다. 후보판의 거절 6건은 두 문항에 대한 세 모델 설정이다. 정상적인 부사형 교정과 같은 동사의 서로 다른 활용형 사이의 교정을 내용 변경으로 처리했다. 모두 합성 응답이며 해당 문항과 거절을 동결 기록에 그대로 보존한다.

정식 참조 자격은 0/60이다. 새 문항의 출처 적합성·독립 AI 검토와 실제 모델 평가가 남아 있다. 이번 API 호출과 토큰 계산은 0건이다.
