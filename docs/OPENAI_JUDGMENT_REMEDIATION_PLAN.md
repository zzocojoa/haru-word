## 새 유료 평가의 고정 범위

주평가: 새30사례=단어15·문법15(15수업 포괄), 권고 분포 정상13·실오류10·문맥 부족7. 수업v1~v4를 분산하고 버전별 정확한 stem/task/check를 사용한다. 구체 문장·허용값은 **새 구현 source 동결 뒤 작성**, 첫 요청 전에 사전 등록한다. 작성자 노출 이력을 남기고 이를 독립 인간 전문가의 미공개 자료라고 표현하지 않는다.

3모델×2버전×30사례=생성180회·교차 채점180회, 최대360회. 별도 진단은 최대18생성/18채점=36회로 합계상한396회다. 단어/문법 각3개 진단 사례에 기본Sol의 고정 대조 조건3개를 사용한다. 실제 Task15 동결 시 지시 범위·추가 문맥 유무·reasoning 중 선정한 요인 하나만 바꾼 대조표를 등록하며 source/schema/input의 함께 바뀐 조건을 단일 원인 효과로 해석하지 않는다. 일반 ChatGPT 제품과 동일한 비교라는 주장도 하지 않는다.

생성 출력2048·채점768토큰은 이 새 평가의 상한이고 모든 모델 성공을 보장하는 값이 아니다. 평가 실행기에는 실제 body·모델별 최신 공식 단가·캐시/지역/미상 실패 여유·사용량 정산·원자 dispatch·원장 잠금·완전대조묶음 선예약을 적용한다. $5를 최우선으로 지키며 횟수는 보장하지 않는다. 주평가 완전 묶음을 우선하고 선택 진단은 남는 예산에서만 수행한다. 주평가 미측정은 R3 미통과, 선택 진단 미실행은 해당 인과 미확정으로 보고한다. 평가/게시후 smoke가 필요하다면 같은 새5달러 안에 예약한다.
