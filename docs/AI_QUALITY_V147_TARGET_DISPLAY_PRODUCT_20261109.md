# 수업 목표의 보완 필요와 문맥 확인 표시 분리

2026-11-09. [가린 화면 비교](AI_QUALITY_V147_RENDERED_REVIEW_ACTUAL_20261109.md)에서 남은 네 판정은 ‘수업 목표 · 확인 필요’가 목표 표현의 오류를 말하는지 불분명하다는 이견이었다. 수정판은 목표 표현이 기준에 맞지 않을 때 ‘보완 필요’, 문맥이 더 필요할 때 ‘문맥 확인 필요’를 표시한다. 새 피드백에는 원문의 목표 표현이 사용 기준에 맞지 않는다고 AI가 판단했다는 설명을 넣는다. 문법과 교정 상태는 각각 별도 표시한다.

기존 `judgment-v6` 기록은 앱이 작성한 옛 목표 안내 한 줄과 저장 상태가 함께 일치할 때 화면에서만 새 문구로 표시한다. 다른 문구와 기존 버전의 설명은 그대로 읽는다. 저장된 설명, 원문, 교정문 및 API 값은 이 읽기 처리로 바뀌지 않는다.

## 검증

- 이전·수정 Worker에 같은 가상 응답 7쌍을 주고 저장·재조회 14건을 대조했다. 제품이 AI에 보내는 요청과 가상 응답 지문은 각 쌍이 동일했다. `needs_work` 사례 다섯 건에서는 목표 설명 한 줄만 달라졌다. 목표가 적절하거나 문맥이 부족한 두 사례는 저장 설명도 일치했다. 원문과 첫 답, 교정 보류, 계정 분리, 중복 요청 차단을 확인했다.
