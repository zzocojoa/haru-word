# T34.4·T26.2 현재 화면과 채점 요청 대조

공개 보정 12개를 구현 브랜치와 동결 후보에서 같은 피드백으로 표시했다. Chromium과 WebKit에서 화면 44건이 일치했다. 피드백이 없는 통제 1개는 별도로 유지했다. 실제 보정 당시 요청과 비교해 9개 사례의 표시가 달랐다.

| 달라진 표시 | 사례 | 채점 요청 수 |
| --- | --- | ---: |
| 문법 표시가 ‘확인 필요’에서 ‘보완 필요’로 바뀜 | MC02, MC06, MC07, MC08, MC10, MC12 | 36 |
| 원문과 동일한 문장을 교정 제안에서 숨김 | MC05, MC09, MC11 | 18 |
| 당시 화면과 일치하거나 피드백 없음 | MC01, MC03, MC04 | 18 |

MC12의 원문은 `They is studying.`, 교정문은 `They are studying.`이다. 당시 두 요청 순서에서 문법 점수가 달랐다. 현재 화면에서는 문법 표시만 달라졌으며, 그 표시가 이견의 원인이었는지와 변경 후 모델 판정은 확인되지 않았다.

보존한 요청·응답 72개를 원본 지문과 대조해 당시 71/72 판정을 재현했다. 표시가 달라진 54개 요청의 새 본문과 입력 계산 본문을 로컬 초안으로 준비했다. 화면 변경을 되돌리면 과거 요청 본문과 바이트 단위로 일치했다. 이전 점수는 당시 화면에 연결해 보존했다.

교차 채점 요청 편성기는 이전 제품 소스의 지문 검사에서 멈췄다. 편성기는 보존된 제품 요청의 필드와 피드백 화면을 받아 채점 요청을 만드는 도구다. 이 경로에 고정된 채점 기준 식별자와 캡처 입력 정규화를 연결했다. 과거 제품 규칙을 재구성하는 경로의 소스 지문 검사는 유지한다. 이번 편성에서 이전 요청 1,440개를 그대로 재현했고, 화면 전용 보정 기준으로도 1,440개를 편성했다. 당시 합성 자료에서 화면이 없는 168개는 계속 보류했다. 대조 조건 9개와 변경 도구 두 파일의 ESLint가 통과했다.

새 AI 호출·입력 토큰 계산·키 읽기·운영 쓰기는 모두 0이다. 정식 참조 0/60, 예비평가 생성 0/360, 교차 채점 0/1,440을 유지한다. 과거 도구와 새 초안, 검증 기록은 Git 제외 `outputs/ai-quality-v147-implementation-20261106/phase135/`에 보존했다. [당시 보정 결과](AI_QUALITY_V147_FORMAL_CALIBRATION_ACTUAL_20261109.md)
