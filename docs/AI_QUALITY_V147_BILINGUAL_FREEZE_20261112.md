## 기존 평가에서 이어갈 범위

기존 예비 초안60문항은 단어30·문법30, 각 영역 정상10·교정10·문맥 부족10이다. 단어30문항에는 새 입력 방식인 `intended_korean` 역할이 없다. 이를 새 한국어/영어 흐름의 평가 결과로 사용할 수 없다. 기존 문장·참조 검토·원점수는 그대로 보존한다.

`pilot-input-impact.json`에60문항별 영향과 다음 작업을 남겼다.

1. **T24.2:** 단어30문항의 한국어/영어 쌍과 평가 층 배분을 검토한다. 뜻·시점·참여자·수량을 덧붙이는 작성자의 추정을 정답으로 확정하지 않는다. 현재 공개 회귀6개를 새 비공개 품질 문항으로 세지 않는다.
2. **T24.3:** 원문 문법과 한국어 의도에 맞춘 교정을 구분하는 기준, 실제 요청 본문, 원장·최대 비용을 정렬한다. 과거 언어 근거를 읽을 수는 있지만 새 후보의 실제 응답이나 한국어 충실도 검토로 재사용하지 않는다.
3. **T24.4:** 새 범위 승인·동결 지문·예산 확인 후에만 실제 전송한다. 과거 실행 승인은 완료한 범위의 이력이다.

새 정식 예비평가 문항·참조 자격은 이번 작업에서 승인하지 않았다. 60문항·생성360/검토1440, 후속 확인·1% 위험 목표, 운영·출시 조건은 유지한다. 이번 공개 회귀로 이를 대체하지 않는다.
