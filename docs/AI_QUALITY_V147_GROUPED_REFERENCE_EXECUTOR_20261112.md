# T24.2·T24.3 묶음 참조 검토 실행 범위

남은 **54문항·108개 언어 판정**을 Sol·Terra·Astra 각각 36문항씩 검토하도록 단일 실행 수집기를 연결했다. 제안 범위는 **AI 응답 3회·입력 토큰 계산 3회**, 기존 추가 US$35 안에서 **최대 US$1.807916**이다. 실제 호출·키 읽기·예약·전용 잔액 소비는 아직 0이며 새 범위 승인이 필요하다.

## 비용과 승인 경계

| 자금·계산 항목 | US$ |
| --- | ---: |
| 직전 실제 48회 정산 뒤 전용 미사용액 | 1.322513 |
| 이번에 사용할 일반 가용액의 최대치 | 0.485403 |
| 이번 합계 상한 | **1.807916** |
| 위 상한에 포함한 입력 계산료 여유, 3회 | 0.105000 |
| 최대 사용 시 추가 US$35 안에 남는 금액 | 0.090838 |

일반 가용액 전체는 US$0.576241이며 이 중 최대 US$0.485403만 예약한다. US$1.322513은 직전 정산의 전용 잔액을 재배정하는 금액으로, 일반 가용액에 중복해서 더하지 않는다. 기존 48회 승인이나 소진된 전용 잔액 사용 기록을 새 실행에 재사용하지 않는다. 원래 US$5의 닫힌 잔액과 별도 보류액도 사용하지 않는다.

입력 3개를 모두 계산한 뒤 그 **실측 토큰 수**에 25% 여유를 적용한다. 요청당 실측 입력 50,000토큰·출력 8,192토큰이 상한이다. 입력에는 30분 캐시 쓰기 단가를 적용하고 모델 비용에 10% 여유를 둔다. 세 모델의 상한 합계는 US$1.702916이며 계산료 여유 US$0.105000을 합쳐 US$1.807916이다. 입력 한도나 계산된 금액이 넘으면 모델 전송 0회에서 중단한다. 실제 정산에는 관측 사용량을 적용하며 미확인 호출이 있으면 승인 상한을 보수적으로 보류한다.

2026-11-12 확인한 [공식 가격](https://developers.openai.com/api/docs/pricing)의 Standard 입력/30분 캐시 쓰기/출력 단가는 백만 토큰당 Sol 2/2.5/10달러, Terra 1/1.25/5달러, Astra 10/12.5/50달러다. 출력 8,192토큰은 [Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol), [Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra), [Astra](https://developers.openai.com/api/docs/models/gpt-6-astra)의 문서상 최대 출력 이내다. 입력 계산료의 별도 공식 과금 근거는 여전히 미확정이다. US$0.035/회는 기존 충당액을 유지한 것이며 실제 청구액 보증이 아니다.

## 전송·실패·복구

수집기는 승인 기록에 실행 범위·수집기·실행기·예산 프로필 지문과 재배정·3회/3회·한도를 결합한다. 직전 실제 48회 원문·정산·소비 기록까지 대조하며, 최종 후보의 제품 입력 33개도 고정 지문과 비교한다. 승인 또는 지문이 맞지 않으면 키를 읽거나 예산을 예약하지 않는다.

전용 잔액 소비 기록과 일반 예약을 남긴 뒤 입력 계산을 시작한다. 각 요청·전송 의도는 통신 전에 저장한다. HTTP 오류, 시간 초과, 완료되지 않은 응답, 사용량 모순, 응답 ID 중복은 중단한다. 같은 범위의 자동 재시도·재개는 없다. 부분 기록 뒤에도 새 실행으로 덮거나 같은 잔액을 다시 소비하지 않는다. 비밀이 반사된 응답은 저장하지 않는다.

수집한 응답은 기존 문항별 검사로 분해하며 **108개 분모**를 유지한다. 응답 잘림·누락·중복 ID는 해당 묶음 36개를 미측정으로 남긴다. 문항별 출처 부족·이견은 보류한다. 교정 문장이 실제로 맞는지는 이 단계의 관측 결과로 기록하며, 합성 테스트의 일치를 영어 점수로 사용하지 않는다.

중단 시 확인 순서:

1. 실행 폴더의 `ONCE.json`, 요청/의도/캡처, `terminal.json` 존재와 지문을 확인한다.
2. 전용 소비 기록·일반 예약·두 정산 파일 및 원장 사본을 대조한다.
3. 결과 미확인 요청은 보류하고 재전송하지 않는다. 남은 예약을 임의 초기화하지 않는다.
4. 확인된 근거로 정산·복구 범위를 별도로 검토한다. 같은 실행 명령을 다시 보내 복구하지 않는다.

## 이 단계가 완성하는 근거와 남는 관문

이 범위는 아직 응답을 받지 않은 54문항의 가린 언어 참조 제안 수집이다. 이미 실제 응답을 받은 첫 6문항과 Noor 후속 근거는 그대로 보존한다. 묶음 방식과 개별 방식의 의미적 동등성, 7차원 참조 검토 역할 통제, 노출·가족 검토 및 작성 기준 이견은 별도 관문이다. 이 실행만으로 정식 참조 자격을 부여하지 않는다.

정식 참조 **0/60**, 예비평가 생성 **0/360·채점 0/1,440**를 유지한다. 현재 보정 72/72와 과거 71/72, 확인 평가 1% 설계, 학습 대리 지표·운영·출시 관문은 보존한다. 전체 개선 목표의 범위를 이 3회 진단으로 축소하지 않는다.

검증 명령과 최종 결과는 phase162 `executor-evidence.json`, `collector-tests.log`, `closeout-verification.json`을 따른다. 수집기 테스트는 실제 키·전송 대신 격리된 합성 원장과 전송을 사용한다. 제품 코드·운영 설정을 바꾸지 않아 제품 단위·타입·빌드는 재실행하지 않는다. 실제 게시·커밋·푸시·사용자 기록 수정·파일 삭제는 없다.
