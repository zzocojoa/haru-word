새 정책은 전체 로컬 자료의 hash와 case별 전달 목록 hash를 계약에 고정한다. 전달 목록의 원본 지문에는 전체 자료 hash·선택 규칙·대상·표시 ID가 묶인다. 목록은 배정/통제를 기준으로 다시 계산하므로 임의 항목 제거·다른 창 선택·누락 자료·낡은 hash·기존 정책으로의 변경은 소유 lease 전에 거절한다. 전체 입력 원본은 실행 중 변경 여부를 다시 확인하며,count 후/소비 후 변조도 호출 경계를 넘지 못한다. 현재 방식은 봉인된 자료 snapshot을 검사한다. 실제 유료 경로의 환경/출처 인증·최종 동결과는 구분한다.

작성과 두 익명 항목은 같은 부분 전달 자료를 쓴다. 검토자의 nonce에 따라 자료/가족 식별자를 바꾸며,전체 로컬 목록의 출처·원본 식별자·대상 묶음·비공개 기대 점수를 모델에게 보내지 않는다. 부분 자료에서 exposure pass/해결 확정은 여전히 거절한다. 일부 항목을 보지 못하는 모델의 구조 판단을 전체 가족 독립성으로 해석하지 않는다.
