# T24.2·T34.2 예비평가 참조 채택 근거 대조

첫 6문항의 실제 응답 12개를 당시 요청과 연결했다. 두 검토 모델의 합의, 작성 기준과의 일치, 제공된 출처의 범위를 문항별로 나눴다. 기존 실제 실행의 4문항 일치·2문항 보류와 새 규칙 재검사의 5문항 일치·1문항 보류를 각각 보존했다.

| 원문 | 채택을 위한 대조 결과 |
| --- | --- |
| `The lacquer looks glossy under the lamp.` | 두 AI와 작성 기준이 자연스러운 문법 및 형용사 사용에 일치했다. 한 AI가 언급한 연습 예시의 주제는 동결 제품 정책상 별도 자기 점검 항목이다. [British Council 연결동사](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/link-verbs) |
| `The museum guide handed she the brochure.` | 두 AI와 작성 기준이 `she`를 `her`로 바꾸는 데 일치했다. [British Council 인칭대명사](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/personal-pronouns) |
| `The fresco depicts a winter market.` | 두 AI와 작성 기준이 `depicts`의 쓰임과 문법이 자연스럽다는 데 일치했다. [Merriam-Webster depict](https://www.merriam-webster.com/dictionary/depict) |
| `Even though the generator had stopped` | 두 AI와 작성 기준이 교정을 보류하는 데 일치했다. 두 AI는 완성 메시지 확인, 작성자는 절의 연결 관계 확인으로 분류했다. 두 값을 보존한다. [Purdue OWL 문장 조각](https://owl.purdue.edu/owl/general_writing/mechanics/sentence_fragments.html) |
| `Several faded receipts` | 새 규칙으로 두 AI 응답을 읽을 수 있게 됐다. 두 AI는 단어 쓰임을 적절하다고 보고 문장을 미완성으로 판단했으며, 작성 기준은 두 판단을 모두 유보했다. |
| `Noor suggested to postpone the launch.` | 작성 기준과 두 AI의 교정문은 같았다. 첫 출처 판단의 이견은 보존하고, 별도 후속 검토 준비 상태를 유지한다. |

세 문항의 문법·목표 용법 근거를 채택 심사 후보로 정리했다. 정식 참조 자격은 0/60이다. 원래 표본·기대값·응답과 후보 파일 지문을 보존했다.

예비 60문항은 여섯 유형 각 10개를 유지하며 기준판·후보판의 생성 요청 360개를 다시 대조했다. 알려진 문장 지문 953개와 일치한 문장은 0개였다. 길이 경계를 시험하는 12문항은 문서 도입과 마무리에 공통 틀 두 가지를 각각 여섯 번 쓴다. 예비 길이 시험에 유지하고, 확인 평가의 독립 가족 수에는 집계하지 않는다. 전체 노출과 의미 구조의 독립성은 별도 확인이 필요하다.

읽기 전용 검사는 로컬 자료의 파일 지문과 실제 응답을 대조했다. 실제 모델 호출, 토큰 계산, 정식 앱 예비평가 생성은 모두 0회다.
