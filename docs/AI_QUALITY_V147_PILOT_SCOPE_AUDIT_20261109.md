## 표본 단위와 중단 조건

관측 중대 오류 0건, 전체 신뢰수준 95%, 114개 단측 경계의 기존 설계에서 유형별 770개가 1% 위험 상한을 만족하는 최소치임을 독립 계산했다. 이때 상한은 약 0.9991%이고 769개에서는 약 1.0004%다. 기준선·후보, 모델, 반복, 두 순서의 응답은 한 가족 안에서 묶는다. 예비 60문항의 확인 평가 자격을 입증한 독립 가족은 0개다. 예를 들어 `A university`와 `an one-page`는 정상·교정필요로 나뉘지만 모음으로 시작하는 철자에서 첫소리로 관사를 고른다는 같은 규칙을 시험한다. 확인 표본을 짤 때 이런 변형을 별개 독립 가족으로 자동 집계하지 않는다.

최종 표본 수와 반복은 독립 가족 모집단과 채점기 자격을 확인하고, 기준선 대비 개선·악화·미측정 비율의 예비 근거를 얻은 뒤 확정한다. 현재 반복 2와 최소 4,620가족을 적용한 확인 평가의 산술 규모는 291,132회다. 이는 검정력 확정과 별개의 최소 위험 시나리오다. 예산에 닿아 멈추면 사전 고정 분모 전체에 실제 실행·미측정을 각각 남긴다.

## 가용 예산과 실행 조건

추가 US$35 원장의 현재 가용액은 **US$6.415846**, 예약은 US$0이다. 이전 진단의 입력 계산료 여유 US$0.035/회와 제품 응답 상한 4,096토큰을 적용하면 첫 6문항을 동시에 예약하는 데 아래 두 항목만으로 **US$9.814368**이 든다.

- 생성 36회와 교차 채점 144회의 입력 계산료 여유 US$6.300000
- 생성 36회의 출력 상한과 10% 여유 US$3.514368

이 값은 입력 비용과 교차 채점의 응답 비용을 뺀 동시 예약 계산이다. 실제 청구액과 순차 정산 총액은 미확정이다. 순차 실행은 먼저 12개 보정 증인의 자격과 적용 기준을 확인하고, 한 문항의 고정 생성 요청 6개에 대한 실제 입력 계산값으로 예약한다. 수집한 생성 응답으로 교차 채점 24개 본문을 확정하고 다시 비용을 확인한다. 필요한 예약을 감당할 수 없으면 해당 단계 전에 중단한다. 첫 묶음의 일부만 실행돼도 60문항 분모와 유형별 결과의 보류를 유지한다.

이번 실제 호출·입력 계산·키 접근·예약은 각각 0건이다. Node 22와 24에서 같은 60문항·360개 요청 지문 및 역할별 합계를 얻었고, Python Decimal로 770 경계와 예약식을 독립 대조했다. T34.2·34.3은 검토 중이며 T24·T25의 예비 실행과 T35·T36의 확인 평가는 보류다.
