## 시범 항목과 의미 검토

아래 평가는 시범 원본을 직접 보고 남긴 당시 제작자 검토다. 독립 학습자 평가나 영어 정확도 인증이 아니다. **시범 당시 모든 항목은 후보 상태였다.** 후속 수정본·품질 상태는 연결 목록과 전체 진행 기록에서 확인한다.

| 항목 | 품사·기본 뜻 | 생성 장면·검토 메모 |

| apple | 명사 · 사과 | 사과 한 개. 스타일 기준 후보. |

실제 공통 스타일은 아이보리 종이 배경, 절제된 색, 성인 인물 비례와 삽화 질감이다. 어린이·교실을 기본 요소로 넣지 않았다. 생성 원본 20장 모두에서 글자·숫자·라벨·워터마크가 보이지 않음을 직접 확인했다. 검토 HTML과 QA 스크린샷의 영단어·메모는 **원본 이미지 밖의 검토용 표시**다.

기능어·추상어는 장면만으로 특정 영어 단어를 유일하게 추론하기 어렵다. 후속 화면에서 이미지를 연상 단서로 제공하고 교재의 뜻·예문과 함께 확인해야 한다. 사용자 수정 뜻이나 개인 단어에 기본 이미지를 추정해 연결하지 않는다.

## 확인한 범위

- 교재 3,809개 ID의 누락·중복, 기본 뜻·품사 일치와 개별 교재 지문을 검사했다.
- 기존 계획의 `words.json`·`content.json` SHA256이 그대로임을 확인했다. 새 이미지 자료가 교재를 수정하지 않았다.
- 원본 20장의 복사 전후 해시, 파일 크기·PNG 헤더·세로 비율을 검사했다. Windows `System.Drawing`으로 모두 디코딩했다.
- 20개 실제 요청의 프롬프트 해시와 첫 사과 참고 자료의 연결을 확인했다.
- 완료된 `apple`을 다시 시작하려는 요청을 검사했다. 실제 이미지 호출 전에 거부됐고 연결 목록·체크포인트가 변하지 않았다. 검사 과정의 이미지 생성 호출은 0회다.
- 로컬 Chromium 320px 화면에서 이미지 20개 모두 로드되고 비율이 유지됨을 확인했다. 20개 축소 스크린샷을 직접 열어 대상·관계가 보이는지 검토했다. 추상적 의미 전달의 한계는 위 표에 남겼다.
- 검사 중 첫 사과 항목의 프롬프트 해시 누락을 찾아, 이미 사용한 원래 프롬프트에서 계산해 보완했다. 최종 전체 검사 통과 후 이 결과를 기록했다.
- 검사 서버는 루프백 주소만 사용하고 종료했다. 운영 사이트·학습 기록·DB·백업·API·예약 설정을 변경하지 않았다.

실제 iPhone, 독립 학습자의 뜻 추론·학습 효과, 이미지 호스팅·웹 전송 성능은 검사하지 않았다. 원본은 보존용이며 후속 화면 반영 때 표시 크기·압축 형식·전송량을 별도로 검증해야 한다. 이번 변경은 제작 자료·문서만으로, 앱 전체 테스트·타입·린트·빌드는 실행하지 않았다.

근거는 이 worktree의 Git 제외 `work/oxford-image-pilot-verification.json`, `work/oxford-images-pilot-progress.json`과 위 `qa/` 폴더에 있다. 로컬 검토 HTML은 운영 학습 UI 구현이 아니다.

## 시범 당시 사용자 확인과 재개 절차

1. 채팅에 표시한 시범 20장을 검토하고 스타일과 수정할 항목을 확인한다. `about` 부사와 `record` 명사는 우선 검토한다.
2. 확인 결과를 해당 항목의 `review`에 기록한다. ‘생성됨’과 ‘사용자 승인’을 구분하며, 승인 전 나머지 3,789개를 호출하지 않는다.
3. 수정이 필요한 항목은 결함을 명시해 한 번 수정 생성하고 `v2` 파일로 보존한다. 기존 `v1`은 유지한다. 여전히 미달이면 `held`로 남기고 해결된 것으로 표시하지 않는다.
4. 전체 진행 전 저장된 교재 해시와 현재 자료를 다시 비교한다. 의미·품사·개별 지문이 달라진 항목은 자동 재사용하지 않는다.
5. 호출 중단 시 `generationCalls`·현재 항목·원본 파일을 먼저 대조한다. 결과가 불명확한 호출을 바로 다시 실행하지 않는다.
6. 승인된 시범 이미지를 재사용하며 A1 → A2 → B1 → B2 교재 순서로 진행한다. 10개마다 상태·파일 해시·검수 결과를 보존한다.

이번 시범 제작은 전체 이미지 제작 완료나 화면 반영·배포 완료로 표시하지 않는다.
