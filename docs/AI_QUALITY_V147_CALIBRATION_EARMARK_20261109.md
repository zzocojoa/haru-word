# T34.3 정식 보정 72개에 한정한 예산 배정

11월 8일에 대조된 계산료 예비비 US$8.575 중 **US$8.567184**를 정식 보정의 고정 Standard 요청 72개와 입력 계산 72회에 배정했다. 계산료 여유 US$2.52를 포함한 금액이다. 배정 대상은 [수정 화면을 연결한 보정 계획](AI_QUALITY_V147_RENDERED_CALIBRATION_20261109.md)의 요청 지문과 모델·순서·출력 상한으로 제한된다.

| 기존 추가 US$35 안의 구분 | 세전 US$ |
| --- | --- |
| V3 사용 상한에서 11월 8일 검증 예비비를 뺀 금액 | 23.385220 |
| 72개 보정에 한정한 배정 | 8.567184 |

기존 V3 원장 두 사본은 당시 정산값을 보존한다. 위 표는 V3 사용 상한에 이미 포함된 US$8.575를 분리해 보여준다. V3의 일반 가용액에 배정액을 더해 일반 평가에 쓸 수 없다. 11월 9일 예비비 US$2.94와 미청구 대비액 US$1은 유지했다. [일별 비용 대조](AI_QUALITY_V147_CLOSED_DAY_COST_MATCH_20261109.md)

배정에는 기존 V3의 배타 잠금을 사용했다. 날짜별 배정 파일을 처음 한 번만 쓸 수 있고, 같은 근거로 다시 생성하거나 불완전한 기록을 덮어쓰려 하면 실패한다. 격리한 가상 경로에서 동시 발급 요청 두 건 중 하나만 성공하고 원래 기록이 유지되는 것을 확인했다.

이번 단계의 키 읽기·입력 계산·모델 호출은 각각 0이다. 보정 사례의 출처 자격, 실행 시 배정을 한 번만 소비하는 조건과 정식 보정 결과가 남아 있다. 60문항 예비 평가와 1% 확인 평가, 운영 게이트는 보류다.
