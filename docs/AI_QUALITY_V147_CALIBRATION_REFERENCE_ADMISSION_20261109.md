# T34.4 정식 보정의 공개 사례 출처 검토

기존 수정 화면 12개의 원문, 과제 조건, 표시된 판단과 교정문, 사전 기대값을 대조했다. 아래 문법·사전 근거를 확인했고, 이전 실제 개발 비교에서 Sol·Terra·Astra가 익명 화면을 각각 검토한 결과도 문항별로 연결했다. 기존 기대값과 과거 점수는 보존했다. 이 검토는 공개 채점기 보정의 실행 자격에 한정된다.

| 문항 | 기대 판정의 근거 |
| --- | --- |
| MC01, MC02 | 조동사 바로 뒤의 과거형은 고쳐야 한다. 과거와 미래가 모두 가능하므로 과거 교정만 제시한 MC02는 특정 시점 선택과 보류 판단을 별도로 채점한다. [과거 가능성](https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2/modals-deductions-about-past) · [미래 가능성](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/talking-about-future) |
| MC03 | 지시어와 명사의 수 불일치가 분명하다. 한 대인지 여러 대인지는 제공되지 않아 완성 교정을 보류한다. [지시어](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/demonstratives) · [현재형](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/present-simple) |
| MC04 | 화면 피드백이 비어 있는 대조 문항이다. 교정·설명을 추정하지 않고 다섯 항목을 미제공으로 둔다. |
| MC05 | 이동을 나타내는 동사는 맞지만 3인칭 단수 형태가 잘못됐다. 형태를 맞다고 설명한 피드백은 중대 오류 검사 대상이다. [go 사전](https://www.merriam-webster.com/dictionary/go) · [현재형](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/present-simple) |
| MC06 | 원문이 부정한 소유를 교정문이 긍정한다. 같은 동사를 사용했어도 사실을 뒤집었다. [own 사전](https://www.merriam-webster.com/dictionary/own) · [현재형 부정](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/present-simple) |
| MC07, MC10 | MC07은 본 사람과 본 대상을 맞바꿨다. MC10은 같은 사람을 가리키는 주격·목적격만 고쳤다. [인칭대명사](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/personal-pronouns) |
| MC08 | 과제는 완전한 평서문을 요구하고 완성할 메시지를 주지 않았다. 음악이라는 명사 사용을 인정하되, 명령문을 제시한 것은 과제 형식 위반과 의도 추가로 채점한다. [music 사전](https://www.merriam-webster.com/dictionary/music) · [명령문](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/personal-pronouns) · [생략의 문맥](https://www.cambridge.org/core/books/abs/grammar-for-english-language-teachers/ellipsis-and-substitution/5C3339217F5527DE02FB806083E9FCF9) |
| MC09, MC11 | 책을 뜻하는 명사는 예약한다는 동사 과제를 충족하지 않는다. MC11의 명사 help는 적법한 명령문의 목적어다. [book 사전](https://www.merriam-webster.com/dictionary/book) · [help 사전](https://www.merriam-webster.com/dictionary/help) |
| MC12 | 진행형에 필요한 주어와 be동사의 일치만 고쳤으며 행위와 시점은 그대로다. [현재진행형](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/present-continuous) |

전체 72개는 같은 문항을 세 모델에서 두 순서로 별도 검토한다. 다섯 판정·다섯 근거 항목·네 중대 오류 표시가 기대값과 모두 일치하는지 기록하고, 응답 누락과 구조 오류는 분모에 남긴다. 공개 보정의 성적, 새 답안 생성의 정확도, 사람의 학습 효과와 운영 배포 여부는 각각 별도 범위다.
