## 3. 실제 iPhone 실행 순서와 완료 기준

[iPhone 실기기 출시 확인표](./iphone-release-checklist.md)에 IP01–IP15의 실행 절차,
통과 기준, 기기·OS·URL·배포·설치 상태·증거 입력란을 포함했습니다.
모든 실기기 항목은 미실시입니다.

1. 후보 URL/커밋 연결 확인 → Safari의 네 탭 → 기존 홈 화면 설치의 업데이트 경로
2. 독립된 시험 환경에서 신규 홈 화면 설치 → 완전 종료 후 시작 이미지·앱 로딩
3. 세로/가로·브라우저 막대·큰 글자 → 실제 한글/영문 키보드 입력과 하단 조작
4. 선택 목록·체크·닫기 → 백업 최종 확인에서 취소 → 임시 입력 삭제에서 취소
5. VoiceOver 이름·선택 상태·모달 초점·닫은 뒤 초점 복귀
6. 명시적 서버 저장 후 재실행 → 별도 로컬 초안 복구·되돌리기 → 과거 기록 비교

기존 설치나 Safari 사이트 데이터를 지워 아이콘을 갱신하지 않습니다.
신규 설치는 기존 데이터에 영향을 주지 않는 시험 환경에서만 실시합니다.
현재 운영 URL에서 수행한 결과는 새 후보가 그 URL에 실제 연결되기 전까지 후보의 통과로 집계하지 않습니다.
