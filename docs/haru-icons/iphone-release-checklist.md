# iPhone 실기기 출시 확인표

작성일: 2026-11-12. 대상: P001–P105 아이콘 적용 후 실제 iPhone의 Safari와 홈 화면 앱.
이 문서는 실행 절차이며 **실기기 검사는 모두 미실시** 상태에서 시작합니다.
검사자가 증거를 확인한 항목만 결과를 바꿉니다. 문서 작성은 출시 승인·배포 완료를 의미하지 않습니다.

## 2. 준비와 판정 방법

전용 시험 계정에 과거 완료 회차 1개와 `내 문장 만들기` 단계에서 이어갈 미완료 회차 1개를 준비합니다.
현재 하루 목표·주간 점검 요일·학습 수준·AI 모델 선호·복습만 하기 체크 상태와 과거 회차의 날짜·단어·성적·문장, 미완료 회차의 저장된 문장을 기준 증거로 남깁니다.
예시 입력은 `iPhone saved 20261112-1030`과 `iPhone local draft 20261112-1030`처럼 구별하고 실제 실행 시각으로 바꿉니다.
과거 완료 기록은 읽기 비교용이며 이번 입력·설정 변경은 시험 회차와 시험 계정에만 적용합니다.
현재 회차는 의도한 저장 직후의 값을 다음 단계의 기준으로 갱신합니다. 과거 완료 기록의 비교 기준은 유지합니다.

IP09와 IP13은 아래 네 선택 컨트롤을 각각 검사합니다. Safari와 홈 화면 앱별로 원래 값·다른 시험값·원복값과 초점 증거를 기록합니다.

| 선택 컨트롤 | 원래 값 → 다른 시험값 → 원복값 | 상태 | 증거·실행 불가 사유 |
| --- | --- | --- | --- |
| 하루 목표 | ___ → ___ → ___ | 미실시 | Safari: ___ / 홈 화면 앱: ___ |
| 주간 점검 요일 | ___ → ___ → ___ | 미실시 | Safari: ___ / 홈 화면 앱: ___ |
| 학습 수준 | ___ → ___ → ___ | 미실시 | Safari: ___ / 홈 화면 앱: ___ |
| AI 모델 선호 — 화면의 `AI 모델` 선택 | ___ → ___ → ___ | 미실시 | 사용 가능한 다른 모델·원복 가능 여부: ___ / 두 환경의 증거: ___ |

AI 모델은 목록 로딩이 끝나고, 원래 모델과 다른 시험 모델이 모두 선택 가능할 때만 선호를 변경합니다.
모델명은 실제 표시된 값으로 기록합니다. 다른 선택지가 없거나 원래 값으로 되돌릴 수 없으면 변경하지 않고 해당 변경·저장·초점 복귀 검사를 **미실시**로 남깁니다.
다른 선택 컨트롤도 비활성화 등으로 검사할 수 없으면 컨트롤별 사유를 적습니다. 선택 불가 상태를 강제로 해제하지 않습니다.
모델 목록 조회와 선호 저장만 검사하며 **실제 AI 참고 의견·이미지 생성 요청은 실행하지 않습니다.**

- **기존 설치·사이트 데이터·로컬 임시 입력을 보존합니다.** 아이콘 갱신을 위해 앱 삭제·재설치나 Safari 사이트 데이터 삭제를 요구하지 않습니다.
- 기존 설치 결과를 먼저 남깁니다. 신규 설치는 별도 시험 기기 또는 기존 환경에 영향을 주지 않는 것으로 확인한 시험 환경에서 수행합니다. Safari 프로필을 썼다는 사실만으로 홈 화면 앱의 저장 공간까지 분리됐다고 가정하지 않습니다. 안전한 환경이 없으면 신규 설치는 **미실시**로 남깁니다.
- Safari와 홈 화면 앱은 각각 같은 시험 계정을 확인합니다. 로컬 초안은 **입력한 동일 실행 환경**에서 검증하며, 두 환경 사이의 로컬 초안 동기화를 통과 조건으로 삼지 않습니다.
- 실제 사용자 기록의 초기화·삭제, 최종 백업 복원, 실제 계정 로그아웃, 유료 AI 요청은 이 확인표에 필요하지 않습니다. AI 의견·이미지 생성 버튼을 누르지 않습니다.
- 상태는 `미실시 / 통과 / 실패 / 해당 없음`으로 기록합니다. `해당 없음`에는 사유가 필요하며, 실행 환경이 없다는 이유는 보통 `미실시`입니다. 필수 항목의 미실시를 통과로 집계하지 않습니다.
- 증거는 항목 ID, 실행 환경, 방향, 글자 설정을 포함합니다. 가림·키보드·초점은 **실제 화면 캡처 또는 녹화**로 남깁니다. 긴 전체 페이지 이미지만으로 화면 안의 버튼 접근성을 판정하지 않습니다.

이 표의 **필수**는 이번 아이콘 출시의 수동 확인 범위입니다. 모든 기기·OS 조합의 인증을 뜻하지 않습니다.
설치 단계 외의 공통 항목은 Safari와 홈 화면 앱 결과를 각각 적습니다.

IP02는 기존 설치가 있는 경우 필요합니다. 기존 설치가 없으면 `해당 없음`과 사유를 남기며, 업데이트 경로를 검증했다고 주장하지 않습니다.
기존 설치의 URL이 아직 운영 v147을 제공한다면 업데이트 검사는 미실시로 남깁니다. 별도 후보 URL의 신규 설치 결과만으로 기존 설치의 갱신을 통과시키지 않습니다.
IP03을 위해 IP02의 설치나 사이트 데이터를 지우지 않습니다. 캐시만 다른 경우에도 관찰 사실과 출시 담당자의 처리 결정을 남깁니다.
