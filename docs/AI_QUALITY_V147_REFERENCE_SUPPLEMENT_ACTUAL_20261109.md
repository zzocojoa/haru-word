# T24.2·T34.3 예비평가 참조 근거 재검토 결과

기존 참조 작성자를 제외한 두 모델이 12문항을 검토했다. 실제 모델 응답 24개와 입력 토큰 계산 24개를 모두 회수했다. 두 모델이 추가 출처를 인용하고, 출처가 충분하며 목표 용법·문법·교정 판단을 모두 지지한 사례는 **8/12**였다. 기존 참조와 이전 검토 120개는 보존했다. [사전 고정한 검토 방법](AI_QUALITY_V147_REFERENCE_SUPPLEMENT_SCOPE_20261109.md)

독립 재계산은 원본 24개 응답, 투표와 집계, 요청 지문, 비용과 원장 미정산 잔액 0을 확인했다. 실제 모델 입력은 616~1,620토큰으로 총 20,028토큰, 출력은 86~345토큰으로 총 3,489토큰이었다. 이번 원장 반영액 US$1.023236은 모델 응답 기준 US$0.183236과 입력 계산료 여유 US$0.840000을 포함한다. 추가 US$35 원장의 보수 사용액은 US$32.983456, 가용액은 US$2.016544다. 청구서 대조는 남아 있다.
