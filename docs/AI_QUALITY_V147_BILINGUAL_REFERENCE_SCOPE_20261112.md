# 한국어·영어 30쌍의 실제 AI 검토 범위 — 2026-11-12

T24.2–4의 다음 실행을 준비했다. 한국어 의도와 영어 답안을 가진 단어30개를 서로 다른 두 AI가 가려서 검토한다. Sol·Terra·Astra 각20판정을 한 응답으로 묶어 **60판정·AI 응답3회·입력 토큰 계산3회**다. 기존 추가 US$35 안에서 **최대 US$1.249323**을 제안한다. **현재 새 실행 승인·실제 호출·키 읽기·예약·전용 잔액 소비는0이다.**

## 확인할 내용과 입력

각 AI에는 동결된 후보 앱에서 캡처한 입력 그대로를 보낸다. 목표 단어·품사·뜻·영어 답안·한국어 의도·명시적 `intended_korean` 역할이 포함된다. 작성자 교정 예시·정상/오류 유형·기존 점수·다른 모델의 응답·제품 교정 결과는 보여주지 않는다. 문항 순서는 모델별로 섞고 각 문항은 두 모델에 배정한다.

검토자는 원문 영어의 목표 사용과 문법을 따로 판단하고, 한국어가 뒷받침하는 교정 또는 필요한 문맥을 제안한다. 예를 들어 문법적으로 자연스러운 `The kite drifted under the bridge.`와 ‘연은 다리 위로 떠갔어.’가 주어지면 문법 판단은 정상으로 유지하면서 `over`로 의미를 고칠 수 있다. 문법이 부족해도 한국어가 주어·행동을 알려주면 완성문을 제안한다. 한국어 자체에도 핵심 내용·수량·시점이 없으면 내용을 발명하지 않는다.

두 모델의 판단·질문·교정이 다르면 이견으로 보존한다. 같은 뜻의 서로 다른 적절한 교정도 문자열이 다르면 자동 합격시키지 않고 후속 검토 대상으로 남긴다. 이견을 바로 제품 버그로 세지 않는다. 예시 교정 하나만 정답으로 강제하거나 작성자의 보류표를 정답으로 복사하지 않는다.

이번 범위는 **가린 언어 참조 제안**이며 제품의 실제 교정 생성360회나 5차원 제품 채점1,440회가 아니다. 한국어가 없는 이전 단어30의 검토표를 새 검토 결과로 재사용하지 않는다. 문법30의 기존 초안·검토와 이전 점수는 유지한다. 새 참조 검토의 역할 통제·출처/노출/문항 가족 자격·현재 후보의 보정은 별도 조건이다. 두 AI가 동의해도 정식 참조 자격은 자동 부여하지 않는다.
