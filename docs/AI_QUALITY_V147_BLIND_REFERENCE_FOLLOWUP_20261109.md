# T24.2·T24.3 첫 참조 검토 보류 후속 조치

평가 도구에서 원문의 문법 상태와 교정에 필요한 문맥을 분리했다. 답안에 결함이 보여도 의도를 추정해야 완성할 수 있다면, 확인한 결함과 필요한 문맥을 기록하고 교정문은 비운다. 문맥 확인이 필요한 응답에 교정문이 들어오면 계속 거절한다. 문맥이 충분하고 교정이 필요하면 원문의 정확한 수정 구간을 요구한다.

| 보류 원문 | 후속 조치 | 검증 |
| --- | --- | --- |
| `Several faded receipts` | 뜻은 알 수 있지만 완성 문장에 필요한 내용이 빠졌다는 두 AI의 응답을 수정 규칙으로 다시 읽었다. | 두 응답 모두 원문 문법·목표 단어 쓰임·문맥 필요를 유지한 채 읽혔다. 교정문은 비어 있다. |
| `Noor suggested to postpone the launch.` | 후속 요청에 `suggest` 뒤의 동사 형태를 직접 다룬 출처를 추가했다. [Cambridge English Grammar Today](https://dictionary.cambridge.org/grammar/british-grammar/word-patterns-suggest) | 기존 출처 부족 판정은 보존했다. 새 출처를 넣은 요청 2개를 준비했다. |

기존 British Council 원문은 `suggest`를 동사가 뒤따를 때 `-ing`을 쓰는 동사군에 포함한다. 첫 요청에 넣은 요약은 `-ing`이 가능하다는 내용까지만 전달했다. [British Council 문법 설명](https://learnenglish.britishcouncil.org/free-resources/grammar/a1-a2/verbs-followed-ing-or-infinitive)

보존된 응답 12개를 새 규칙으로 로컬 재검사해 12개를 읽었고, 판정 일치는 5문항, 출처 보류는 1문항이었다. 교정 지어내기·잘못된 수정 구간·출처 변조 등 대조군 12개를 거절했다. 기존 실제 실행 기록은 응답 유효 10/12, 문항 일치 4/6으로 보존했다. 수정 규칙을 만드는 데 사용한 응답은 개발 재생 근거로 기록했다.

후속 검토 요청 110개를 생성했다. 기존 미실행 108개와 출처 보완 2개이며, 과제·원문·모델 배정은 유지했다. 전송과 입력 토큰 계산은 0회다. 정식 참조 자격은 0/60, 예비평가 생성은 0/360이다.
