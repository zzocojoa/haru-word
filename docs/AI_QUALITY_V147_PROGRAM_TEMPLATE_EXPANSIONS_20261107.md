## 역할과 보장 범위

원문을 parser에 넣은 틀,제안 교정안을 만든 틀,보존 비교의 원문/변경안 틀을 구분했다. 일부 비교는 양방향으로 호출되므로 반대 방향의 입력 역할도 적었다. 역할은 코드에서 쓰인 위치에 대한 기록이며 문법/의미 점수나 영어의 자연스러움 판정이 아니다. 이전 정적629회/433종의 모든 실제 역할을 분류한 것은 아니다.

원본 문자열·틀/반복 배열·행/열(UTF-16)·소스 구간 지문을 보존한다. 선택한12개 템플릿 표현식의 유한 값을 모두 열거했다는 범위만 true다. 다른 문자열 결합·여러 줄/한 단어 예문·추가 생성기/보관 평가·구조 가족 전체를 검증하지 않았다. 원문 대문자 파생은 정규화 비교에서 같은 표면으로 잡히지만 모든 가능한 변환을 실행/열거한 것으로 표현하지 않는다.

이 목록은 **로컬 출처 점검용**이며 모델 요청으로 보내지 않는다. 기존426corpus·wire 크기 제한·fresh 정책과 실행기를 바꾸지 않았다. matchProgramTemplateExpansionV1은 일치하면 known-finite-test-frame-surface,불일치하면 unresolved-not-a-freshness-clearance다. 어느 쪽도 fresh/영어 정답/가족 독립성 합격이 아니다.
