## 자금 연결과 실패 처리

기존 V3 원장의 배타 잠금을 잡고, 과거 배정·정산 원문의 지문과 현재 원장·후보·요청·승인 지문을 대조한다. 고정된 미사용액 소비 파일을 최초 한 번만 기록한 뒤 일반 원장에 최대 US$0.611241을 예약한다. 이 두 단계가 끝나기 전에는 키를 읽지 않는다. 같은 전용 잔액을 두 번 배정하거나 기존 원장을 초기화하지 않는다.

일반 원장은 첫 입력 계산료 여유 US$0.035와 전용 잔액을 넘는 비용을 부담한다. 나머지 47회 계산료 여유 US$1.645와 가능한 모델 비용은 전용 잔액에서 부담한다. 두 자금원의 합은 항상 전체 보수 비용과 같고, 각각의 상한도 지킨다. 일반 원장용 `stageUsedUpperMicros`·`countAllowanceRetainedMicros`와 전체 비용용 `combinedUsedUpperMicros`·`combinedCountAllowanceRetainedMicros`를 구분한다. 계산료 여유 US$1.68을 US$0.035로 줄인 것이 아니다.

계산 단계 실패나 측정 견적 초과 시 전체 계산료 여유 US$1.68을 유지한다. 모델 전송 뒤 HTTP·시간 초과·사용량 오류 등으로 비용이 불명확하면 합계 상한 US$5.690037을 유지한다. 형식이 틀리거나 기대 기준과 다른 채점은 원문과 함께 그대로 보존한다. 일부 파일만 저장된 경우에도 소비 기록과 예약을 남겨 재전송을 차단한다. 자동 복구·자동 재시도는 없으며 실제 장애의 정산 복구는 별도 근거 검토가 필요하다.
