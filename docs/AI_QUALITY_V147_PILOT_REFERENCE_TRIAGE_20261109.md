# T24.2·T34.3 예비 60문항 요청과 참조 재대조

최신 수정판과 고정 기준선의 실제 제품 요청 함수로 60문항 × 두 버전 × 세 모델의 **360개 요청**을 다시 만들었다. 이전에 준비한 360개와 바이트 단위로 모두 일치했다. 이후 수정된 학습자 화면은 별도 버전으로 유지되며, 이번 검사는 생성 요청 본문을 대조한 것이다.

60개의 참조 작성 기록과 두 비작성자 검토 120개도 이전 원본 요청과 응답에서 다시 검증했다. 기존 검토의 여섯 언어·과제 항목은 60문항에서 두 모델이 일치했고, 출처 적용 범위나 문맥은 아래처럼 나눴다.

| 분류 | 문항 수 | 처리 |
| --- | --- | --- |
| 출처 부족 또는 AI 합의만 표시 | 12 | 문법·사전 근거 보완. 이전 검토와 새 근거를 분리 |
| 이 중 출처 부족을 명시 | 6 | 부족했던 문법·용법 설명에 직접 대응하는 근거를 추가 |
| 문맥·방언 등의 모호함 표시 | 7 | 조건부 해석을 유지 |
| 위 두 항목에 해당하지 않음 | 41 | 이전 검토 근거를 유지하고 자격 확인 대상으로 분류 |

예를 들어 `make` 뒤에 목적어를 설명하는 형용사가 오는 구조는 문법적으로 가능하다. 이 문항은 정상 문장인지와 과제에서 요구한 형용사 사용법을 충족하는지를 각각 판단한다. 명시적인 과거 사건의 `ask` 교정에는 규칙동사의 과거형 근거를, 전치사 뒤 대명사 교정에는 목적격 근거를 연결했다. 출처별로 직접 열어 확인한 페이지와 검색에 표시된 편집 본문 발췌를 구분했다. 12개 보완안의 URL과 적용 범위는 `outputs/ai-quality-v147-implementation-20261106/phase108/source-supplement.json`에 보존했다. 기존 AI 검토가 이 새 근거를 평가한 것으로 처리하지 않았다. 60문항의 확인 평가용 독립성은 미확인이고, 정식 보정의 MC12 이견도 보류로 유지한다.

현재 설계의 60문항 예비평가는 실제 생성 360개와 교차 채점 1,440개가 남아 있다. 현재 계산료 여유 규칙만 적용해도 전체에 US$63의 준비금이 필요하다. 이는 실제 청구액이 아닌 사전 예산의 일부이며 모델 비용은 별도다. 일반 가용액 US$3.039780에서 전체 평가를 바로 실행할 수 없다. 이번 API 호출·입력 계산·키 읽기는 모두 0이다. [기존 예비평가 분모와 비용](AI_QUALITY_V147_PILOT_SCOPE_AUDIT_20261109.md)
