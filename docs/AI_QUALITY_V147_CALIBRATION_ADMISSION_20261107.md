# 평가 기준 문항의 사용 자격 검사 · 2026-11-07

실제 공개 진단 6응답은 수집했지만 영어 정답을 확정하지 못했다. 따라서 이전 12개 기준 문항을 그대로 ‘검증된 정답’으로 사용해 다음 보정 평가를 통과시키지 않도록 현재 평가 프로필에 사용 자격 검사를 추가했다. 기존 정책의 ‘참조에 이견이 있으면 보정 수락 중단’을 수집기와 보고서에 연결하는 변경이다.

## 동작과 적용 범위

- 원래 12개 문항과 기대 점수는 유지한다. N04/G12는 분쟁 중, 나머지 11개는 검토 미완료 상태다. 가상 오류 F01–F04에 없던 goldCaseId는 만들지 않았다.
- 현재 프로필은 참조 원본·감사·실제 6응답 진단의 지문과 고정된 사용 자격 목록을 검증한다. 문항 ID가 witness-12로 바뀌어도 내용 지문으로 N04/G12를 찾아 차단한다.
- 현재 프로필의 pilot-panel을 열면 저널 잠금·캡처·토큰 계산·모델 요청 전에 `CALQ1_REFERENCE_UNQUALIFIED`로 중단한다. 기대 점수 편집·문항 제거·중복·검토 완료 위조도 거절한다.
- 보고서는 점수 일치에 따른 산술 통과와 참조 사용 자격을 별도로 표시한다. 산술이 통과해도 미검토 참조로 보정 수락은 불가능하다.
- 새 참조를 작성하는 reference-preparation은 본 보정 문항을 사용하지 않으므로 이 조건만으로 막지 않는다. 기존 출처·노출·의견 일치 검사는 계속 적용한다.

이 수집기는 합성 전용이다. 기존 정책 없는 fixture는 과거 전송·복구 검사에 사용하며 `legacy-synthetic-mechanism-only`로 표시하고 보정 수락을 부여하지 않는다. 모든 실행 경로에 대한 강제 적용이나 실제 유료 본 평가 실행을 구현했다는 의미는 아니다. 현재 프로필 생성에는 `calibrationAdmissionFixtureV1`/`withCalibrationAdmissionV1`과 manifest의 필수 프로토콜을 사용한다. 기존 16개 봉인 구성 요소 안의 contract/collectionPolicy에 연결하며 모델에 전달하는 요청 본문은 바꾸지 않는다.

## 검증 절차와 완료 기준

`QA_OUTPUT_DIR`를 아직 없는 검증 폴더의 절대 경로로 지정하고 다음을 Node22.23.4와 Node24.22.1에서 실행한다.

```powershell
node --test .taskmaster/scripts/test-ai-quality-v147-calibration-admission-v1.mjs
```

11개 검사는 원본 지문, 별칭, 잠금 전 차단, 목록/정책 위조, 문항 변조, 보고서 구분, 이전/현재 대조, 과거 경로 제한, 참조 작성 호환, 물리 원본 사본 변조, 요청/점수 보존을 확인한다. 대조는 같은 현재 프로필을 과거 수집기에 넣어 합성 보정 72회와 첫 생성 1회를 허용하는지, 수정 경로는 0회에서 막는지를 비교한다. 이 대조는 합성 수집기 검사이며 실제 영어 판정 성능 비교가 아니다.

최종 실행·종료 코드와 로그는 `outputs/ai-quality-v147-implementation-20261106/phase49/focused-checks.json` 및 `management-checks.json`을 따른다. 기존 수집·출처·토큰 계산·복구 검사, 기존 빌드 Worker의 합성 동작, 대시보드와 관리 원본 검증을 포함한다. 최초 검사의 보고서 반환 위치/템플릿 필드 참조 오류와 실패 로그도 보존한다.

## 비용·상태·복구

이번 보완의 유료 호출·키 읽기는 0이다. [실제 토큰 비용](AI_QUALITY_V147_ASTRA_ACTUAL_TOKENS_20261107.md)의 세전 한도 US$5, 생성 6회·계산 2회, 보수적 총액 US$0.843789와 잔여 US$4.156211을 유지한다. 미확정 비용 여유를 환급하거나 닫힌 원장을 재개하지 않는다. 새 참조 검토·본 평가를 남은 금액으로 자동 실행하지 않는다.

사람 검토자 섭외는 요구하지 않는다. 후속 작업은 사용 범위가 명확한 참조와 근거를 AI로 검토해 별도 버전으로 수락할 수 있는지를 확인하는 것이다. AI 의견 일치만으로 영어 정답이나 학습 효과를 인증하지 않는다. T34/자식 4개 review, 상위 24/40·세부 77/133 완료, 전체 품질/출시 보류를 유지한다.

제품·API/백업·DB·Site는 변경하지 않았다. 새 마이그레이션·배포·운영 학습 QA·Git 작업은 없다. 과거 자료 재현에는 phase49/management-before의 보관본을 사용한다. 현재 차단을 제거해 본 평가를 계속하는 것을 복구로 취급하지 않는다. 원래 참조·실패·비용·평가 기록을 모두 보존하고, 미병합 산출물은 삭제하지 않는다.
