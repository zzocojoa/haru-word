# 첫 여섯 문항의 실제 AI 참조 검토 결과

사용자가 승인한 범위에서 입력 토큰 계산 12회와 AI 검토 12회를 완료했다. 원본 요청·응답·사용량과 예산 원장을 보존했고 자동 재전송은 0회다. [고정 실행 범위](AI_QUALITY_V147_FIRST_REFERENCE_WAVE_SCOPE_20261109.md)

| 결과 | 문항 수 | 처리 |
| --- | ---: | --- |
| 두 모델의 판정 일치 | 4 | 정식 참조 채택 심사 대기 |
| 출처 부족 | 1 | 한 모델이 동사 형태의 근거가 원문 형태를 배제하기에는 부족하다고 판단해 보류 |
| 판정 규칙 불일치 | 1 | 두 모델이 문장 조각에 문맥이 더 필요하다고 판단했으나, 수정 필요 판정과 교정 없음의 조합이 수집 규칙과 충돌해 보류 |

| 원문 | 영어 판정 | 참조 검토 결과 |
| --- | --- | --- |
| `Noor suggested to postpone the launch.` | 두 AI가 `Noor suggested postponing the launch.`에 동의했다. | 보류. 한 모델이 제공된 출처가 원문의 형태를 배제하기에는 부족하다고 판단했다. |
| `Several faded receipts` | 두 AI가 명사구이며 완성 문장에 필요한 내용이 빠졌다고 판단했다. | 보류. 문법 수정 필요, 문맥 필요, 교정 없음의 조합이 수집 규칙을 충족하지 않았다. |
| `The lacquer looks glossy under the lamp.` | 두 AI가 형용사 사용과 문법이 자연스럽다고 판단했다. | 판정 일치. 교정 없음. |
| `The museum guide handed she the brochure.` | 두 AI가 `The museum guide handed her the brochure.`로 교정했다. | 판정 일치. `she`를 목적격 `her`로 바꾼다. |
| `Even though the generator had stopped` | 두 AI가 뒤에 이어질 내용이 필요하다고 판단했다. | 판정 일치. 교정 없이 문맥을 확인한다. |
| `The fresco depicts a winter market.` | 두 AI가 `depicts`의 쓰임과 문법이 자연스럽다고 판단했다. | 판정 일치. 교정 없음. |

응답 12건 중 수집 규칙을 만족한 응답은 10건이다. 보류된 두 문항의 원판정은 보존했다. 정식 참조 자격은 0/60, 실제 예비평가 생성은 0/360이다.

실제 응답의 입력 6,594토큰과 출력 1,649토큰을 확인했다. 원장 반영액 **US$0.495434**에는 모델 비용의 보수 계산액 US$0.075434와 입력 계산료 여유 US$0.420000이 포함된다. 승인 상한은 US$1.249116이었으며, 정산 후 추가 원장 가용액은 **US$1.152100**, 예약액은 US$0이다. 이 반영액은 청구서의 확정 금액과 구분한다.
