# 격리 앱에서 실제 AI 교정문 생성 비교

T34.4 개발 진단으로 고정 60문항 밖의 새 합성 문장 세 개를 사용한다. 원문 오류가 분명할 때 전체 교정문을 제공하는지, 정상 문장의 부정 의미를 유지하는지, 시점이 모호할 때 임의로 정하지 않는지 살핀다. 기준판 `reference-v5`와 수정판 `reference-v6`의 실제 빌드를 격리된 D1과 루프백에서 실행한다. 두 판 모두 앱 기본 모델인 GPT-6.1 Sol을 한 번씩 요청한다. 기준판과 수정판은 각 문장에 동일한 수업 목표와 입력을 사용한다.

실제 빌드에서 확보한 요청 6개와 합성 응답을 사용한 저장·재조회 6건을 먼저 확인했다. 요청 지문은 `9743bea61f0b2cce24a5d96053f3a4426ee1dfbd62c9c634e6fb200b2d635a41`이다. 입력 토큰 계산 6회를 받은 뒤 앱에서 다시 만든 본문이 고정본과 일치할 때만 실제 응답을 요청한다. 모델 응답은 같은 요청에 돌려주고 앱의 표시용 응답, 저장과 재조회 결과를 대조한다. 하나의 문장마다 사용자 제출에 대응하는 모델 호출은 한 번이며 자동 재전송을 금지한다.

추가 US$35 원장의 실행 전 가용액은 US$2.016544다. 이 진단의 예약 상한 **US$0.604086**에는 토큰 계산료 여유 US$0.210000이 포함된다. 입력 토큰 계산 상한 6,000, 제품 출력 한도 4,096, Standard 단가와 보수 여유를 사용한다. 예상하는 교정·유지·보류를 사전 기록했다. 의미를 보존한 다른 적절한 표현은 별도 검토할 수 있으며 문자열 일치만으로 품질 합격을 판정하지 않는다. 이 범위에서는 60문항 예비평가, 1% 위험 검증, 출시 상태가 변경되지 않는다.
