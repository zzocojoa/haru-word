# T15.2·T26.2 실제 단어 교정 응답 재생

별도 로컬 후보의 단어 연습 화면에서 이전에 받은 실제 AI 응답 3개를 재생했다. 브라우저에서 요청 버튼을 눌렀을 때 앱이 만든 제공자 요청이 당시 요청과 바이트 단위로 일치할 때만 저장된 응답을 돌려줬다. 제공자 연결은 격리 Worker의 로컬 응답기로 가로챘다. [최초 실제 응답 기록](AI_QUALITY_V147_COMPLETE_CORRECTION_LIVE_RESULT_20261109.md)

| 이전 실제 AI 결과 | Chromium·WebKit에서 확인한 결과 |
| --- | --- |
| `Two pieces of luggage block the aisle.` | 완성 교정 표시, 저장·재조회, 새로고침 후 복원, 입력란에 적용·되돌리기 |
| `She avoids driving at night.` | 완성 교정 표시, 저장·재조회, 새로고침 후 복원, 입력란에 적용·되돌리기 |
| `The guard does not move the luggage at night.` | 원문·판정 저장·복원. 중복 교정문과 적용 버튼 없음 |

화면 6건에서 요청 버튼을 누를 때만 응답을 가져왔다. 교정 적용·되돌리기 4건은 편집 중인 문장을 바꿨고 서버에 저장된 원문, 교정 결과, 독립 회상 기록을 보존했다. 현재 요청과 영수증의 문맥 지문을 대조했다. 문맥 지문에는 세션 식별자가 포함되어 과거 가상 계정의 값과는 달랐다.

최초 두 검사는 편집 중 문장의 서버 저장을 기대하거나 서로 다른 세션의 문맥 지문을 같은 값으로 비교해 실패했다. 테스트를 실제 저장 시점과 현재 요청의 지문에 맞춰 고친 뒤 6건이 통과했다. 별도 제품 코드는 변경하지 않았다.

이전 문법 응답 6건은 당시 지침 버전이 달라 동일 요청 재생에서 제외했다. 새 AI 호출·토큰 계산·운영 쓰기는 0건이며, 이 결과는 단어 연습 세 문장과 한 모델의 회귀 근거다. 정식 예비평가 생성은 0/360이다.
