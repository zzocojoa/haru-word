# 참조 판정 경계 명문화와 요청 연결 — 2026-11-07

실제 공개 진단에서 확인한 **공통 판정 경계 정의의 부재**를 보완했다. 새 운영 기준 초안은 7차원·5위험 플래그·8경계 규칙을 명시하며, 모든 새 요청의 지시문에 포함된다. 응답에는 해당 기준의 고정 hash가 필수다. 이는 전달/버전/일부 구조적 모순을 검사하는 개선이고, 실제 AI 판단 정확도나 참조 평가자 자격의 검증은 아니다.

기존 실제 응답 6개·10/36 일치 결과, 원래 기대값, 공개 출처와 노출 자료는 그대로 보존한다. 관측 후 작성한 기준이므로 개발에 노출된 자료다. 그 결과에 맞춰 옛 점수를 올리거나 새 미공개 검증으로 계산하지 않는다. 추가 실제 모델/토큰 계산/키 읽기는 모두 0, 현재 보수적 총액은 US$3.788335/5(잔여 US$1.211665·청구서 미확인) 그대로다.

## 관측과 원인 가설

phase52 실제 요청에는 차원 이름과 일반 지시·출력 형식만 있었고, 정상 원문/수정안 없음·잘못된 목표/원문 문법·출처 귀속/일반 주장·형식 정합성/문맥 추론의 경계를 정의하지 않았다. 이것은 요청 원문으로 확인했다. 이 누락이 낮은 일치의 원인이라는 인과 가설은 새 실제 대조로 검증되지 않았다. 같은 작성자의 기대값도 독립 자격을 얻지 못했으므로 모델 불일치를 모두 모델 오류로 세지 않는다.

## 새 버전의 판정 경계

| 차원 | 평가 대상과 경계 |
| --- | --- |
| assignmentAlignment | case/assignment/domain/target/family 식별자와 선언 메타데이터의 정합성. 내용상의 과도한 추론은 별도 항목에서 판정한다. |
| inputAndTargetValidity | 목표와 진단 층위에 사용할 수 있는 입력인지. 틀린 원문이나 문맥 부족을 시험하는 입력도 유효한 검사 자료일 수 있다. |
| originalLabelSupport | meaningUsage/grammar/contextNeeded의 결합 판단. 잘못된 선언 목표에서는 결합 판단을 평가 불가로 두되 원문 문법 오류로 전가하지 않는다. 문법 목표의 meaningUsage는 해당 구문의 형태/사용을 평가한다. |
| minimalCorrectionMeaning | 제시한 모든 수정 예시의 최소성·의미 보존. 독립적으로 자연스럽고 해석 가능한 원문이며 수정 예시가 없으면 통과. 원문이 틀렸거나 메시지가 불명인데 수정 예시도 없으면 평가 불가이며, 단순히 없다는 이유로 실패 처리하지 않는다. |
| sourceClaimHonesty | 인용뿐 아니라 criterion의 실질 주장도 포함한다. 근거 없는 확정 주장과 허위 귀속을 구분해 기록한다. |
| ambiguityHandling | 필요한 문맥·해석 불확실성을 유지하는지. 문맥 의존 응답을 일률적으로 비문으로 단정하지 않는다. |
| exposureAndFamilyCompliance | 공개 노출·가족 독립성. 이미 알려진 문장은 진단용이어도 실패/knownExposureLeak을 유지한다. 부분 목록만으로 독립성 통과를 주지 않는다. |

`pass`는 해당 차원의 지지가 확인됨, `fail`은 구체적인 모순이 확인됨, `uncertain`은 적용 가능한 판단의 경쟁 해석이 남음, `unavailable`은 평가 대상/전제 부족이다. 평가 불가를 통과로 세지 않는다.

위험 플래그도 분리했다. 허위 출처·인용·실측·제공된 근거의 조작은 inventedEvidence다. 제공됐다는 근거 주장 없이 빠진 앞 문맥을 임의로 확정하는 경우는 sourceClaimHonesty/ambiguityHandling/forcedCertainty로 다루며 그 자체만으로 inventedEvidence를 켜지 않는다. 수정 예시가 없으면 가상의 수정을 만들어 meaningConstraintViolation을 켜지 않는다. 이는 이 새 버전의 운영 정의 초안이며 보편적인 정답이라고 주장하지 않는다.

## 구현과 관측 가능한 성공 조건

- `.taskmaster/docs/ai-quality-v147-reference-operational-rubric-v1.json`: 문항별 정답/역할 없는 공통 기준, hash 고정, 개발 노출/자격 미확보 표시.
- `.taskmaster/scripts/ai-quality-v147-reference-rubric-v1.mjs`: 기존 요청을 수정하지 않는 별도 어댑터. 2문항 참조 검토와 공개 7기록 묶음의 새 요청에 기준을 붙이고 응답 hash·항목 ID·고정 분모·위험/차원 모순을 검사한다.
- 새 6요청은 84,237–84,239 bytes로 기존 131,072 한도를 유지한다. 입력 전체와 기준/응답 스키마를 토큰 계산용 본문에 똑같이 포함하며 출력 최대 4,096을 유지한다. 실제 토큰 수·새 최종 견적은 아직 없다.
- private 기대값·문항 역할·세부 기대 근거는 모델에 전달하지 않는다. 문항/출처/노출 정보는 모두 보존하고 기준별 새 별칭을 사용한다.
- 잘못된 선언 목표의 모순, 위험 플래그와 대응 실패의 모순, 제시하지 않은 수정에 대한 의미 위반을 거절한다. 다른 차원의 실패를 무조건 위험 플래그로 확대하지 않는다. 문법 자연스러움이나 의미 동등성을 코드로 자동 판정하지 않는다.
- 응답의 hash는 **사용했다고 선언한 기준 버전**만 묶는다. 모델이 이해/준수했다는 증거가 아니다. 이전 실제 응답을 새 요청에 붙이거나 hash가 없는 옛 응답을 새 점수로 소비하면 거절한다.

현재 유료 수집기와 기존 참조 실행기는 바꾸지 않았다. 새 어댑터는 아직 이들의 실제 실행 경로에 통합되지 않았고, 새 기준에 대한 실제 모델 수집·역할 자격은 미완료다. 기존 승인/닫힌 원장으로 이 요청을 실행하지 않는다. 기존 입력 토큰 수나 과거 US$4.875245 견적을 새 요청에 재사용하지 않는다.
