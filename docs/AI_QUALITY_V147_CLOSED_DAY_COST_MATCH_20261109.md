# T34.3 정식 보정 비용 대조와 계산료 예비비

OpenAI 사용량 화면에서 Default project의 2026년 11월 8~9일 UTC 상세 비용 CSV를 내려받아, 이전 보고서와 이후에 보관한 응답 329개의 실제 사용량을 대조했다. 11월 8일에 추가된 모델 응답 245개는 보고서의 15개 비용 항목과 토큰·금액이 모두 일치했다. 11월 9일에는 Sol의 네 모델 비용 항목에서 합계 US$0.012527 차이가 있어 그날 계산료 예비비 US$2.94는 유지한다.

11월 8일에 기록된 계산 응답 245개의 원본, 전송 의도, 토큰 계산 본문과 여섯 실행의 정산 기록을 대조했다. 이전 정산에 들어간 실행과 중복되는 건은 없었다. 과거 161회의 US$5.635와 그 뒤 84회의 US$2.94를 합한 **US$8.575**가 정산 검토 대상이다. 기존 미청구 대비액 US$1도 유지한다. 기간별 보고서의 일치는 최종 청구서나 앞으로의 계산 API 단가를 확정하지 않는다.

| 구분 | 세전 US$ |
| --- | --- |
| 현재 추가 US$35 원장 가용액 | 3.039780 |
| 11월 8일 예비비 정산 검토액 | 8.575000 |
| 해당 정산을 한 번 적용했을 때 가용액 | 11.614780 |
| 정식 보정 72개 Standard 예약 상한 | 8.567184 |
| 기존 가용액을 그대로 둔 채 검증된 정산분만 72개에 배정할 경우 여유 | 0.007816 |

공식 문서에서 지정한 세 모델과 Responses의 Batch 지원, 모델 요금 50% 인하를 확인했다. 기존 계산료 예비비를 유지하면 Batch의 출력 상한과 계산료 여유만으로 약 US$3.40이 필요하다. 11월 8일 정산분을 단 한 번 별도로 연결하면 현재의 Standard 요청 72개와 출력 상한을 유지할 수 있다. 이번 단계는 비용 대조와 검증된 정산 범위 확정까지다. 활성 V3 원장과 두 사본의 지문, 사용액과 가용액은 동일하다. 추가 호출·계산·키 읽기는 모두 0이다. 정산분의 중복 사용을 차단하는 연결, 출처 자격과 정식 보정 실행은 보류다. CSV와 원본 대조 지문은 Git 제외 `outputs/ai-quality-v147-implementation-20261106/phase105/`에 보존했다.
